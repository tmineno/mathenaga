::: goal
定義や定理を記号のまま正確に読み下し、証明のどこで仮定が使われているかを追えるようになる。
:::

::: motivation
大学の数学の教科書を開いて最初につまずくのは、内容より書き方であることが多いものです。$\forall \varepsilon > 0\ \exists \delta > 0$ のような記号の列は、読み方を知っていれば、ふつうの日本語の文に戻せます。証明も、決まった型を知っていれば、どこを読めば要点がつかめるかが分かります。
:::

この章では、記号の読み方と、定義・定理・証明の読み方を順に扱います。ここで身につけた読み方は、[[@convergence-metric]] 以降のすべての章で使います。

## 記号の読み方 {#reading-symbols}

::: summary
記号で書かれた数学の主張を、日本語の文に読み下すための文法。かなめは「任意の」「ある」などの量化子を自在に記載し理解することである。
:::

::: why
収束・連続・完備といった、この先の定義はどれも $\forall$ と $\exists$ の組み合わせで書かれます。二つの記号の順番を入れ替えるだけで、まったく別の主張になります。記号を一つずつ日本語に戻せれば、長い定義も怖くありません。そのための文法が、一階の述語論理 (first-order predicate logic) です。
:::

### 命題と論理結合子

真か偽かがはっきり決まる文を命題 (proposition) と呼びます。「$2 < 3$」は真の命題、「$\sqrt{2}$ は有理数である」は偽の命題です。「$x < 3$」は $x$ が決まるまで真偽が決まらないので、このままでは命題ではありません。

命題どうしは、論理結合子 (logical connective) でつないで、新しい命題にします。

| 記号 | 読み方 | 真になるとき |
|---|---|---|
| $\neg P$ | $P$ でない | $P$ が偽のとき |
| $P \land Q$ | $P$ かつ $Q$ | $P$ と $Q$ がどちらも真のとき |
| $P \lor Q$ | $P$ または $Q$ | $P$ と $Q$ の少なくとも一方が真のとき(両方でもよい) |
| $P \Rightarrow Q$ | $P$ ならば $Q$ | $P$ が偽のとき、または $Q$ が真のとき |
| $P \iff Q$ | $P$ と $Q$ は同値 | $P$ と $Q$ の真偽が一致するとき |

いちばん間違えやすいのは $P \Rightarrow Q$(含意)です。真理値表で確かめておきます。

| $P$ | $Q$ | $P \Rightarrow Q$ |
|---|---|---|
| 真 | 真 | 真 |
| 真 | 偽 | 偽 |
| 偽 | 真 | 真 |
| 偽 | 偽 | 真 |

含意が偽になるのは「$P$ が真なのに $Q$ が偽」のときだけです。たとえば実数 $x$ について「$x > 2 \Rightarrow x^2 > 4$」はどの $x$ でも真です。$x = 1$ では前提 $x > 2$ が偽なので、結論がどうであれ含意は真になります。

### 述語と量化子

「$x < 3$」のように、変数を含み、変数に値を入れると命題になる文を述語 (predicate) と呼び、$P(x)$ のように書きます。述語から命題を作るもう一つの方法が、量化子 (quantifier) です。

| 記号 | 読み方 | 意味 |
|---|---|---|
| $\forall x\, P(x)$ | 任意の $x$ について $P(x)$ | どの $x$ を選んでも $P(x)$ が成り立つ |
| $\exists x\, P(x)$ | ある $x$ について $P(x)$ | $P(x)$ が成り立つ $x$ が少なくとも一つある |

$\forall$ は全称記号 (universal quantifier)、$\exists$ は存在記号 (existential quantifier) と呼びます。量化子が付いた変数は束縛変数 (bound variable) で、別の文字に置き換えても意味は変わりません($\forall x\, P(x)$ と $\forall t\, P(t)$ は同じ主張)。量化子の付いていない変数は自由変数 (free variable) で、その値が決まるまで式全体の真偽は決まりません。

数学ではたいてい、変数の動く範囲を $\forall x \in X$ のように書き添えます。これは次の略記です。$\forall$ では「ならば」、$\exists$ では「かつ」でつなぐ点に注意します。

$$
\forall x \in X: P(x) \;:\iff\; \forall x\,\bigl(x \in X \Rightarrow P(x)\bigr), \qquad \exists x \in X: P(x) \;:\iff\; \exists x\,\bigl(x \in X \land P(x)\bigr)
$$

量化子で動かす変数が、その理論が扱う「もの」(数、点、集合など)だけである論理を、一階 (first-order) の論理と呼びます。「すべての性質 $P$ について」のように、述語そのものを量化する論理は二階以上の論理と呼ばれます。ふだんの数学は、集合も「もの」として扱う一階の論理の上で書かれているので、このサイトでは一階の論理だけを使います。

::: examples
- 実数全体 $\mathbb{R}$ で、$\forall x\ \exists y: y > x$ は「どんな数 $x$ にも、それより大きい数 $y$ がある」と読め、正しい主張です($y = x + 1$ とすればよい)。
- 順番を入れ替えた $\exists y\ \forall x: y > x$ は「ある数 $y$ は、どの数 $x$ よりも大きい」と読め、正しくありません。そのような $y$ があったとしても、$x = y$ を選べば $y > x$ が成り立ちません。
- 前者では $y$ を $x$ に合わせて選べますが、後者では $y$ を先に一つ決めてから、どの $x$ にも勝たなければなりません。
:::

### 否定の作り方

証明では、主張の否定を正確に作る場面がよくあります。論理結合子の否定には、次の規則(ド・モルガンの法則 (De Morgan's laws) と、含意の否定)を使います。

$$
\neg(P \land Q) \iff \neg P \lor \neg Q, \qquad \neg(P \lor Q) \iff \neg P \land \neg Q, \qquad \neg(P \Rightarrow Q) \iff P \land \neg Q
$$

量化子を含む主張の否定は、量化子を入れ替え、条件を否定して作ります。

$$
\neg\bigl(\forall x: P(x)\bigr) \iff \exists x: \neg P(x), \qquad \neg\bigl(\exists x: P(x)\bigr) \iff \forall x: \neg P(x)
$$

たとえば「任意の $\varepsilon > 0$ に対して、ある $N$ があり、$n \ge N$ ならば $|x_n| < \varepsilon$」の否定は「ある $\varepsilon > 0$ があって、どの $N$ に対しても、$n \ge N$ で $|x_n| \ge \varepsilon$ となる $n$ がある」です。量化子を外側から一つずつ入れ替え、最後に条件を否定しています。[[@convergence]] で、点列が収束しないことを示すときにこの形を使います。

### 集合と写像の記号

量化子と並んでよく使う記号です。

| 記号 | 読み方 | 意味 |
|---|---|---|
| $x \in A$、$A \subset B$ | $x$ は $A$ に属する、$A$ は $B$ に含まれる | 要素と集合、集合と集合の関係 |
| $\{x \in X \mid P(x)\}$ | $P(x)$ をみたす $X$ の要素の集まり | 条件で集合を作る |
| $f: X \to Y$ | $X$ から $Y$ への写像 $f$ | $X$ の各要素に、$Y$ の要素を一つずつ対応させる |
| $A := B$ | $A$ を $B$ で定める | 左辺を、右辺の意味で新しく使う |

::: pitfall
- 「任意の」は「勝手に一つ選んだ」ではなく「どれを選んでも」という意味です。また「ある」は「ちょうど一つ」ではなく「少なくとも一つ」です。ただ一つであることを言うときは、$\exists!$ と書くか「ただ一つ存在する」と明記します。
- 「または」は、両方が成り立つ場合も含みます。日常語の「A か B のどちらか一方」とは違います。
- $\exists x \in X: P(x)$ を $\exists x\,(x \in X \Rightarrow P(x))$ と書くと、別の意味になります。$X$ の外の $x$ を一つ選べば前提が偽になって含意は真になるので、$P$ が何であっても成り立ってしまいます。
- 空集合 $\emptyset$ について、$\forall x \in \emptyset: P(x)$ は、$P$ が何であっても真です。前提 $x \in \emptyset$ がいつも偽だからです。
:::

## 定義と証明の読み方 {#reading-proofs requires=reading-symbols}

::: summary
定義は約束、定理は主張、証明はその根拠。証明を読むときは、仮定がどこで使われるかを追う。
:::

::: why
数学の本は、定義・定理・証明の三つの型を繰り返して進みます。型ごとに読み方が違います。定義は覚えるもので、正しいか間違っているかを問うものではありません。定理は確かめるもので、仮定と結論に分けて読みます。証明は、仮定のそれぞれがどこで効いているかを追いながら読みます。
:::

定理を読むときは、まず仮定と結論に分けます。[[@banach]] のバナッハの不動点定理なら、仮定は「空間が完備」と「写像が縮小写像」、結論は「不動点がただ一つあり、逐次近似がそこに収束する」です。このサイトの「証明の骨格」は、証明の各段階に、どの仮定を使ったかを括弧で書き添えています。また「仮定を外すと」では、仮定を一つ外すと結論が成り立たなくなる例を示し、仮定が飾りではないことを確かめます。

証明にはいくつかの決まった型があります。

- **直接証明**:仮定から出発して、結論まで推論をつなぐ。
- **対偶** (contrapositive):$P \Rightarrow Q$ の代わりに、同値な $\neg Q \Rightarrow \neg P$ を示す。
- **背理法** (proof by contradiction):結論が成り立たないと仮定して、矛盾を導く。
- **数学的帰納法** (mathematical induction):$n = 1$ で成り立つことと、$n$ で成り立てば $n + 1$ でも成り立つことを示す。

::: theorem {#sqrt2-irrational name="√2 は無理数"}
$\sqrt{2}$ は有理数ではない。
:::

::: proof-sketch
1. $\sqrt{2}$ が既約分数 $p/q$ で書けると仮定する(背理法)。
2. $p^2 = 2q^2$ から $p$ は偶数、さらに $q$ も偶数になる(「$n^2$ が偶数なら $n$ は偶数」を使う)。
3. $p$ と $q$ がどちらも偶数なのは、既約であることに反する。
:::

::: proof
$\sqrt{2} = p/q$($p, q$ は正の整数で、公約数は 1 だけ)と仮定します。両辺を 2 乗すると

$$
p^2 = 2q^2
$$

なので $p^2$ は偶数です。$n^2$ が偶数なら $n$ は偶数なので(確認問題 3)、$p$ は偶数で、$p = 2r$ と書けます。代入すると $4r^2 = 2q^2$、つまり $q^2 = 2r^2$ で、同じ理由で $q$ も偶数です。$p$ と $q$ がともに 2 で割り切れるので、公約数が 1 だけという仮定に反します。よって $\sqrt{2}$ は有理数ではありません。
:::

この定理は、[[@cauchy-sequence]] で有理数の世界に「穴」があることを示す例の土台になります。

::: pitfall
$P \Rightarrow Q$ が正しくても、逆の $Q \Rightarrow P$ が正しいとは限りません。たとえば「収束する数列は有界である」は正しい主張ですが、逆の「有界な数列は収束する」は正しくありません。$(-1)^n$ は有界ですが収束しません。一方、対偶の「有界でない数列は収束しない」は、もとの主張と同値なので正しい主張です。
:::

::: review
- 命題と述語を区別し、論理結合子と量化子で書かれた式を日本語に読み下せる。含意 $P \Rightarrow Q$ の真理値表を言える。
- $\forall$ と $\exists$ を日本語に読み下し、順番を入れ替えると主張が変わることを例で説明できる。
- 量化子を含む主張の否定を作れる。
- 定理を仮定と結論に分け、証明のどこで各仮定が使われているかを追える。
- 逆と対偶の違いを説明でき、対偶・背理法・数学的帰納法の型を見分けられる。
:::

::: question
実数全体で考えます。「$\forall x\ \exists y: x < y$」と「$\exists y\ \forall x: x < y$」は、それぞれ正しいですか。
:::

::: answer
前者は正しく、後者は正しくありません。前者は、$x$ ごとに $y = x + 1$ を選べば成り立ちます。後者は、ある $y$ がすべての $x$ より大きいという主張ですが、$x = y$ を選ぶと $x < y$ が成り立たないので誤りです。
:::

::: question
「任意の $\varepsilon > 0$ に対して、ある $N$ があり、すべての $n \ge N$ について $|x_n| < \varepsilon$」の否定を、量化子を使って書いてください。
:::

::: answer
「ある $\varepsilon > 0$ があって、どの $N$ に対しても、ある $n \ge N$ で $|x_n| \ge \varepsilon$」です。$\forall$ と $\exists$ を入れ替え、最後の条件 $|x_n| < \varepsilon$ を否定します。
:::

::: question
整数 $n$ について、「$n^2$ が偶数なら $n$ は偶数」を対偶を使って証明してください。
:::

::: answer
対偶は「$n$ が奇数なら $n^2$ は奇数」です。$n = 2k + 1$ と書くと、$n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$ なので $n^2$ は奇数です。対偶が正しいので、もとの主張も正しいことが分かります。
:::

::: question
「$P \Rightarrow Q$」の否定を、$\Rightarrow$ を使わずに書いてください。また、実数 $x$ について「$x^2 = 4 \Rightarrow x = 2$」の否定を書き、それが正しいかどうかを答えてください。
:::

::: answer
$\neg(P \Rightarrow Q)$ は $P \land \neg Q$ です。ただし「$x^2 = 4 \Rightarrow x = 2$」をすべての実数 $x$ についての主張($\forall x$ が省略されている)と読むと、否定は「ある実数 $x$ について $x^2 = 4$ かつ $x \ne 2$」です。$x = -2$ がそうなので、否定の方が正しく、もとの主張は誤りです。
:::
