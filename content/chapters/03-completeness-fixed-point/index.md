::: goal
逐次近似が必ず答えにたどり着くための条件を述べ、その理由を一つの定理から説明できるようになる。
:::

::: goal {field=physics}
力が位置と速度について時刻全体でリプシッツ連続なら、運動方程式の解は初期条件からただ一つに決まります。古典力学の決定論を支えるこの事実を、バナッハの不動点定理から、短い時間の解をつないで導けるようになります。
:::

::: goal {field=cs}
有限個の状態と行動をもつ問題で割引率が 1 未満なら、価値反復法はどの初期値から始めても、ベルマン作用素のただ一つの不動点に収束します。強化学習の土台にあるこの事実を、バナッハの不動点定理から導けるようになります。
:::

::: motivation
電卓に適当な数を入れて cos のキーを押し続けると、表示は 0.739085… に落ち着きます。この数は方程式 $x = \cos x$ の解です。同じ操作を繰り返して方程式を解くこの方法を、逐次近似(反復法)と呼びます。逐次近似は、集合 $X$ から $X$ への写像 $T$ を繰り返し適用して、$x = T(x)$ となる点(不動点)に近づけるという形をしています。cos の例では、$X$ は実数全体、$T$ は $\cos$ です。
:::

::: motivation {field=physics}
物理でも逐次近似を使います。運動方程式の解をピカールの方法で作るとき、散乱問題をボルン級数で解くとき、自己無撞着場の方程式を反復で解くとき、どれもこの形です。
:::

::: motivation {field=cs}
情報科学でも、同じ計算を繰り返して答えに近づく方法を使います。強化学習の価値反復法、PageRank の計算、ニュートン法による求根は、どれもこの形です。ただし、形が同じでも収束するとは限りません。たとえばニュートン法は一般には縮小写像ではなく、この章の定理だけでは収束を保証できません。
:::

ただし、繰り返せば必ず答えにたどり着くとは限りません。うまくいかない原因は二つあります。

1. 列の項どうしは近づき合っていくのに、行き着く先の点が空間の中にない。
2. そもそも列の項どうしが近づき合わない。

この章では、1 を防ぐ条件として[[completeness|完備性]]を、2 を防ぐ条件として[[contraction|縮小写像]]を導入します。両方がそろえば、逐次近似は必ず成功します。これが到達目標の[[banach|バナッハの不動点定理]]です。

## コーシー列 {#cauchy-sequence requires=metric-space}

::: summary
先に進むほど、項どうしがいくらでも近づき合う点列。
:::

::: why
[[点列の収束]]を確かめるには、行き先の点 $x$ を先に知っている必要があります。逐次近似では、その行き先こそが求めたい答えです。だから、列そのものだけを見て判定できる基準が要ります。
:::

::: definition {name="コーシー列" en="Cauchy sequence" aliases="コーシー点列"}
[[距離空間]] $(X, d)$ の点列 $(x_n)$ がコーシー列であるとは、次が成り立つことをいう。

$$
\forall \varepsilon > 0\ \ \exists N\ \ \forall m, n \ge N:\quad d(x_m, x_n) < \varepsilon
$$

ここで $N$、$m$、$n$ は正の整数を動く。
:::

どんなに小さな正の数 $\varepsilon$ を指定されても、ある番号 $N$ から先の項は、どの二つをとっても距離が $\varepsilon$ 未満に収まります。

::: examples
- 収束する点列はコーシー列です。極限を $x$ とし、$\varepsilon > 0$ に対して、すべての $n \ge N$ について $d(x_n, x) < \varepsilon/2$ となる番号 $N$ をとります。すべての $m, n \ge N$ について、三角不等式から $d(x_m, x_n) \le d(x_m, x) + d(x, x_n) < \varepsilon$ です。
- 逆は成り立ちません。有理数全体 $\mathbb{Q}$(距離は $d(x, y) = |x - y|$)で、$\sqrt{2}$ の小数を一桁ずつ伸ばした列 $1,\ 1.4,\ 1.41,\ 1.414,\ \dots$ はコーシー列です。$m, n \ge N$ なら二つの項は小数第 $N - 1$ 位まで一致するので、$|x_m - x_n| < 10^{-(N-1)}$ だからです。しかし $\mathbb{Q}$ の中に極限はありません。$\mathbb{Q}$ の中に極限 $q$ があれば、$\mathbb{R}$ でも $q$ に収束するので、[[@limit-unique]] から $q = \sqrt{2}$ となり、$\sqrt{2}$ が有理数でないことに反します。
:::

::: pitfall
隣り合う項の距離 $d(x_{n+1}, x_n)$ が 0 に近づくだけでは、コーシー列とは言えません。$x_n = \sqrt{n}$ では $\sqrt{n+1} - \sqrt{n} \to 0$ ですが、列は限りなく大きくなります。たとえば $d(x_{4n}, x_n) = \sqrt{4n} - \sqrt{n} = \sqrt{n}$ は、$n$ を大きくするほど大きくなり、どんな $\varepsilon$ よりも小さくはなりません。定義が隣どうしではなく、番号 $N$ より先のすべての二項を見ているのはこのためです。
:::

## 完備性 {#completeness requires=cauchy-sequence}

::: summary
コーシー列が必ず収束する、穴のない空間。
:::

::: definition {name="完備" en="complete" aliases="完備性"}
距離空間 $(X, d)$ のすべての[[コーシー列]]が $X$ の点に収束するとき、$X$ は完備であるという。
:::

コーシー列が近づいていく先の点が、どれも空間の中にある、ということです。$\mathbb{Q}$ のように行き先の点が欠けている空間を、「穴がある」と言います。

::: examples
$\mathbb{R}$ とその部分集合には、距離 $d(x, y) = |x - y|$ を入れます。

- 完備:$\mathbb{R}$。これは実数の性質として認めます。$\mathbb{R}^n$(ユークリッド距離)は、各成分の列が $\mathbb{R}$ のコーシー列になることから完備です。閉区間 $[a, b]$ は、下の注意から完備です。
- 完備でない:$\mathbb{Q}$([[@cauchy-sequence]] の例)、開区間 $(0, 1)$(列 $1/(n+1)$ の行き先 0 が空間の外にある)
:::

完備な空間 $X$ の閉集合 $F$ は、同じ距離で完備です。$F$ のコーシー列は $X$ のコーシー列なので $X$ のある点に収束し、[[@closed-set-limits]] からその点は $F$ にあるからです。閉区間 $[a, b]$ は $\mathbb{R}$ の閉集合なので完備です。

同じ集合でも、距離の選び方で完備かどうかが変わることがあります。完備性は、集合ではなく距離空間の性質です。例として、区間 $[a, b]$ 上の実数値の連続関数全体 $C[a, b]$ に、二通りの距離を入れてみます。

$$
d_\infty(f, g) = \sup_{t \in [a, b]} |f(t) - g(t)|, \qquad d_1(f, g) = \int_a^b |f(t) - g(t)|\,dt
$$

$d_\infty$ では完備です。$(f_n)$ を $d_\infty$ についてのコーシー列とします。各点 $t$ で $|f_m(t) - f_n(t)| \le d_\infty(f_m, f_n)$ なので、$(f_n(t))$ は $\mathbb{R}$ のコーシー列で、極限 $f(t)$ があります。コーシー列の条件「すべての $m, n \ge N$ について $d_\infty(f_m, f_n) < \varepsilon$」で $m \to \infty$ とすると、すべての $n \ge N$ とすべての $t$ について $|f(t) - f_n(t)| \le \varepsilon$ となり、$f_n$ は $f$ に[[一様収束]]します。連続関数の一様収束極限はまた連続なので、$f$ は $C[a, b]$ の点で、$d_\infty(f_n, f) \to 0$ です。

$d_1$ では完備ではありません。$[-1, 1]$ 上の連続関数 $f_n(t) = \max(-1, \min(1, nt))$ は、原点付近の傾きがどんどん急になる列です。$m > n$ のとき、$f_m$ と $f_n$ が違うのは $|t| < 1/n$ の範囲だけで、その差は 1 を超えないので、$d_1(f_m, f_n) \le 2/n$ となり、$d_1$ についてコーシー列です。近づいていく先は、$t < 0$ で $-1$、$t > 0$ で $1$ をとる階段関数で、連続な行き先はありません。連続な $g$ で $d_1(f_n, g) \to 0$ となるものがあったとすると、$0 < \delta < 1$ について、$n > 1/\delta$ なら $[\delta, 1]$ 上で $f_n = 1$ なので、$\int_\delta^1 |1 - g(t)|\,dt \le d_1(f_n, g) \to 0$ です。0 以上の連続関数の積分が 0 なので、$[\delta, 1]$ 上で $g = 1$ です。同じく $[-1, -\delta]$ 上で $g = -1$ です。$\delta$ はいくらでも小さくとれるので、$g$ は $t = 0$ で連続になりえません。

::: application {field=physics title="量子力学の状態空間"}
上の列 $f_n$ は、$L^2$ 距離 $d_2(f, g) = \bigl(\int_{-1}^{1} |f(t) - g(t)|^2\,dt\bigr)^{1/2}$ についてもコーシー列です。差が 1 を超えないので $|f_m(t) - f_n(t)|^2 \le |f_m(t) - f_n(t)|$ となり、$d_2(f_m, f_n)^2 \le d_1(f_m, f_n) \le 2/n$ だからです。連続な行き先がないことも、$d_1$ のときと同じ議論で示せます。つまり、連続関数の空間は $L^2$ 距離について完備ではありません。

量子力学では、波動関数 $\psi$ の確率を $|\psi|^2$ の積分で計算します。$L^2$ 距離は、これと同じ形の積分で測る距離です。極限をとる議論(固有関数による展開など)が空間の中で閉じるように、状態空間には、連続関数の空間を $L^2$ 距離について完備にした空間 $L^2$ を使います([[@hilbert-spaces]])。

完備性の物理的な意味は、重ね合わせの和がいつも状態になることです。幅 $L$ の箱の中の粒子で見てみます($d_2$ は区間を $[0, L]$ にとって同じ式で測ります)。エネルギー固有関数は $u_n(x) = \sqrt{2/L}\,\sin(n\pi x/L)$($n$ は正の整数)で、$\int_0^L u_n(x)^2\,dx = 1$ であり、$n \ne m$ なら $\int_0^L u_n(x)\,u_m(x)\,dx = 0$ です(このことを直交するといいます。[[@norm-inner-product]] で扱います)。状態を $\psi = \sum_n c_n u_n$ と展開すると、$|c_n|^2$ はエネルギーを測って $n$ 番目の準位が出る確率で、全部足すと 1 です。

部分和 $\psi_N = \sum_{n=1}^{N} c_n u_n$ について、直交することから、$M < N$ なら $d_2(\psi_N, \psi_M)^2 = \sum_{n=M+1}^{N} |c_n|^2$ となります。確率の合計が 1 なので、この和は $M$ を大きくすればいくらでも小さくなり、$(\psi_N)$ は $L^2$ 距離についてコーシー列です。状態空間が完備なら、その行き先は必ず空間の中にあります。つまり、各準位の確率を合計が 1 になるようにどう割り当てても、その割り当てをもつ状態がある、ということです。展開を $N$ 番目で打ち切った誤差も、$d_2(\psi_N, \psi)^2 = \sum_{n > N} |c_n|^2$ と、捨てた準位がもつ確率そのものになります。

連続関数だけを状態にすると、これが崩れます。基底状態 $u_1$ にある粒子について、箱の左半分 $[0, L/2]$ にいるかを測り、いると分かった直後の状態 $\chi$ は、$u_1$ を左半分だけに切り取り、全確率が 1 になるように $\sqrt{2}$ 倍したものです(測定の射影仮説)。$\chi$ は $x = L/2$ で $2/\sqrt{L}$ から 0 にとぶので、連続ではありません。展開の係数を計算すると、$c_1 = 1/\sqrt{2}$、3 以上の奇数 $n$ では $c_n = 0$、偶数 $n$ では $|c_n|^2 = 8n^2 / \bigl(\pi^2 (n^2 - 1)^2\bigr)$ です。たとえば $|c_2|^2 = 32/(9\pi^2) \approx 0.36$ です。部分和 $\psi_N$ はどれも連続関数ですが、行き先の $\chi$ は連続ではなく、$L^2$ の中にしかありません。$N = 10$ まで足しても $d_2(\psi_N, \chi)^2 \approx 0.037$、$N = 100$ でも約 $0.004$ で、高い準位に確率が残り続けます。
:::

::: application {field=cs title="価値関数の空間"}
強化学習では、状態の集合 $S$ 上の関数 $V: S \to \mathbb{R}$ を価値関数と呼びます。有界な価値関数の全体 $B(S)$ に sup 距離

$$
d_\infty(V, W) = \sup_{s \in S} |V(s) - W(s)|
$$

を入れた空間は完備です。上の $C[a, b]$ と同じく、各状態 $s$ で $\mathbb{R}$ の完備性を使って極限 $V(s)$ を定め、一様収束を示します(一様収束の極限は有界です)。価値反復法が動く舞台はこの空間で、完備性があるおかげで、反復の行き先が空間の外に逃げません。
:::

## 縮小写像 {#contraction requires=metric-space}

::: summary
写すたびに、どの二点の距離も一定の割合以下に縮む写像。
:::

::: definition {name="縮小写像" en="contraction mapping"}
距離空間 $(X, d)$ から自分自身への写像 $T: X \to X$ が縮小写像であるとは、ある定数 $0 \le k < 1$ があって、すべての $x, y \in X$ について

$$
d(T(x), T(y)) \le k\, d(x, y)
$$

が成り立つことをいう。$k$ を縮小率と呼ぶ。
:::

::: examples
閉区間 $[0, 1]$ 上の $\cos$ を考えます。$\cos$ は $[0, 1]$ を $[\cos 1, 1] \subset [0, 1]$ に写し、平均値の定理から

$$
|\cos x - \cos y| \le \sin 1 \cdot |x - y|, \qquad \sin 1 \approx 0.84
$$

なので、縮小率 $k = \sin 1$ の縮小写像です。電卓で cos を 2 回押せば値は $[0, 1]$ に入り、それから先はこの縮小写像の繰り返しになります。出発点の実験が収束したことは、この後の [[@banach-fixed-point]] から分かります。
:::

::: pitfall
大事なのは、$k$ が 1 未満の定数であることです。「距離が縮む」だけでは足りません。[[@banach]] の「仮定を外すと」で反例を見ます。
:::

::: application {field=cs title="ベルマン作用素"}
有限個の状態と行動をもつマルコフ決定過程で、価値関数 $V$ を

$$
(TV)(s) = \max_{a} \Bigl( r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V(s') \Bigr)
$$

に写す写像 $T$ をベルマン作用素と呼びます。最大値どうしの差は差の最大値で抑えられ、遷移確率の和は 1 なので、$d_\infty(TV, TW) \le \gamma\, d_\infty(V, W)$ が成り立ちます。割引率が $0 \le \gamma < 1$ なら、$T$ は縮小率 $\gamma$ の縮小写像です。
:::

## バナッハの不動点定理 {#banach requires=completeness,contraction}

::: summary
完備な空間の縮小写像がただ一つもつ不動点と、そこへ必ずたどり着く逐次近似。
:::

::: theorem {#banach-fixed-point name="バナッハの不動点定理"}
$(X, d)$ を空でない[[completeness|完備]]距離空間、$T: X \to X$ を縮小率 $k$ の[[縮小写像]]とする。このとき次が成り立つ。

1. $T$ の不動点 $x^* = T(x^*)$ がただ一つ存在する。
2. どの初期値 $x_0$ から始めても、$x_n = T(x_{n-1})$ で作った列は $x^*$ に収束する。
3. $n = 0, 1, 2, \dots$ について $d(x_n, x^*) \le \dfrac{k^n}{1-k}\, d(x_1, x_0)$ が成り立つ。
:::

::: proof-sketch
1. 一歩の移動距離は毎回 $k$ 倍以下に縮む。移動距離を足し合わせて等比級数で抑えると、列はコーシー列になる(縮小性と三角不等式を使う)。
2. $X$ は完備なので、列は $X$ のある点 $x^*$ に収束する(完備性を使う)。
3. $T(x_n) = x_{n+1}$ で極限をとると $x^*$ は不動点になり、二つの不動点の距離は自分の $k$ 倍以下なので 0 になる(縮小性と三角不等式を使う)。
4. 1 の不等式で、番号の大きいほうの項を $x^*$ に近づけると、主張 3 の不等式が得られる(三角不等式を使う)。
:::

::: proof
**1.** 帰納法により $d(x_{n+1}, x_n) \le k^n\, d(x_1, x_0)$。$m > n$ のとき三角不等式を繰り返し使うと

$$
d(x_m, x_n) \le \sum_{j=n}^{m-1} d(x_{j+1}, x_j) \le \sum_{j=n}^{m-1} k^j\, d(x_1, x_0) \le \frac{k^n}{1-k}\, d(x_1, x_0).
$$

$0 \le k < 1$ より右辺は $n \to \infty$ で 0 に近づくので、$(x_n)$ はコーシー列。

**2.** $X$ は完備なので、$x_n \to x^*$ となる $x^* \in X$ がある。

**3.** $T(x_n) = x_{n+1}$ を使うと

$$
d(T(x^*), x^*) \le d(T(x^*), T(x_n)) + d(x_{n+1}, x^*) \le k\, d(x^*, x_n) + d(x_{n+1}, x^*) \to 0.
$$

よって $T(x^*) = x^*$。不動点 $y^*$ がもう一つあれば $d(x^*, y^*) = d(T(x^*), T(y^*)) \le k\, d(x^*, y^*)$ で、$k < 1$ より $d(x^*, y^*) = 0$。

**4.** 1 の不等式で $m \to \infty$ とする。三角不等式から $d(x_m, x_n) \to d(x^*, x_n)$ なので、主張 3 が得られる。
:::

$x_n$ を $x^*$ の近似値とみると、主張 3 はその誤差 $d(x_n, x^*)$ を上から抑える不等式(誤差評価)です。1 回目の反復と縮小率が分かれば、何回反復すれば必要な精度に届くかを前もって教えてくれます。

::: drop-assumption
**完備性を外す。** $X = [1, 2] \cap \mathbb{Q}$、$T(x) = \dfrac{x}{2} + \dfrac{1}{x}$ とします。$T$ は有理数を有理数に写し、値は $[\sqrt{2}, 3/2]$ に入るので $X$ を $X$ に写します。$|T'(x)| \le 1/2$ なので縮小率 $1/2$ の縮小写像です。それでも $X$ に不動点はありません。$T(x) = x$ を解くと $x^2 = 2$ で、行き先 $\sqrt{2}$ は $\mathbb{Q}$ の外にあります。

**「1 未満の定数 $k$」を「距離が縮む」に弱める。** $X = [1, \infty)$($\mathbb{R}$ の閉集合なので、[[@completeness]] の注意から完備)、$T(x) = x + \dfrac{1}{x}$ とします。$x \ne y$ なら

$$
|T(x) - T(y)| = |x - y|\left(1 - \frac{1}{xy}\right) < |x - y|
$$

で距離は必ず縮みますが、$T(x) > x$ なので不動点はありません。$x, y$ が大きくなるほど縮み方が弱まり、一定の割合 $k$ で抑えられないことが原因です。
:::

::: application {field=physics title="ボルン級数"}
散乱理論のリップマン–シュウィンガー方程式 $\psi = \varphi + G_0 V \psi$ も不動点の形です。$\varphi$ は入射波、$V$ はポテンシャル、$G_0$ は自由粒子のグリーン関数を表す作用素です。右辺を写像 $\psi \mapsto \varphi + G_0 V \psi$ とみると、それを考える関数の空間が完備で、作用素 $G_0 V$ のノルムが $\|G_0 V\| < 1$ なら縮小写像になり、ボルン級数 $\psi = \varphi + G_0 V \varphi + (G_0 V)^2 \varphi + \cdots$ が収束します。相互作用が弱ければ摂動展開が使えるという直観を、条件として書いたものの一つです。作用素のノルムは [[@norm-inner-product]] で扱います。
:::

::: application {field=cs title="価値反復法の収束"}
[[@completeness]] と [[@contraction]] から、ベルマン作用素 $T$ は完備な空間 $B(S)$ 上の縮小写像です。この定理により、価値反復法 $V_{n+1} = T V_n$ はどの初期値からでも、ただ一つの不動点 $V^*$ に収束します。この $V^*$ が最適価値関数であることは、マルコフ決定過程の理論で別に示される事実で、ここでは認めます。主張 3 の誤差評価

$$
d_\infty(V_n, V^*) \le \frac{\gamma^n}{1-\gamma}\, d_\infty(V_1, V_0)
$$

から、必要な精度に届くまでの反復回数を前もって見積もれます。
:::

## ピカールの定理 {#picard-lindelof requires=banach}

::: summary
微分方程式の解を、関数の空間の不動点として求める方法。
:::

初期値問題

$$
\frac{dx}{dt} = f(t, x(t)), \qquad x(0) = x_0
$$

を考えます。$x$ は $\mathbb{R}^n$ に値をとる関数、$x_0$ は $\mathbb{R}^n$ の点で、$f$ は連続とします。両辺を積分すると、初期値問題は、連続関数 $x$ についての積分方程式

$$
x(t) = x_0 + \int_0^t f(s, x(s))\,ds
$$

と同値です(微積分の基本定理を使う)。右辺を、関数 $x$ を別の関数に写す写像 $T$ とみなすと、解とは $T$ の不動点にほかなりません。舞台は、区間 $[0, h]$ 上の $\mathbb{R}^n$ 値の連続関数の空間 $C([0, h], \mathbb{R}^n)$ に sup 距離 $d_\infty(x, y) = \sup_{t \in [0, h]} |x(t) - y(t)|$ を入れたものです。ここで $|v|$ は、$\mathbb{R}^n$ のベクトル $v$ の長さ(ユークリッド距離で測った原点からの距離)です。この空間は、[[@completeness]] の $C[a, b]$ と同じ議論を各成分に当てはめると、完備です。右辺の積分は $t$ について連続なので、$T$ はこの空間を自分自身に写します。

::: definition {#lipschitz name="リプシッツ連続" en="Lipschitz continuous"}
区間 $I$ と $\mathbb{R}^n$ の上の関数 $f(t, x)$ が $x$ についてリプシッツ連続であるとは、ある定数 $L \ge 0$ があって、すべての $t \in I$ と $x, y \in \mathbb{R}^n$ について $|f(t, x) - f(t, y)| \le L\,|x - y|$ が成り立つことをいう。$L$ をリプシッツ定数と呼ぶ。
:::

$f$ が連続で、$x$ について[[リプシッツ連続]](定数 $L$)だとすると、

$$
|T(x)(t) - T(y)(t)| \le \int_0^t L\,|x(s) - y(s)|\,ds \le Lh\; d_\infty(x, y)
$$

なので $d_\infty(T(x), T(y)) \le Lh\, d_\infty(x, y)$ です。$Lh < 1$ となるように $h$ をとれば($L = 0$ ならどんな $h$ でもよい)、$T$ は縮小率 $Lh$ の縮小写像になり、バナッハの不動点定理から次が言えます。

::: theorem {#picard-lindelof-short name="ピカールの定理(短時間版)"}
$f$ が連続で、$x$ について[[リプシッツ連続]](定数 $L$)とし、$Lh < 1$ とする。このとき初期値問題は $[0, h]$ 上にただ一つの解をもつ。さらに、定数関数 $\varphi_0(t) = x_0$ から始めて $\varphi_{n+1} = T(\varphi_n)$ で作るピカールの逐次近似は、その解に[[一様収束]]する。
:::

::: proof-sketch
1. 初期値問題を積分方程式に書き換え、解を求めることを、関数を関数に写す写像の不動点を探すことに言い換える(微積分の基本定理を使う)。
2. 区間上の連続関数の空間に sup 距離を入れると、完備な距離空間になる(完備性を使う)。
3. 区間の長さをリプシッツ定数の逆数より短くとると、この写像は縮小写像になる(リプシッツ条件を使う)。
4. 不動点すなわち解がただ一つ存在し、逐次近似はそこに収束する。sup 距離での収束なので、一様収束である(バナッハの不動点定理を使う)。
:::

::: proof
**1.** $[0, h]$ 上の解とは、微分可能な関数 $x: [0, h] \to \mathbb{R}^n$ で、すべての $t \in [0, h]$ について $x'(t) = f(t, x(t))$(端点では片側の微分)、かつ $x(0) = x_0$ となるものとする。解 $x$ は連続で $f$ も連続なので、導関数 $x'(t) = f(t, x(t))$ も連続。微積分の基本定理を各成分に使うと $x(t) - x_0 = \int_0^t x'(s)\,ds = \int_0^t f(s, x(s))\,ds$ となり、$x$ は積分方程式をみたす。逆に、連続な $x$ が積分方程式をみたすとする。被積分関数 $s \mapsto f(s, x(s))$ は連続なので、微積分の基本定理から右辺は $t$ について微分可能で、導関数は $f(t, x(t))$。よって $x$ は微分方程式をみたし、$t = 0$ を代入すると $x(0) = x_0$。同じ理由で、連続な $x$ に対して $T(x)(t) := x_0 + \int_0^t f(s, x(s))\,ds$ は微分可能、したがって連続なので、$T$ は $C([0, h], \mathbb{R}^n)$ を自分自身に写す。以上から、$[0, h]$ 上の解は、$T$ の $C([0, h], \mathbb{R}^n)$ での不動点と一致する。

**2.** $C([0, h], \mathbb{R}^n)$ が $d_\infty$ について完備であることを示す。$(x_m)$ をコーシー列とし、$x_m$ の第 $i$ 成分を $x_m^{(i)}$ と書く。成分の絶対値はベクトルの長さ以下なので、すべての $t$ について $|x_m^{(i)}(t) - x_l^{(i)}(t)| \le |x_m(t) - x_l(t)| \le d_\infty(x_m, x_l)$。よって各 $i$ について $(x_m^{(i)})$ は $C[0, h]$ の $d_\infty$ についてのコーシー列で、[[@completeness]] で示した $C[a, b]$ の完備性($a = 0$、$b = h$ の場合)から、ある連続関数 $x^{(i)}$ に $d_\infty$ で収束する。これらを成分とする関数を $x$ とすると $x$ は連続。ベクトルの長さは成分の絶対値の和以下なので(三角不等式)、$d_\infty(x_m, x) \le \sum_{i=1}^{n} d_\infty(x_m^{(i)}, x^{(i)}) \to 0$。

**3.** $x, y \in C([0, h], \mathbb{R}^n)$ と $t \in [0, h]$ をとると

$$
\begin{aligned}
|T(x)(t) - T(y)(t)| &= \left| \int_0^t \bigl(f(s, x(s)) - f(s, y(s))\bigr)\,ds \right| \\
&\le \int_0^t \bigl|f(s, x(s)) - f(s, y(s))\bigr|\,ds \\
&\le \int_0^t L\,|x(s) - y(s)|\,ds \\
&\le Lt\; d_\infty(x, y) \le Lh\; d_\infty(x, y).
\end{aligned}
$$

1つ目の不等号は、ベクトル値の積分の長さが長さの積分以下であること、2つ目はリプシッツ条件、3つ目はすべての $s$ について $|x(s) - y(s)| \le d_\infty(x, y)$ であること、4つ目は $t \le h$ による。左辺の $t$ についての sup をとると $d_\infty(T(x), T(y)) \le Lh\, d_\infty(x, y)$。$0 \le Lh < 1$ なので、$T$ は縮小率 $Lh$ の縮小写像。

**4.** $C([0, h], \mathbb{R}^n)$ は定数関数 $\varphi_0$ を含むので空でなく、2 から完備、3 から $T$ は縮小写像なので、[[@banach-fixed-point]] が使える。主張 1 から $T$ の不動点 $x^*$ がただ一つあり、1 から $x^*$ は $[0, h]$ 上の解。$[0, h]$ 上の解 $z$ がほかにあっても、$z$ は連続なので $C([0, h], \mathbb{R}^n)$ の点で、1 から $T$ の不動点になり、$z = x^*$。主張 2 から $d_\infty(\varphi_n, x^*) \to 0$、すなわち $\sup_{t \in [0, h]} |\varphi_n(t) - x^*(t)| \to 0$ で、これは $\varphi_n$ が $x^*$ に[[一様収束]]することにほかならない。
:::

$f$ が時刻全体で、同じ定数 $L$ について[[リプシッツ連続]]なら、この議論はつなげます。$[0, h]$ の解の終わりの値 $x(h)$ を新しい初期値にして、$[h, 2h]$ で同じ議論をし、これを繰り返すと、どれだけ長い時間についても解がただ一つに決まります。$h$ は初期値によらないので、つなぐたびに区間が短くなることはありません。

リプシッツ性が初期値の近くでしか成り立たない場合は、値が $x_0$ のまわりの閉球 $\{v \in \mathbb{R}^n \mid |v - x_0| \le b\}$ に入る関数だけに空間を制限します。一様収束の極限も同じ閉球に値をとるので、この空間も完備です。閉球の上で $|f| \le M$ なら、$hM \le b$ となるように $h$ を小さくとると $T$ はこの空間を自分自身に写し、同じ議論が通ります。

::: drop-assumption
$x' = 3x^{2/3}$、$x(0) = 0$ を考えます。$x(t) = 0$ も $x(t) = t^3$ も解なので、解は一つに決まりません。右辺の $3x^{2/3}$ は、$x = 0$ を含むどの区間の上でもリプシッツ連続ではありません($x > 0$ での傾き $2x^{-1/3}$ が、$x \to 0$ でいくらでも大きくなる)。そのため、ピカールの定理が使えません。
:::

::: application {field=physics title="決定論とノートンのドーム"}
ニュートンの運動方程式も、位置と速度を並べれば一階の形 $dx/dt = f(t, x)$ に書けます。力が連続で、位置と速度について時刻全体でリプシッツ連続なら、上でつないだ議論から、初期条件が運動をどの時刻までもただ一つに決めます。古典力学の決定論は、数学ではこの形で言えます。

「力が位置と速度についてリプシッツ連続」とは、物体の位置や速度を少しずらしたときの、力の変わり方に上限がある、ということです。力を $F(t, r, v)$、質量を $m$ と書き、位置と速度を $\Delta r$、$\Delta v$ だけずらしたときの力の変化を $\Delta F := F(t, r + \Delta r, v + \Delta v) - F(t, r, v)$ とします。定数 $K_r \ge 0$ と $K_v \ge 0$ があって、すべての時刻 $t$、位置 $r$、速度 $v$ と、ずれ $\Delta r$、$\Delta v$ について

$$
\frac{|\Delta F|}{m} \le K_r\,|\Delta r| + K_v\,|\Delta v|
$$

が成り立つ、と言い換えられます。左辺は、位置と速度をずらしたことによる加速度の変化です。右辺の二つの項も加速度の次元をもつので、$K_r$ は時間の2乗の逆数、$K_v$ は時間の逆数の次元をもちます。「時刻全体で」は、同じ定数 $K_r$、$K_v$ が、どの時刻でも、どの位置と速度でも使えることです。ばねの力 $-kr$ なら左辺は $(k/m)\,|\Delta r|$ で、$K_r = k/m$ は角振動数 $\omega$ の2乗です。速度に比例する抵抗 $-\gamma v$ なら左辺は $(\gamma/m)\,|\Delta v|$ で、$K_v = \gamma/m$ は速度が減っていく割合(減衰率)です。一様な重力なら左辺は 0 です。どれもこの条件をみたします。逆に、万有引力やクーロン力は距離の2乗に反比例するので、二つの物体が近づくほど、少しのずれで力が大きく変わります。衝突の近くでは $K_r$ をどんなに大きくとっても条件をみたせないので、この議論はぶつかる前までの時間にしか使えません。

一階の形にするには位置と速度を並べます。二つは次元が違うので、距離を測る尺度をそろえるため、時間の目安 $\tau > 0$ を一つ決め、速度を長さの次元の $\tau v$ に直して $x := (r, \tau v)$ とします。$K_r > 0$ なら $\tau := 1/\sqrt{K_r}$ にとると(ばねなら $\tau = 1/\omega$)、$dx/dt = f(t, x)$ の $f$ は、$x$ について定数 $L = \sqrt{2}\,(\sqrt{K_r} + K_v)$ でリプシッツ連続になります。$L$ は時間の逆数の次元をもつので、$Lt$ は無次元の数です。この条件があると、すべての時刻 $t \ge 0$ について、二つの運動のずれ $|\Delta x(t)|$ は、初めのずれ $|\Delta x(0)|$ の $e^{Lt}$ 倍以下になります(グロンウォールの不等式 (Gronwall's inequality) と呼ばれる評価から分かります)。初めのずれが 0 なら以後も 0 なので、同じ初期条件から違う運動が分かれ出ることはありません。

逆に、リプシッツ連続でない力では、一意性が崩れることがあります。頂上のまわりに回転対称なドームを考え、頂上から面に沿って測った距離を $r$、頂上から下向きに測った高さの差を $h(r)$、重力加速度を $g > 0$ とします。形を決める定数 $a > 0$ を用いて、頂上付近で $h(r) := \frac{2a}{3g} r^{3/2}$ とします。$r$ と $h(r)$ は長さの次元をもつので、$a$ は長さの平方根を時間の2乗で割った次元をもちます。

質点が頂上から一つの方向に摩擦なく滑り、面に接している間を考えます。面に沿った重力加速度は $g h'(r) = a\sqrt{r}$ なので、運動方程式は $\ddot r = a\sqrt{r}$($r \ge 0$)です。右辺は、すべての $r > 0$ について $|a\sqrt{r} - a\sqrt{0}|/|r - 0| = a/\sqrt{r}$ で、$r \to 0$ でいくらでも大きくなるため、頂上にどれだけ近い範囲に限ってもリプシッツ連続ではありません。$r(0) = 0,\ \dot r(0) = 0$ で解くと、$r(t) = 0$ のほかに、動き出す時刻として任意の $T \ge 0$ を選んだ

$$
r(t) = \begin{cases} 0 & (t \le T) \\ \dfrac{a^2(t - T)^4}{144} & (t \ge T) \end{cases}
$$

も解になります。すべての $t > T$ について $\dot r(t) = a^2(t - T)^3/36$、$\ddot r(t) = a^2(t - T)^2/12 = a\sqrt{r(t)}$ で、$t = T$ でも位置・速度・加速度はすべて 0 でつながります。動き出した後をドーム上の運動とみなすのは、頂上付近で形状と接触が保たれる時間の範囲です。その短い時間だけでも、同じ初期条件から静止し続ける運動と動き出す運動の両方が許され、一意性が崩れます。これは、理想化されたモデルで決定論が破れる例(ノートンのドーム)です。
:::

::: review
- 極限を知らなくても、完備な空間では点列が収束するかどうかを判定できる(コーシー列)。
- 空間に穴があるかどうかを判定でき、それが距離の選び方で変わることを説明できる(完備性)。
- 逐次近似が収束するための十分条件を述べ、証明の三つの段階を説明できる(バナッハの不動点定理)。
- リプシッツ条件があれば微分方程式の解がただ一つに決まることを説明できる(ピカールの定理)。
:::

::: question
開区間 $(0, 1)$ 上の $T(x) = x/2$ は縮小写像ですか。不動点はありますか。
:::

::: answer
縮小率 $1/2$ の縮小写像です。しかし不動点の候補 0 は $(0, 1)$ の外にあり、不動点はありません。$(0, 1)$ が完備でないので、バナッハの不動点定理の仮定をみたしていません。
:::

::: question
$\mathbb{R}$ 上の $T(x) = x + 1$ は縮小写像ですか。
:::

::: answer
いいえ。$|T(x) - T(y)| = |x - y|$ なので距離はまったく縮まず、縮小率を 1 未満にとれません。実際、不動点はありません。
:::

::: question
ピカールの議論で $Lh < 1$ となるように $h$ をとったのはなぜですか。
:::

::: answer
縮小率 $k = Lh$ を 1 未満にして、$T$ を縮小写像にするためです。$h$ を大きくとると、この評価では縮小性が保証されません。
:::
