::: goal
関数の全体をベクトル空間として扱い、そこに長さ(ノルム)と角度(内積)を入れて、距離が決まる仕組みを説明できるようになる。
:::

::: goal {field=physics}
波動関数を規格化するときと、固有関数で展開して確率を求めるときに、ノルムと内積のどの性質を使っているかを説明できるようになります。
:::

::: goal {field=cs}
重みの大きさをノルムで測る正則化と、文書の近さを角度で測るコサイン類似度が、ノルムと内積のどの性質に支えられているかを説明できるようになります。
:::

::: motivation
平面のベクトルには長さと角度があります。直交座標の成分で $x = (x_1, x_2)$ と表すと、長さは $\sqrt{x_1^2 + x_2^2}$ で、二つのベクトル $x, y$ が直交するのは $x_1 y_1 + x_2 y_2 = 0$ のときです。

関数にも同じことを考えられないでしょうか。区間 $[-\pi, \pi]$ 上の $\sin t$ と $\cos t$ について、各点 $t$ での値を座標とみなし、座標ごとの積の和の代わりに、積の積分をとってみると

$$
\int_{-\pi}^{\pi} \sin t \cos t\,dt = 0
$$

になります。この意味で、$\sin$ と $\cos$ は「直交」していると言えます。フーリエ級数(関数を、定数と $\cos nt$、$\sin nt$ の実数倍の和で表したもの)の係数を積分で取り出せるのは、定数関数 1 と $\cos nt$、$\sin nt$($n = 1, 2, \dots$)が、この意味で互いに直交しているおかげです。
:::

::: motivation {field=physics}
量子力学では、波動関数 $\psi$ を $\int |\psi(x)|^2\,dx = 1$ となるように定数倍してから使います(規格化)。測定でどの結果が出るかの確率は、$\psi$ と固有関数を掛けて積分した「重なり」から計算します(複素数の値なら一方の複素共役をとります)。前者は関数の長さに、後者は関数どうしの角度に関わる量です。
:::

::: motivation {field=cs}
機械学習では、モデルの重みが大きくなりすぎないように、重みベクトルの大きさに応じた罰則を損失に加えることがあります(正則化)。文書検索では、単語の出現回数を並べたベクトルどうしの角度で、二つの文書の近さを測る方法があります。前者はベクトルの長さを、後者はベクトルどうしの角度を使っています。
:::

この章では、まず連続関数の全体なども平面のベクトルと同じ規則で足し算と実数倍ができること、つまりベクトル空間になることを確かめます([[@vector-space]])。次に、足し算と実数倍に合った長さ(ノルム)を入れ、ノルムから距離が決まることを示します([[@normed-space]])。最後に角度を測る内積を入れ、内積から長さが決まることを示します([[@inner-product]])。[[@metric-space]] で後回しにした、直線距離 $d_2$ の三角不等式もここで証明します。

## ベクトル空間 {#vector-space requires=reading-proofs,sets-maps}

::: summary
足し算と実数倍で組み合わせを作ることができ、その計算が平面のベクトルと同じ規則に従う集合。
:::

::: why
[[@convergence-metric]] からここまでの距離空間で扱ってきたのは、2点がどれだけ離れているかと、そこから決まる収束や完備性でした。一方、平面のベクトルには、ほかのベクトルを実数倍して足し合わせたもの(線形結合、linear combination)として、新しいベクトルを作るという使い方があります。どのベクトル $x = (x_1, x_2)$ も $x = x_1 (1, 0) + x_2 (0, 1)$ と書け、座標はこの組み合わせの係数です。関数にも同じ使い方があります。出発点で触れたフーリエ級数も、関数を定数と $\cos nt$、$\sin nt$ の線形結合で表すものです(無限個の項の和をどう考えるかは [[@hilbert-space]] で扱います)。考えている集合の中で足し算と実数倍ができ、平面のベクトルと同じ規則で計算できれば、こうした組み合わせを数の計算と同じように扱えます。この共通の規則を取り出したものが、ベクトル空間の定義です。足し算と実数倍の規則だけを使う議論なら、数の組にも関数にも共通して使えます。
:::

::: definition {name="ベクトル空間" en="vector space" aliases="線形空間"}
集合 $V$ に、二つの元 $x, y \in V$ から元 $x + y \in V$ を作る足し算と、実数 $\alpha$ と元 $x \in V$ から元 $\alpha x \in V$ を作る実数倍が定まっていて、次の 1〜8 が成り立つとき、$V$ を(実数を係数とする)ベクトル空間、または線形空間 (linear space) といい、$V$ の元をベクトル (vector) と呼ぶ。1、2、5〜8 は、すべての $x, y, z \in V$ とすべての実数 $\alpha, \beta$ について成り立つものとする。

1. $(x + y) + z = x + (y + z)$(足し算の結合法則)
2. $x + y = y + x$(交換法則)
3. $\exists 0 \in V\ \forall x \in V: x + 0 = x$(零ベクトルの存在)
4. 3 の $0$ について、$\forall x \in V\ \exists y \in V: x + y = 0$(逆ベクトルの存在)
5. $\alpha (x + y) = \alpha x + \alpha y$(ベクトルの和への分配法則)
6. $(\alpha + \beta) x = \alpha x + \beta x$(実数の和への分配法則)
7. $(\alpha \beta) x = \alpha (\beta x)$(実数倍の結合法則)
8. $1 x = x$(1 倍)
:::

1〜4 は、足し算が実数の足し算と同じ規則に従うことを言っています。3 の $0$ を零ベクトル (zero vector) と呼びます。5〜7 は、実数倍がベクトルの足し算、実数の足し算、実数の掛け算と両立することを言っています。8 は、1 倍がベクトルを変えないことです。8 がないと、どのベクトルも 0 に送る「実数倍」でも 5〜7 をみたしてしまいます(下の「仮定を外すと」)。

::: theorem {#zero-inverse name="零ベクトルと逆ベクトル"}
$V$ をベクトル空間とする。

1. 零ベクトルはただ一つである。
2. 各 $x \in V$ について、$x + y = 0$ となる $y \in V$ はただ一つである。これを $x$ の逆ベクトルと呼び、$-x$ と書く。
3. すべての $x \in V$ について $0 x = 0$ である(左辺の $0$ は実数、右辺の $0$ は零ベクトル)。
4. すべての $x \in V$ について $(-1) x = -x$ である。
:::

::: proof-sketch
1. 零ベクトルが $0$ と $0'$ の二つあれば、$0 = 0 + 0' = 0' + 0 = 0'$(零ベクトルの存在と交換法則を使う)。
2. $x + y = 0$ と $x + y' = 0$ なら、$y = y + (x + y')$ と書いて組み替えると $y = y'$(零ベクトルの存在、足し算の結合法則、交換法則を使う)。
3. $0 x = (0 + 0) x = 0 x + 0 x$ の両辺に $-(0 x)$ を足すと $0 = 0 x$(分配法則 6、逆ベクトルの存在、足し算の結合法則、零ベクトルの存在を使う)。
4. $x + (-1) x = 1 x + (-1) x = (1 + (-1)) x = 0 x = 0$ なので、2 から $(-1) x = -x$(8、分配法則 6、3、2 を使う)。
:::

::: proof
**1.** $0$ と $0'$ がどちらも規則 3 をみたすとします。$0'$ が零ベクトルなので $0 + 0' = 0$、$0$ が零ベクトルなので $0' + 0 = 0'$ です。交換法則から $0 + 0' = 0' + 0$ なので、$0 = 0'$ です。

**2.** $x + y = 0$ と $x + y' = 0$ をみたす $y, y'$ があるとします。零ベクトルの存在、足し算の結合法則、交換法則を使うと

$$
y = y + 0 = y + (x + y') = (y + x) + y' = (x + y) + y' = 0 + y' = y' + 0 = y'
$$

です。規則 4 から $y$ は少なくとも一つあるので、ちょうど一つです。

**3.** 実数の $0 = 0 + 0$ と分配法則 6 から $0 x = (0 + 0) x = 0 x + 0 x$ です。両辺に $-(0 x)$ を足すと、左辺は $0 x + (-(0 x)) = 0$ です。右辺は、足し算の結合法則から

$$
(0 x + 0 x) + (-(0 x)) = 0 x + (0 x + (-(0 x))) = 0 x + 0 = 0 x
$$

なので、$0 = 0 x$ です。

**4.** 8、分配法則 6、3 を順に使うと

$$
x + (-1) x = 1 x + (-1) x = (1 + (-1)) x = 0 x = 0
$$

です。2 から $x + y = 0$ となる $y$ はただ一つなので、$(-1) x = -x$ です。
:::

以下、$x + (-y)$ を $x - y$ と書きます。

::: examples
**数の組。** $\mathbb{R}^m$ は、成分ごとの足し算 $(x_1, \dots, x_m) + (y_1, \dots, y_m) := (x_1 + y_1, \dots, x_m + y_m)$ と、成分ごとの実数倍 $\alpha (x_1, \dots, x_m) := (\alpha x_1, \dots, \alpha x_m)$ でベクトル空間になります。八つの規則は、成分ごとに見れば実数の計算規則そのものです。零ベクトルは $(0, \dots, 0)$、逆ベクトルは $-x = (-x_1, \dots, -x_m)$ です。

**関数。** 区間 $[a, b]$ 上の連続関数の全体 $C[a, b]$ は、各点ごとの足し算 $(f + g)(t) := f(t) + g(t)$ と実数倍 $(\alpha f)(t) := \alpha f(t)$ でベクトル空間になります。連続関数の和と実数倍はまた連続なので、この足し算と実数倍は $C[a, b]$ の中で閉じています。八つの規則は、各点 $t$ で見れば実数の計算規則です。零ベクトルは恒等的に 0 の関数、$-f$ は $(-f)(t) = -f(t)$ で決まる関数です。$[a, b]$ 上の多項式の全体も、同じ足し算と実数倍でベクトル空間です。

**ベクトル空間でない例。** 平面の上半分 $H := \{x \in \mathbb{R}^2 \mid x_2 \ge 0\}$ では、$H$ の2点を足しても $H$ の外に出ません。しかし $(0, 1) \in H$ の $(-1)$ 倍の $(0, -1)$ は $H$ の外にあり、実数倍で $H$ の外に出てしまうので、$H$ はベクトル空間ではありません。また、$[0, 1]$ 上の連続関数で $f(0) = 1$ をみたすものの全体は、$f, g$ がこの条件をみたしても $(f + g)(0) = 2$ となるので、足し算で外に出てしまい、ベクトル空間ではありません。条件を $f(0) = 0$ に変えると、足し算でも実数倍でも外に出ないので、ベクトル空間になります。
:::

::: pitfall
**ベクトルは矢印とは限らない。** 高校では、ベクトルを向きと大きさをもつ矢印として習います。この駅の意味では、八つの規則をみたす集合の元なら何でもベクトルで、関数もベクトルです。長さと角度はベクトル空間の定義に含まれていないので、長さは [[@normed-space]]、角度は [[@inner-product]] で別に入れます。

**零ベクトルの記号。** 零ベクトルも、実数の 0 と同じ記号 $0$ で書きます。[[@zero-inverse]] の $0 x = 0$ は、左辺の $0$ が実数、右辺の $0$ が零ベクトルです。$C[a, b]$ の零ベクトルは恒等的に 0 の関数で、数の 0 ではありません。

**実数倍と複素数倍。** この章のベクトル空間の定義では、掛ける数を実数に限っています。定義の実数を複素数に替えたものを複素ベクトル空間 (complex vector space) と呼び、量子力学の波動関数はこちらで扱います。複素数の値をとる関数の全体も、足し算と実数倍で閉じているので、この章の意味のベクトル空間でもあります。
:::

::: drop-assumption
**1 倍の規則 8 を外す。** $\mathbb{R}^2$ に、ふつうの成分ごとの足し算と、どんな実数 $\alpha$ とどんな $x$ についても $\alpha x := 0$ とする「実数倍」を入れます。足し算はふつうのものなので 1〜4 は成り立ち、5〜7 は両辺がどちらも $0$ になるので成り立ちます。しかし $x = (1, 0)$ では $1 x = 0 \ne x$ で、8 が成り立ちません。このとき $(-1) x = 0$ ですが、逆ベクトルは $-x = (-1, 0)$ なので、[[@zero-inverse]] の 4 が成り立ちません。
:::

::: application {field=physics title="重ね合わせの原理"}
実数全体で2回微分できる実数値関数のうち、調和振動子の運動方程式 $\ddot{x} + \omega^2 x = 0$($\omega > 0$ は角振動数)をみたすものの全体を $S$ とします。$x_1, x_2 \in S$ と実数 $\alpha, \beta$ について、微分は足し算と実数倍を保つので

$$
\frac{d^2}{dt^2}(\alpha x_1 + \beta x_2) + \omega^2 (\alpha x_1 + \beta x_2) = \alpha (\ddot{x}_1 + \omega^2 x_1) + \beta (\ddot{x}_2 + \omega^2 x_2) = 0
$$

となり、$\alpha x_1 + \beta x_2$ もまた解です。$S$ は、関数の各点ごとの足し算と実数倍で閉じていて、規則は各点で実数の計算規則なので、ベクトル空間です。解を組み合わせたものがまた解になることを、重ね合わせの原理 (superposition principle) と呼びます。

たとえば $\omega = 2$ なら、$\cos 2t$ と $\sin 2t$ はどちらも解なので、$x(t) = 3 \cos 2t + 4 \sin 2t$ も解です。実際、$\ddot{x} = -12 \cos 2t - 16 \sin 2t = -4 x$ です。この解は、$\cos \theta = 3/5$、$\sin \theta = 4/5$ となる $\theta$ を使って $x(t) = 5 \cos(2t - \theta)$ と書け、振幅は 5 です。

外力のかかった方程式 $\ddot{x} + \omega^2 x = 1$ の解の全体は、ベクトル空間ではありません。二つの解を足すと $\ddot{x} + \omega^2 x = 2$ の解になり、零ベクトル(恒等的に 0 の関数)も解ではないからです。量子力学のシュレーディンガー方程式も波動関数について線形なので、解を複素数倍して足したものがまた解になります。
:::

## ノルム空間 {#normed-space requires=completeness,vector-space}

::: summary
ベクトルの「長さ」を測る関数(ノルム)を備えたベクトル空間。
:::

::: why
[[ベクトル空間]]の定義には足し算と実数倍が含まれていますが、長さや距離は含まれていません。逆に、[[距離空間]]の定義は、2点の組に数を対応させるだけで、足し算や実数倍を前提にしていません。しかし、関数の空間で使ってきた $d_\infty$ や $d_1$ は、足し算や実数倍とかみ合っています。たとえば sup 距離 $d_\infty$ では、$f$ と $g$ の両方に同じ関数 $h$ を足しても距離は変わらず、両方を 2 倍すると距離も 2 倍になります。こうした性質は、どの距離にもあるわけではありません(たとえば実数全体の離散距離では、$x \ne y$ なら $d(2x, 2y) = 1 = d(x, y)$ で、2 倍になりません)。足し算と実数倍に合った距離を作るには、まず一つのベクトルの「長さ」を決め、2点の距離をその差の長さとすればよいのです。
:::

::: definition {name="ノルム" en="norm" aliases="ノルム空間"}
$V$ を[[ベクトル空間]]とする。関数 $\|\cdot\|: V \to \mathbb{R}$ がノルムであるとは、すべての $x, y \in V$ とすべての実数 $\alpha$ について次が成り立つことをいう。組 $(V, \|\cdot\|)$ をノルム空間 (normed space) と呼ぶ。

1. $\|x\| \ge 0$ であり、$\|x\| = 0 \iff x = 0$(正値性)
2. $\|\alpha x\| = |\alpha|\,\|x\|$(斉次性)
3. $\|x + y\| \le \|x\| + \|y\|$(三角不等式)
:::

ノルム $\|x\|$ は、ベクトル $x$ の長さを表す数です。正値性は、長さ 0 のベクトルが零ベクトルだけであること、斉次性は、ベクトルを $\alpha$ 倍すると長さが $|\alpha|$ 倍になること、三角不等式は、二つのベクトルの和の長さが、それぞれの長さの和を超えないことです。平面のベクトルを矢印で描くと、三角不等式は、二つの矢印を続けてたどっても、まっすぐ進むより短くはならないことにあたります。

::: theorem {#norm-metric name="ノルムから決まる距離"}
$(V, \|\cdot\|)$ をノルム空間とし、$d(x, y) := \|x - y\|$ と定める。このとき $(V, d)$ は[[距離空間]]である。さらに、すべての $x, y, z \in V$ とすべての実数 $\alpha$ について、次が成り立つ。

$$
\begin{aligned}
d(x + z, y + z) &= d(x, y) \\
d(\alpha x, \alpha y) &= |\alpha|\, d(x, y)
\end{aligned}
$$
:::

::: proof-sketch
1. $d(x, y) = \|x - y\|$ は 0 以上で、0 になるのは $x - y = 0$、つまり $x = y$ のときだけ(ノルムの正値性を使う)。
2. $x - y = (-1)(y - x)$ なので $d(x, y) = d(y, x)$(ベクトル空間の規則と [[@zero-inverse]]、斉次性を $\alpha = -1$ で使う)。
3. $x - z = (x - y) + (y - z)$ と分けて、$d(x, z) \le d(x, y) + d(y, z)$(ノルムの三角不等式を使う)。
4. 両方に $z$ を足しても差 $x - y$ は変わらず、両方を $\alpha$ 倍すると差も $\alpha$ 倍になる(斉次性を使う)。
:::

::: proof
**1.** ノルムの正値性から $d(x, y) = \|x - y\| \ge 0$ で、$d(x, y) = 0 \iff x - y = 0 \iff x = y$ です。

**2.** 分配法則 5 と [[@zero-inverse]] の 4 から、$(-1)(y - x) = (-1) y + (-1)(-x) = -y + x = x - y$ です。2番目の等号の $(-1)(-x) = x$ は、$(-x) + x = 0$ と [[@zero-inverse]] の 2(逆ベクトルはただ一つ)から $-(-x) = x$ となることを使っています。3番目の等号は、交換法則と $x - y$ の書き方によります。斉次性を $\alpha = -1$ で使うと、$d(x, y) = \|(-1)(y - x)\| = |-1|\,\|y - x\| = d(y, x)$ です。

**3.** ノルムの三角不等式から

$$
d(x, z) = \|(x - y) + (y - z)\| \le \|x - y\| + \|y - z\| = d(x, y) + d(y, z).
$$

1〜3 から、$d$ は距離です。

**4.** $(x + z) - (y + z) = x - y$ なので $d(x + z, y + z) = d(x, y)$ です。また $\alpha x - \alpha y = \alpha(x - y)$(分配法則 5、実数倍の結合法則 7、[[@zero-inverse]] の 4 から)と斉次性から、$d(\alpha x, \alpha y) = |\alpha|\,\|x - y\| = |\alpha|\, d(x, y)$ です。
:::

以下、ノルム空間は、この距離で距離空間とみなします。点列の収束も[[completeness|完備性]]も、この距離で考えます。

::: examples
**$\mathbb{R}^m$ のノルム。** $x = (x_1, \dots, x_m)$ について

$$
\|x\|_2 = \sqrt{\sum_{i=1}^{m} x_i^2}, \qquad \|x\|_1 = \sum_{i=1}^{m} |x_i|, \qquad \|x\|_\infty = \max_{i} |x_i|
$$

はどれもノルムで、ここから決まる距離が [[@metric-space]] の $d_2$、$d_1$、$d_\infty$ です。$\|\cdot\|_1$ と $\|\cdot\|_\infty$ の三角不等式は、座標ごとの三角不等式 $|x_i + y_i| \le |x_i| + |y_i|$ を足し合わせる(または最大をとる)と分かります。$\|\cdot\|_2$ の三角不等式は [[@inner-product]] で示します。

**関数のノルム。** 区間 $[a, b]$ 上の連続関数の全体 $C[a, b]$ には、たとえば次のノルムが入ります。

$$
\|f\|_\infty = \max_{t \in [a, b]} |f(t)|, \qquad \|f\|_1 = \int_a^b |f(t)|\,dt, \qquad \|f\|_2 = \sqrt{\int_a^b |f(t)|^2\,dt}
$$

前の二つから決まる距離が、[[@completeness]] で比べた $d_\infty$ と $d_1$ です。$\|f\|_1 = 0$ なら $f$ が恒等的に 0 になるのは、$f$ が連続だからです。ある点で $f(t_0) \ne 0$ なら、その近くでも $|f|$ は正の値をとるので、積分が正になります。$\|\cdot\|_2$ の三角不等式は、内積から決まるノルムであることから示します([[@inner-product]])。

**ノルムでない例。** $\mathbb{R}^2$ の $p(x) := |x_1|$ は斉次性と三角不等式をみたしますが、$(0, 1) \ne 0$ なのに $p((0, 1)) = 0$ なので、正値性をみたさず、ノルムではありません。このように正値性の後半だけを欠くものを、半ノルム (seminorm) と呼びます。[[@metric-space]] の「仮定を外すと」で見た $d(f, g) = |f(0) - g(0)|$ は、$[0, 1]$ 上の関数の半ノルム $p(f) = |f(0)|$ から、同じ作り方で決まる「距離」です。
:::

完備なノルム空間には、名前が付いています。

::: definition {#banach-space name="バナッハ空間" en="Banach space"}
ノルム空間 $(V, \|\cdot\|)$ が、ノルムから決まる距離 $d(x, y) = \|x - y\|$ について[[completeness|完備]]であるとき、$V$ をバナッハ空間という。
:::

::: examples
- バナッハ空間である例:$\mathbb{R}^m$($\|\cdot\|_1$、$\|\cdot\|_2$、$\|\cdot\|_\infty$ のどれでも)と、$\|\cdot\|_\infty$ を入れた $C[a, b]$。$\mathbb{R}^m$ でノルムによらないのは、[[@metric-space]] の不等式 $d_\infty \le d_2 \le d_1 \le m\, d_\infty$ から、どのノルムで測ってもコーシー列と収束する列が同じだからです。$C[a, b]$ の完備性は、[[@completeness]] で見たとおり、連続関数の一様収束極限がまた連続であることから来ます。
- バナッハ空間でない例:$\|\cdot\|_1$ を入れた $C[-1, 1]$([[@completeness]] の例)。
- $[0, 1]$ 上の多項式の全体 $P$ に $\|\cdot\|_\infty$ を入れた空間も、バナッハ空間ではありません。$e^t$ のテイラー展開の部分和 $s_n(t) = \sum_{k=0}^{n} t^k / k!$ は多項式で、テイラーの定理から $\|e^t - s_n\|_\infty \le e / (n + 1)!$ なので、$C[0, 1]$ の中で $e^t$ に収束します。収束する列はコーシー列なので、$(s_n)$ は $P$ のコーシー列です。もし $(s_n)$ が多項式 $p$ に収束するなら、極限はただ一つなので([[@metric-space]])$p = e^t$ となるはずですが、多項式は何回か微分すると 0 になるのに、$e^t$ は何回微分しても $e^t$ のままです。$(s_n)$ は $P$ のどの点にも収束しません。
:::

::: pitfall
**「L0 ノルム」。** ベクトル $x$ の 0 でない成分の個数を $\|x\|_0$ と書きます。機械学習や信号処理では、この個数を「L0 ノルム」と呼ぶことがありますが、ノルムではありません。$x \ne 0$ なら $\|2x\|_0 = \|x\|_0 > 0$ で、斉次性が要求する $2\|x\|_0$ と一致しないからです。

**ノルムを変えると、収束の意味が変わる。** $\mathbb{R}^m$ では、$\|\cdot\|_1$、$\|\cdot\|_2$、$\|\cdot\|_\infty$ のどれで測っても収束する列は同じです。実は、$\mathbb{R}^m$ に入るノルムなら、どれを選んでも収束する列は変わりません(有限次元のノルムの同値性と呼ばれる定理で、ここでは証明しません)。関数の空間ではそうはいきません。[[@metric-space]] の落とし穴で見た $[0, 1]$ 上の $f_n(t) = t^n$ は、$\|f_n\|_1 = 1/(n + 1) \to 0$ ですが、$\|f_n\|_\infty = 1$ です。関数の空間では、どのノルムで測るかまで決めて、はじめて「収束する」の意味が決まります。
:::

::: drop-assumption
**ノルムの三角不等式を外す。** $\mathbb{R}^2$ で

$$
p(x) := \left(\sqrt{|x_1|} + \sqrt{|x_2|}\right)^2
$$

と定めます。$p$ は正値性と斉次性をみたします($p(\alpha x) = |\alpha|\, p(x)$)。しかし $x = (1, 0)$、$y = (0, 1)$ では $p(x + y) = 4 > 2 = p(x) + p(y)$ で、三角不等式をみたしません。$d(x, y) := p(x - y)$ とすると $d(0, x + y) = 4$ ですが、$x$ を経由すると $d(0, x) + d(x, x + y) = p(x) + p(y) = 2$ で、寄り道したほうが近くなってしまいます。$d$ は距離ではありません。$p(x) \le 1$ となる点の集合は、$(1, 0)$ と $(0, 1)$ を含むのに、その中点 $(1/2, 1/2)$($p = 2$)を含まない、へこんだ形をしています。

**正値性を外す。** 上の半ノルム $p(x) = |x_1|$ から作った $d(x, y) = |x_1 - y_1|$ は、$x \ne y$ でも 0 になりえます。[[@metric-space]] の「仮定を外すと」で見たとおり、こうなると極限がただ一つに決まりません。
:::

::: application {field=physics title="波動関数の規格化"}
1次元の量子力学では、絶対値の2乗を積分した値が有限な関数 $\psi$ を扱います。この章では簡単のため、$\psi$ を連続関数に限り、ノルム

$$
\|\psi\|_2 = \sqrt{\int_{-\infty}^{\infty} |\psi(x)|^2\,dx}
$$

を入れて考えます。波動関数は複素数の値をとってもかまいません。この章のノルムの定義は実数倍について述べたものですが、複素数の値をとる関数どうしも足し算と実数倍ができるので、そのまま当てはまります。規格化で掛けるのも実数 $1/\|\psi\|_2$ です。確率として解釈できるように、波動関数は $\|\psi\|_2 = 1$ となるように選びます(規格化、normalization)。$\psi \ne 0$ なら正値性から $\|\psi\|_2 > 0$ で、斉次性から

$$
\left\| \frac{\psi}{\|\psi\|_2} \right\|_2 = \frac{1}{\|\psi\|_2}\, \|\psi\|_2 = 1
$$

なので、ノルムで割れば必ず規格化できます。

たとえば調和振動子の基底状態の形 $\psi(x) = e^{-x^2/(2a^2)}$($a > 0$ は長さの定数)では、ガウス積分 $\int_{-\infty}^{\infty} e^{-x^2/a^2}\,dx = a\sqrt{\pi}$ から $\|\psi\|_2 = \pi^{1/4} \sqrt{a}$ です。規格化した波動関数は

$$
\frac{\psi(x)}{\|\psi\|_2} = \frac{1}{\pi^{1/4} \sqrt{a}}\, e^{-x^2/(2a^2)}
$$

で、$a = 1$ なら係数は $\pi^{-1/4} \approx 0.751$ です。規格化で使ったのはノルムの正値性と斉次性だけで、三角不等式は使っていません。
:::

::: application {field=cs title="正則化と重みのノルム"}
線形回帰で重み $w \in \mathbb{R}^m$ を学習するとき、誤差の2乗和に、重みの大きさに応じた罰則を足して最小化することがあります(正則化、regularization)。罰則に $\lambda \|w\|_2^2$ を使うものをリッジ回帰 (ridge regression)、$\lambda \|w\|_1$ を使うものをラッソ (lasso) と呼びます($\lambda > 0$ は罰則の強さ)。

同じ重みでも、ノルムによって大きさの測り方が違います。$w = (3, -4)$ なら $\|w\|_1 = 7$、$\|w\|_2 = 5$、$\|w\|_\infty = 4$ です。$m = 2$ なら、$\|w\|_1 \le 1$ となる点の集合は座標軸の上に角をもつひし形で、ラッソの解はこの角、つまりいくつかの成分がちょうど 0 になる点に来やすいことが知られています。

罰則がノルム(リッジ回帰ではその2乗)であることは、目的関数が凸になることにも効いています。三角不等式と斉次性から、$0 \le t \le 1$ について

$$
\|t w + (1 - t) v\| \le \|t w\| + \|(1 - t) v\| = t \|w\| + (1 - t) \|v\|
$$

が成り立つので、ノルムは凸関数です。リッジ回帰の罰則 $\|w\|_2^2$ はノルムの2乗ですが、これも凸です。上の不等式の両辺は 0 以上なので2乗でき、さらに $s \mapsto s^2$ が凸であることから、$\|t w + (1 - t) v\|^2 \le \bigl(t \|w\| + (1 - t) \|v\|\bigr)^2 \le t \|w\|^2 + (1 - t) \|v\|^2$ となるからです。誤差の2乗和も、$w$ の1次式の2乗の和なので凸です。凸関数の和は凸なので、罰則を足した目的関数も凸になり、局所的な最小値はどれも全体の最小値です。落とし穴の「L0 ノルム」は凸ではないので(たとえば1次元では、$0$ と $1$ の中点 $1/2$ での値 $1$ が、両端の値の平均 $1/2$ を超えます)、罰則に使うと目的関数も凸になるとは限らず、局所的な最小値が全体の最小値であるという保証がなくなります。
:::

## 内積空間 {#inner-product requires=normed-space}

::: summary
ベクトルどうしの「角度」を測る内積を備え、そこから長さも決まるベクトル空間。
:::

::: why
ノルムの定義に含まれているのは長さだけで、二つのベクトルがどれだけ同じ向きを向いているかを測るものは含まれていません。出発点の $\sin$ と $\cos$ のように「直交する」を扱うには、平面の $x_1 y_1 + x_2 y_2$ にあたるものが要ります。平面ではこの量から長さ $\sqrt{x_1^2 + x_2^2}$ も決まります。この量の性質だけを取り出して定義にすれば、関数の空間でも角度と長さを同時に扱えます。
:::

::: definition {name="内積" en="inner product" aliases="内積空間"}
$V$ を[[ベクトル空間]]とする。関数 $\langle \cdot, \cdot \rangle: V \times V \to \mathbb{R}$ が内積であるとは、すべての $x, y, z \in V$ とすべての実数 $\alpha, \beta$ について次が成り立つことをいう。組 $(V, \langle \cdot, \cdot \rangle)$ を内積空間 (inner product space) と呼び、$\|x\| := \sqrt{\langle x, x \rangle}$ と書く。

1. $\langle x, x \rangle \ge 0$ であり、$\langle x, x \rangle = 0 \iff x = 0$(正値性)
2. $\langle x, y \rangle = \langle y, x \rangle$(対称性)
3. $\langle \alpha x + \beta y, z \rangle = \alpha \langle x, z \rangle + \beta \langle y, z \rangle$(線形性)
:::

::: definition {#orthogonal name="直交" en="orthogonal"}
内積空間の二つのベクトル $x, y$ が直交するとは、$\langle x, y \rangle = 0$ となることをいう。
:::

対称性と線形性から、内積は2番目の引数についても線形です。$\langle x, y \rangle$ は、$x$ と $y$ の長さと、二つがどれだけ同じ向きを向いているかを、一つの数にまとめたものです。下の [[@cauchy-schwarz]] により $|\langle x, y \rangle| \le \|x\|\,\|y\|$ なので、$x, y \ne 0$ なら

$$
\cos \theta := \frac{\langle x, y \rangle}{\|x\|\,\|y\|}
$$

は $-1$ 以上 $1$ 以下で、$0 \le \theta \le \pi$ の範囲の $\theta$ がちょうど一つ決まります。これを $x$ と $y$ のなす角と呼びます。

::: examples
- $\mathbb{R}^m$ の $\langle x, y \rangle = \sum_{i=1}^{m} x_i y_i$ は内積で(標準内積、ドット積 (dot product) とも呼ぶ)、決まるノルムは $\|\cdot\|_2$ です。
- $C[a, b]$ の $\langle f, g \rangle = \int_a^b f(t) g(t)\,dt$ は内積で、決まるノルムは $\|\cdot\|_2$ です。正値性で「$\langle f, f \rangle = 0$ なら $f = 0$」と言えるのは、[[@normed-space]] の $\|\cdot\|_1$ と同じく、$f$ が連続だからです。出発点の $\sin$ と $\cos$ は、$C[-\pi, \pi]$ のこの内積について直交しています。
- $\mathbb{R}^2$ の $\langle x, y \rangle = x_1 y_1 + 2 x_2 y_2$ も内積です。同じ空間に入る内積は一つではありません。
:::

::: theorem {#cauchy-schwarz name="コーシー=シュワルツの不等式"}
内積空間のすべての $x, y$ について、次が成り立つ。

$$
|\langle x, y \rangle| \le \|x\|\,\|y\|
$$

等号が成り立つのは、$x$ と $y$ の一方が他方の実数倍のときに限る。
:::

::: proof-sketch
1. $y = 0$ なら両辺とも 0。$y \ne 0$ のときは、実数 $t$ について $\langle x - t y, x - t y \rangle \ge 0$ から出発する(内積の正値性を使う)。
2. 左辺を展開すると、$t$ の2次式 $\|x\|^2 - 2t \langle x, y \rangle + t^2 \|y\|^2$ になる(対称性と線形性を使う)。
3. この2次式を最小にする $t = \langle x, y \rangle / \|y\|^2$ を代入すると、$\langle x, y \rangle^2 \le \|x\|^2 \|y\|^2$ が出る(1 の不等式を使う)。
4. 等号が成り立つのは $\langle x - t y, x - t y \rangle = 0$、つまり $x = t y$ のときに限る(正値性を使う)。
:::

::: proof
$y = 0$ のとき、対称性、[[@zero-inverse]] の 3($0 = 0 \cdot x$)、線形性から $\langle x, 0 \rangle = \langle 0, x \rangle = \langle 0 \cdot x, x \rangle = 0 \cdot \langle x, x \rangle = 0$ で、$\|y\| = 0$ なので両辺とも 0 です。このとき $y = 0 \cdot x$ なので、等号の条件にも合っています。

$y \ne 0$ とします。正値性から $\|y\|^2 > 0$ です。どの実数 $t$ についても、対称性と線形性で展開して

$$
0 \le \langle x - t y, x - t y \rangle = \|x\|^2 - 2t \langle x, y \rangle + t^2 \|y\|^2.
$$

$t = \langle x, y \rangle / \|y\|^2$ を代入すると

$$
0 \le \|x\|^2 - \frac{\langle x, y \rangle^2}{\|y\|^2}
$$

となり、両辺に $\|y\|^2$ を掛けて平方根をとると $|\langle x, y \rangle| \le \|x\|\,\|y\|$ です。

等号が成り立つのは、この $t$ で $\langle x - t y, x - t y \rangle = 0$ となるとき、つまり正値性から $x = t y$ のときです。逆に $x = s y$ なら $\langle x, y \rangle = s \|y\|^2$、$\|x\| = |s|\,\|y\|$ なので、両辺とも $|s|\,\|y\|^2$ で等号が成り立ちます。$y$ が $x$ の実数倍 $r x$ で $y \ne 0$ のときは、$r \ne 0$ なので $x = (1/r) y$ となり、この場合に含まれます。
:::

::: theorem {#inner-product-norm name="内積から決まるノルム"}
内積空間 $(V, \langle \cdot, \cdot \rangle)$ で $\|x\| := \sqrt{\langle x, x \rangle}$ と定めると、$\|\cdot\|$ は $V$ の[[ノルム]]である。
:::

::: proof-sketch
1. $\|x\| \ge 0$ で、0 になるのは $x = 0$ のときだけ(内積の正値性を使う)。
2. $\langle \alpha x, \alpha x \rangle = \alpha^2 \langle x, x \rangle$ から $\|\alpha x\| = |\alpha|\,\|x\|$(線形性と対称性を使う)。
3. $\|x + y\|^2$ を展開し、真ん中の項 $2\langle x, y \rangle$ を $2\|x\|\,\|y\|$ で上から抑えると、$\|x + y\|^2 \le (\|x\| + \|y\|)^2$(コーシー=シュワルツの不等式を使う)。
:::

::: proof
**1.** 内積の正値性から $\langle x, x \rangle \ge 0$ なので平方根がとれて $\|x\| \ge 0$ です。$\|x\| = 0 \iff \langle x, x \rangle = 0 \iff x = 0$ です。

**2.** 線形性と対称性から $\langle \alpha x, \alpha x \rangle = \alpha \langle x, \alpha x \rangle = \alpha \langle \alpha x, x \rangle = \alpha^2 \langle x, x \rangle$ なので、$\|\alpha x\| = \sqrt{\alpha^2}\,\|x\| = |\alpha|\,\|x\|$ です。

**3.** 対称性と線形性で展開し、[[@cauchy-schwarz]] を使うと

$$
\|x + y\|^2 = \|x\|^2 + 2 \langle x, y \rangle + \|y\|^2 \le \|x\|^2 + 2 \|x\|\,\|y\| + \|y\|^2 = (\|x\| + \|y\|)^2.
$$

両辺は 0 以上なので、平方根をとって $\|x + y\| \le \|x\| + \|y\|$ です。
:::

[[@metric-space]] で後回しにした $d_2$ の三角不等式は、これで示せます。$\mathbb{R}^m$ の標準内積から決まるノルムは $\|\cdot\|_2$ なので、[[@inner-product-norm]] から $\|\cdot\|_2$ はノルムで、[[@norm-metric]] から $d_2(x, y) = \|x - y\|_2$ は三角不等式をみたす距離です。同じ理由で、$C[a, b]$ の $\|\cdot\|_2$ もノルムです。

内積から決まるノルムは、$\|x + y\|^2$ と $\|x - y\|^2$ を展開して足すだけで、次の等式をみたします。これを平行四辺形の法則(中線定理、parallelogram law)と呼びます。

$$
\|x + y\|^2 + \|x - y\|^2 = 2\|x\|^2 + 2\|y\|^2
$$

::: examples
平行四辺形の法則をみたさないノルムは、どんな内積からも決まりません。$\mathbb{R}^2$ の $\|\cdot\|_\infty$ で $x = (1, 0)$、$y = (0, 1)$ とすると、$\|x + y\|_\infty = \|x - y\|_\infty = 1$ なので、左辺は 2、右辺は 4 です。したがって $\|\cdot\|_\infty$ は内積から決まるノルムではありません。$\|\cdot\|_2$ では、左辺も右辺も 4 になります。
:::

::: drop-assumption
**正値性を外す。** $\mathbb{R}^2$ で $\langle x, y \rangle_M := x_1 y_1 - x_2 y_2$ と定めると、対称性と線形性はみたしますが、$\langle (0, 1), (0, 1) \rangle_M = -1 < 0$ なので、正値性をみたしません。$x = (1, 0)$、$y = (1, 1)$ では $\langle x, y \rangle_M = 1$、$\langle x, x \rangle_M = 1$、$\langle y, y \rangle_M = 0$ なので

$$
\langle x, y \rangle_M^2 = 1 > 0 = \langle x, x \rangle_M\, \langle y, y \rangle_M
$$

となり、コーシー=シュワルツの不等式(の両辺を2乗した形)が成り立ちません。$\langle y, y \rangle_M < 0$ となる $y$ もあるので、$\sqrt{\langle y, y \rangle_M}$ でノルムを作ることもできません。この形は、時間1次元・空間1次元の特殊相対論の時空(ミンコフスキー空間、Minkowski space)で、時間と空間の座標の組に使われます。
:::

::: pitfall
**複素数の内積と、線形な側。** 量子力学の波動関数は複素数の値をとるので、内積も複素数の値をとるものを使います。そのときは対称性を $\langle x, y \rangle = \overline{\langle y, x \rangle}$(複素共役)に変え、線形性は片方の引数についてだけ要求します。数学の本の多くは1番目の引数について線形とし、物理の本(ディラックのブラケット記法 $\langle \varphi | \psi \rangle$)は2番目の引数について線形とします。同じ記号でも、どちらの約束かを確かめてから計算してください。

**内積空間は完備とは限らない。** $C[-1, 1]$ に $\langle f, g \rangle = \int_{-1}^{1} f(t) g(t)\,dt$ を入れた内積空間は、完備ではありません。[[@completeness]] の列 $f_n(t) = \max(-1, \min(1, nt))$ は、$\|\cdot\|_1$ についてのコーシー列でした。[[@completeness]] で見たとおり差が 1 を超えないので $\|f_m - f_n\|_2^2 \le \|f_m - f_n\|_1$ となり、$\|\cdot\|_2$ についてもコーシー列です。近づく先は階段関数です。連続な行き先がないことは、$C[-1, 1]$ のどの $g$ についても、[[@cauchy-schwarz]] を $|g|$ と定数関数 1 に使うと $\|g\|_1 \le \sqrt{2}\,\|g\|_2$ となるので、$\|\cdot\|_2$ で連続関数に収束するなら $\|\cdot\|_1$ でも収束してしまい、[[@completeness]] の $d_1$ の結果に反することから分かります。完備な内積空間は [[@hilbert-space]] で扱います。
:::

::: application {field=physics title="固有関数による展開と確率"}
[[@completeness]] の理論物理の応用で見た、幅 $L$ の箱の中の粒子のエネルギー固有関数

$$
u_n(x) = \sqrt{\frac{2}{L}}\, \sin\frac{n\pi x}{L} \qquad (n = 1, 2, 3, \dots)
$$

を、内積の言葉で見直します。そこで見た積分の関係は、$C[0, L]$ の内積 $\langle f, g \rangle = \int_0^L f(x) g(x)\,dx$ を使うと、$\langle u_m, u_n \rangle$ が $m = n$ なら 1、$m \ne n$ なら 0 になる、ということです(互いに[[直交]]し、長さが 1)。状態 $\psi$ を $u_n$ で展開できるとすると、その係数は内積 $c_n = \langle u_n, \psi \rangle$ で取り出せ、エネルギーを測って $n$ 番目の値が出る確率は $|c_n|^2$ です。

たとえば規格化された $\psi(x) = \sqrt{30/L^5}\, x(L - x)$ では、部分積分を繰り返して

$$
c_n = \langle u_n, \psi \rangle = \begin{cases} \dfrac{8\sqrt{15}}{(n\pi)^3} & (n \text{ が奇数}) \\ 0 & (n \text{ が偶数}) \end{cases}
$$

となり、基底状態のエネルギーが出る確率は $|c_1|^2 = 960/\pi^6 \approx 0.9986$ です。$\psi$ の形が基底状態の $\sin$ の山とほとんど同じであることを、内積が数で表しています。

確率の和が 1 を超えないことは、内積の性質だけから言えます。最初の $N$ 項を引いた残り $r = \psi - \sum_{n=1}^{N} c_n u_n$ について、直交性を使って展開すると

$$
0 \le \|r\|^2 = \|\psi\|^2 - \sum_{n=1}^{N} |c_n|^2
$$

なので、$\sum_{n=1}^{N} |c_n|^2 \le \|\psi\|^2 = 1$ です(ベッセルの不等式、Bessel's inequality)。実際、$|c_1|^2 + |c_3|^2 \approx 0.99992$ です。すべての $n$ について足すとちょうど 1 になるのは、固有関数の全体が「足りている」(完全である)からで、[[@hilbert-space]] で扱います。
:::

::: application {field=cs title="コサイン類似度"}
文書を、単語ごとの出現回数を並べたベクトルで表します。三つの単語について、文書 A が $(2, 1, 0)$、文書 B が $(1, 1, 1)$ なら、二つの近さを

$$
\cos \theta = \frac{\langle A, B \rangle}{\|A\|\,\|B\|} = \frac{3}{\sqrt{5}\,\sqrt{3}} \approx 0.775
$$

で測ります(コサイン類似度、cosine similarity)。[[@cauchy-schwarz]] により、この値は必ず $-1$ 以上 $1$ 以下に収まります。出現回数は 0 以上なので、実際には 0 以上 1 以下です。

等号の条件から、類似度が 1 になるのは、一方のベクトルが他方の正の実数倍のときに限ります。文書 A を2回つなげた文書 $(4, 2, 0)$ と A の類似度は 1 で、文書の長さの違いは無視されます。差のノルムで比べると、$A$ と $(4, 2, 0)$ の距離は $\|A\| = \sqrt{5}$ で、単語の使い方の割合が同じでも離れてしまいます。角度で比べれば、単語の使い方の割合だけを比べられます。
:::

::: review
- ベクトル空間の八つの規則を挙げ、ある集合が足し算と実数倍についてベクトル空間になるかどうかを確かめられる。
- ノルムの三つの性質を挙げ、$\mathbb{R}^m$ と $C[a, b]$ のノルムの例でそれを確かめられる。
- ノルムから距離が決まることを証明でき、距離の三つの性質がノルムのどの性質から来るかを言える。
- バナッハ空間の例と、完備でないノルム空間の例を挙げられる。
- コーシー=シュワルツの不等式を証明し、そこから内積がノルムを決めることを示せる。
- 平行四辺形の法則を使って、あるノルムが内積から決まらないことを確かめられる。
:::

::: question
関数の各点ごとの足し算と実数倍について、次の集合はベクトル空間ですか。(1) $[0, 1]$ 上の連続関数で $f(0) = f(1)$ をみたすものの全体。(2) $[0, 1]$ 上の多項式で、次数がちょうど 2 のものの全体。
:::

::: answer
(1) ベクトル空間です。$f(0) = f(1)$ と $g(0) = g(1)$ なら $(f + g)(0) = f(0) + g(0) = f(1) + g(1) = (f + g)(1)$、$(\alpha f)(0) = \alpha f(0) = \alpha f(1) = (\alpha f)(1)$ なので、足し算でも実数倍でも外に出ません。和と実数倍は連続のままで、恒等的に 0 の関数もこの条件をみたします。八つの規則は各点で実数の計算規則です。

(2) ベクトル空間ではありません。$t^2$ と $-t^2 + t$ はどちらも次数がちょうど 2 ですが、和の $t$ は次数 1 なので、足し算で外に出てしまいます。零ベクトルである恒等的に 0 の多項式も、次数がちょうど 2 ではありません。
:::

::: question
$\mathbb{R}^2$ で $\|x\| := |x_1| + 2|x_2|$ と定めると、ノルムになりますか。
:::

::: answer
なります。正値性:$|x_1| + 2|x_2| \ge 0$ で、0 になるのは $x_1 = x_2 = 0$ のときだけです。斉次性:$|\alpha x_1| + 2|\alpha x_2| = |\alpha|\,(|x_1| + 2|x_2|)$ です。三角不等式:座標ごとに $|x_i + y_i| \le |x_i| + |y_i|$ が成り立つので、第2座標の不等式を 2 倍して第1座標の不等式と足せば得られます。
:::

::: question
実数全体で $d(x, y) := |x^3 - y^3|$ と定めると、$x \mapsto x^3$ が一対一なので距離になります。この距離は、あるノルムから決まる距離ですか。
:::

::: answer
いいえ。ノルムから決まる距離なら、[[@norm-metric]] により、2点に同じ数を足しても距離は変わらないはずです。しかし、$d(1, 0) = 1$ なのに、両方に 1 を足した $d(2, 1)$ は $8 - 1 = 7$ です。
:::

::: question
$\mathbb{R}^3$ の $x = (1, 2, 2)$ と $y = (3, 0, 4)$ について、標準内積、それぞれの長さ、なす角の余弦を求め、コーシー=シュワルツの不等式が成り立っていることを確かめてください。
:::

::: answer
$\langle x, y \rangle = 3 + 0 + 8 = 11$、$\|x\| = \sqrt{1 + 4 + 4} = 3$、$\|y\| = \sqrt{9 + 0 + 16} = 5$ です。余弦は $11/15 \approx 0.733$ で、$|\langle x, y \rangle| = 11 \le 15 = \|x\|\,\|y\|$ が成り立っています。$x$ と $y$ はどちらも他方の実数倍ではないので、等号にはなりません。
:::

::: question
$\mathbb{R}^2$ の $\|\cdot\|_1$ は、ある内積から決まるノルムですか。
:::

::: answer
いいえ。$x = (1, 0)$、$y = (0, 1)$ とすると $\|x + y\|_1 = \|x - y\|_1 = 2$ なので、平行四辺形の法則の左辺は $4 + 4 = 8$、右辺は $2 \cdot 1 + 2 \cdot 1 = 4$ です。内積から決まるノルムは必ず平行四辺形の法則をみたすので、$\|\cdot\|_1$ はどの内積からも決まりません。
:::
