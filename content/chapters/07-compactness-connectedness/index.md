::: goal
開被覆を使ってコンパクト性を、開集合による分割を使って連結性を定義し、どちらも連続写像で保たれることを示せるようになる。そこから、閉区間上の連続関数が最大値をとること(最大値の定理)と、途中の値をすべてとること(中間値の定理)を導き、定義域についての仮定を外すと成り立たなくなる例を挙げられるようになる。
:::

::: goal {field=physics}
振り子のように角度で位置が決まる系では、ポテンシャルが周期的で微分できれば、つり合いの位置が少なくとも二つあることを、最大値の定理から説明できるようになります。一定のトルクを加えて周期性が崩れると、つり合いの位置がなくなりうることも説明できます。また、回転を時間とともに連続に変えても、空間反転には行き着かないことを、中間値の定理から導けます。
:::

::: goal {field=cs}
0 と 1 の無限列を入力とし、どの入力でも止まるプログラムには、読むビット数の上限があることを、無限列の空間のコンパクト性から導けるようになります。また、実数を近似値の列で入力して 0 か 1 を答えるプログラムは、どの入力でも止まり、答えが近似値の列によらず実数だけで決まるなら答えが一定で、$x < 0$ かどうかさえ判定できないことを、実数全体の連結性から導けます。重みの大きさを制限したロジスティック回帰で、損失が最小値をとる理由も説明できます。
:::

::: motivation
区間 $(0, 1)$ 上の関数 $f(x) = x$ は、1 にいくらでも近い値をとりますが、最大値はありません。どの点 $x$ についても、$(x + 1)/2$ も $(0, 1)$ の点で、そこでの値のほうが大きいからです。区間を $[0, 1]$ にすると、$f(1) = 1$ が最大値です。区間を $[0, \infty)$ に広げた $g(x) = x/(1 + x)$ も、値は 1 にいくらでも近づきますが 1 にはならず、最大値はありません。閉区間の上の連続関数は最大値をとる、という最大値の定理は、こうした例を除くために「閉区間の上」と断っています。

有理数だけを考えると、別のことが起きます。有理数全体 $\mathbb{Q}$ の上の関数 $h(x) = x^2 - 2$ は連続で、$h(1) = -1 < 0$、$h(2) = 2 > 0$ です。ところが、1 と 2 のあいだに $h(x) = 0$ となる有理数はありません。$x^2 = 2$ をみたす実数は $\pm\sqrt{2}$ で、有理数ではないからです([[@sqrt2-irrational]])。実数の区間の上の連続関数なら、二つの値のあいだの値をすべてとります。これが中間値の定理です。

二つの定理が成り立つかどうかは、関数の式ではなく、関数を考える集合で決まっています。$[0, 1]$ にあって $(0, 1)$ や $[0, \infty)$ にない性質、実数の区間にあって $\mathbb{Q}$ にない性質とは何でしょうか。その性質は、開集合だけで述べられるでしょうか。
:::

::: motivation {field=physics}
おもりを軽い棒で支点につないだ振り子を考えます。おもりの位置は、鉛直下向きから測った角度 $\theta$ で決まり、$\theta$ と $\theta + 2\pi$ は同じ位置を表します。おもりが止まっていられる位置(つり合いの位置)は、ポテンシャル $V(\theta)$ の微分が 0 になる角度です。重力だけなら $V(\theta) = -mgl\cos\theta$($m$ はおもりの質量、$l$ は棒の長さ、$g$ は重力加速度)で、真下の $\theta = 0$ と真上の $\theta = \pi$ がつり合いの位置です。ばねや磁石の力が加わってポテンシャルの形が複雑になると、つり合いの位置を式で求めるのは難しくなります。それでも、つり合いの位置がなくならないと言えるでしょうか。

また、物体の向きを変える回転は、時間とともに連続に変えられます。回し続けて、右手系の座標軸を左手系の座標軸に変えることはできるでしょうか。
:::

::: motivation {field=cs}
[[@topological-spaces]] では、0 と 1 の無限列を先頭から読むプログラムを考えました。今度は、どの入力でも止まるプログラムを考えます。止まるまでに読むビットの数は、入力ごとに違ってかまいません。たとえば「1 を読むか、3 ビットを読み終えたら止まる」プログラムは、どの入力でも止まり、読むのは多くても 3 ビットです。入力が有限の長さの列なら、入力を最後まで読むプログラムのように、どの入力でも止まるのに、読むビットの数に上限のないプログラムが作れます。無限列を入力とするとき、どの入力でも止まり、読むビットの数に上限がないプログラムはあるでしょうか。
:::

この章では、まず、開集合の族で空間をおおう操作(開被覆)を使って、コンパクト性を定めます([[@compact]])。$\mathbb{R}^m$ では、コンパクトな集合は有界な閉集合のことで、その証明に $\mathbb{R}$ の完備性を使います。コンパクト性は連続写像で保たれ、そこから最大値の定理が出てきます([[@extreme-value]])。次に、二つの開集合に分けられないことを連結性として定めます([[@connected]])。$\mathbb{R}$ の区間は連結で、連結性も連続写像で保たれ、そこから中間値の定理が出てきます([[@intermediate-value]])。どちらの定義にも距離は出てこないので、二つの定理は位相空間の定理として成り立ちます。

## コンパクト空間 {#compact requires=topological-space,completeness}

::: summary
どのように開集合でおおっても、そのうちの有限個だけでおおい直せる位相空間。
:::

::: why
出発点の $(0, 1)$ 上の $f(x) = x$ に最大値がないのは、値の大きい点を選び直していくと、点が $(0, 1)$ の外の 1 に近づいていくからでした。$[0, \infty)$ 上の $g$ では、点が限りなく遠くへ離れていきます。閉区間 $[0, 1]$ では、どちらも起きません。この違いを、距離を使わずに、開集合だけで述べたいのです。

点が空間の外へ近づいていく様子は、開集合の族で捉えられます。$(0, 1)$ は、開区間 $U_n := (0, 1 - 1/n)$($n \ge 2$)をすべて合わせた和集合です。$(0, 1)$ のどの点も、どれかの $U_n$ に入ります。ところが、$U_n$ を有限個だけ選ぶと、その和集合は選んだうちで $n$ がいちばん大きい $U_n$ になり、$1 - 1/n$ 以上の点が残ります。1 に近い点ほど $n$ の大きい $U_n$ が要るので、有限個では足りません。$[0, 1]$ では、どんな開集合の族でおおっても、そのうちの有限個でおおえることを、この駅で示します。
:::

::: definition {#def-open-cover name="開被覆" en="open cover"}
位相空間 $X$ の開集合の族 $(U_\lambda)_{\lambda \in \Lambda}$ が $\bigcup_{\lambda \in \Lambda} U_\lambda = X$ をみたすとき、この族を $X$ の開被覆という。$\Lambda$ の有限個の要素 $\lambda_1, \dots, \lambda_k$ について $U_{\lambda_1} \cup \dots \cup U_{\lambda_k} = X$ となるとき、$U_{\lambda_1}, \dots, U_{\lambda_k}$ を、この開被覆の有限部分被覆 (finite subcover) という。$k = 0$ でもよく、そのときの和集合は $\emptyset$ とする。
:::

::: definition {name="コンパクト" en="compact" aliases="コンパクト性,コンパクト空間"}
位相空間 $X$ のどの[[開被覆]]も有限部分被覆をもつとき、$X$ はコンパクトであるという。位相空間の部分集合 $K$ は、[[相対位相]]でコンパクトなとき、コンパクトであるという。
:::

どんな開被覆を持ってこられても、そこから有限個を選んで、全体をおおい直せる、ということです^[コンパクトの定義にハウスドルフ空間([[@hausdorff]])であることを含め、この駅の意味のコンパクトを準コンパクト (quasi-compact) と呼ぶ本もあります。]。選んだ有限個でおおえればよく、もとの開被覆が有限である必要はありません。否定は、量化子を取り替えて「有限部分被覆をもたない開被覆が、少なくとも一つある」です。コンパクトでないことを示すには、そのような開被覆を一つ挙げれば足ります。

部分集合 $K$ の相対位相の開集合は、$X$ の開集合 $U$ との共通部分 $U \cap K$ でした。$X$ の開集合の族 $(U_\lambda)_{\lambda \in \Lambda}$ が $K \subset \bigcup_{\lambda \in \Lambda} U_\lambda$ をみたすとき、この族は $K$ をおおうといいます。$K$ がコンパクトであることは、「$K$ をおおう $X$ の開集合の族は、どれも、そのうちの有限個 $U_{\lambda_1}, \dots, U_{\lambda_k}$ で $K \subset U_{\lambda_1} \cup \dots \cup U_{\lambda_k}$ とできる」と言い換えられます。実際、$K$ がコンパクトなら、$(U_\lambda \cap K)_{\lambda \in \Lambda}$ は $K$ の開被覆なので有限部分被覆 $U_{\lambda_1} \cap K, \dots, U_{\lambda_k} \cap K$ があり、$U_{\lambda_1}, \dots, U_{\lambda_k}$ が $K$ をおおいます。逆に、この言い換えが成り立つなら、$K$ の開被覆 $(W_\lambda)_{\lambda \in \Lambda}$ の各 $W_\lambda$ を、$X$ の開集合 $U_\lambda$ を使って $W_\lambda = U_\lambda \cap K$ と書き、$K$ をおおう $U_{\lambda_1}, \dots, U_{\lambda_k}$ を選べば、$W_{\lambda_1}, \dots, W_{\lambda_k}$ が有限部分被覆になります。この駅の証明では、こちらの形を使います。

::: examples
- 有限集合は、どの位相でもコンパクトです。開被覆が与えられたら、各点について、その点を含む開集合を一つずつ選べば、有限個で全体をおおえます。
- $(0, 1)$ はコンパクトではありません。上の $U_n = (0, 1 - 1/n)$($n \ge 2$)は $(0, 1)$ の開被覆で、有限部分被覆をもちません。$\mathbb{R}$ もコンパクトではありません。開区間 $(-n, n)$($n$ は正の整数)を集めた族は $\mathbb{R}$ の開被覆ですが、有限個を選ぶと、その和集合は選んだうちで $n$ がいちばん大きい $(-N, N)$ で、$N$ を含まないからです。
- 無限集合に離散位相を入れた空間は、コンパクトではありません。1点の集合 $\{x\}$ はどれも開集合で、すべての点 $x$ についての $\{x\}$ を集めた族は開被覆ですが、有限個を選んでも有限個の点しかおおえないからです。
- $\mathbb{R}$ の部分集合 $Y = \{0\} \cup \{1/n \mid n \text{ は正の整数}\}$ はコンパクトです。$Y$ をおおう $\mathbb{R}$ の開集合の族 $(U_\lambda)$ が与えられたとします。$0$ を含む $U_{\lambda_0}$ を一つとると、$B(0, r) \subset U_{\lambda_0}$ となる $r > 0$ があり、$n > 1/r$ となるすべての $1/n$ は $U_{\lambda_0}$ に入ります。残りの $1/n$($n \le 1/r$)は有限個なので、それぞれを含む $U_\lambda$ を一つずつ選べば、合わせて有限個で $Y$ をおおえます。
- 一方、0 を除いた $Y' = \{1/n \mid n \text{ は正の整数}\}$ はコンパクトではありません。開球 $V_n := B\bigl(1/n, 1/(n(n+1))\bigr)$ は、$Y'$ の点のうち $1/n$ だけを含みます。$1/n$ にいちばん近い $Y'$ の点は $1/(n+1)$ で、その距離は $1/n - 1/(n+1) = 1/(n(n+1))$ だからです。$(V_n)$ は $Y'$ をおおいますが、有限個では有限個の点しかおおえません。$Y$ と $Y'$ の違いは、点列 $(1/n)$ の極限 0 を含むかどうかです。
- 余有限位相([[@cofinite-topology]])を入れた $\mathbb{R}$ は、コンパクトです。開被覆から空でない開集合 $U_0$ を一つ選ぶと、その補集合は有限集合 $\{c_1, \dots, c_k\}$ で、各 $c_i$ を含む開集合 $U_i$ を一つずつ選べば、$U_0, U_1, \dots, U_k$ で全体をおおえます。
:::

コンパクト性は、連続写像で保たれます。

::: theorem {#compact-image name="コンパクト集合の連続像"}
位相空間のあいだの連続写像 $f: X \to Y$ について、$X$ がコンパクトなら、[[像]] $f(X)$ は $Y$ のコンパクトな部分集合である。
:::

::: proof-sketch
1. $f(X)$ をおおう $Y$ の開集合の族 $(V_\lambda)$ をとると、逆像 $f^{-1}(V_\lambda)$ はどれも $X$ の開集合である($f$ の連続性を使う)。
2. $X$ の各点 $x$ について、$f(x)$ はある $V_\lambda$ に入るので、$(f^{-1}(V_\lambda))$ は $X$ の開被覆である(逆像の定義を使う)。
3. 有限部分被覆 $f^{-1}(V_{\lambda_1}), \dots, f^{-1}(V_{\lambda_k})$ をとると、$V_{\lambda_1}, \dots, V_{\lambda_k}$ が $f(X)$ をおおう($X$ のコンパクト性を使う)。
:::

::: proof
$(V_\lambda)_{\lambda \in \Lambda}$ を、$f(X)$ をおおう $Y$ の開集合の族とします。$f$ は連続なので、$f^{-1}(V_\lambda)$ はどれも $X$ の開集合です。$x \in X$ をとると、$f(x) \in f(X)$ はある $V_\lambda$ に属するので、$x \in f^{-1}(V_\lambda)$ です。よって $(f^{-1}(V_\lambda))_{\lambda \in \Lambda}$ は $X$ の開被覆です。

$X$ はコンパクトなので、$X = f^{-1}(V_{\lambda_1}) \cup \dots \cup f^{-1}(V_{\lambda_k})$ となる $\lambda_1, \dots, \lambda_k$ があります。$f(X)$ の点 $y$ は、ある $x \in X$ で $y = f(x)$ と書け、$x$ はある $f^{-1}(V_{\lambda_i})$ に属するので、$y = f(x) \in V_{\lambda_i}$ です。よって $f(X) \subset V_{\lambda_1} \cup \dots \cup V_{\lambda_k}$ で、上の言い換えから $f(X)$ はコンパクトです。
:::

::: drop-assumption
**連続性を外す。** $[0, 1]$ 上の関数 $f$ を、$x > 0$ で $f(x) = 1/x$、$f(0) = 0$ と定めます。$[0, 1]$ はコンパクトですが(下の [[@heine-borel]])、像 $\{0\} \cup [1, \infty)$ はコンパクトではありません。開区間 $(-1, n)$($n$ は正の整数)を集めた族は像をおおいますが、有限個を選ぶと、その和集合は $n$ がいちばん大きい $(-1, N)$ で、像の点 $N = f(1/N)$ を含まないからです。証明の1段目で、$f^{-1}((-1, 1)) = \{0\}$ が $[0, 1]$ の開集合でないことが原因です。
:::

### 有界な閉集合

$\mathbb{R}^m$ では、どの集合がコンパクトかを、開被覆を調べずに判定できます。そのために、距離空間の部分集合が有界であることを定めます。

::: definition {#def-bounded name="有界" en="bounded"}
[[距離空間]] $(X, d)$ の部分集合 $A$ が有界であるとは、ある実数 $M$ があって、$A$ のどの2点 $x, y$ についても $d(x, y) \le M$ となることをいう。
:::

$A$ の点どうしの距離が、ある値を超えない、ということです。$\mathbb{R}$ の区間 $[0, 1]$ と $(0, 1)$ は有界で、$[0, \infty)$ と $\mathbb{R}$ は有界ではありません。$\mathbb{R}^m$ には距離 $d_2$ を入れ、点 $x$ の第 $i$ 成分を $x_i$ と書きます。$\mathbb{R}^m$ の空でない部分集合 $K$ が有界なら、$K$ はある箱 $[-L, L]^m = [-L, L] \times \dots \times [-L, L]$ に含まれます。$K$ の点 $x_0$ を一つ決め、有界の定義の $M$ について $L := M + \max_j |x_{0,j}|$ とおくと、$K$ のどの点 $x$ についても、どの $i$ でも $|x_i| \le |x_i - x_{0,i}| + |x_{0,i}| \le d_2(x, x_0) + |x_{0,i}| \le L$ となるからです。

::: theorem {#compact-bounded-closed name="コンパクト集合は有界な閉集合"}
距離空間 $(X, d)$ のコンパクトな部分集合 $K$ は、有界な閉集合である。
:::

::: proof-sketch
1. $K$ の点 $a$ を中心とする開球 $B(a, n)$($n$ は正の整数)を集めた族は $K$ をおおうので、有限個でおおえ、ある $N$ で $K \subset B(a, N)$ となる(開球は開集合であることと、コンパクト性を使う)。
2. $K$ の2点の距離は、$a$ を経由して $2N$ 未満になる(三角不等式と対称性を使う)。
3. $K$ の外の点 $x$ について、$V_n := \{y \in X \mid d(y, x) > 1/n\}$ は開集合で、これを集めた族は $K$ をおおうので、ある $N$ で $K \subset V_N$ となる(距離の連続性と、正値性と、コンパクト性を使う)。
4. すると $B(x, 1/N)$ は $K$ と交わらないので、$X \setminus K$ は開集合で、$K$ は閉集合である(開集合の定義と、閉集合の定義を使う)。
:::

::: proof
**有界であること.** $K = \emptyset$ なら、条件を確かめる2点がないので、$K$ は有界です。$K \ne \emptyset$ なら、点 $a \in K$ を一つとります。開球 $B(a, n)$($n$ は正の整数)はどれも開集合で([[@open-ball-is-open]])、$X$ のどの点 $y$ も $n > d(y, a)$ となる $B(a, n)$ に入るので、これを集めた族は $K$ をおおいます。$K$ はコンパクトなので、有限個 $B(a, n_1), \dots, B(a, n_k)$ で $K$ をおおえます。$N = \max(n_1, \dots, n_k)$ とすると、どの $B(a, n_i)$ も $B(a, N)$ に含まれるので、$K \subset B(a, N)$ です。$K$ の2点 $x, y$ について、三角不等式と対称性から $d(x, y) \le d(x, a) + d(a, y) < 2N$ です。よって $K$ は有界です。

**閉集合であること.** $X \setminus K$ が開集合であることを示します。$x \in X \setminus K$ をとり、正の整数 $n$ について $V_n := \{y \in X \mid d(y, x) > 1/n\}$ とおきます。$g(y) = d(y, x)$ は連続なので([[@continuous-map]] の例)、$V_n = g^{-1}((1/n, \infty))$ は開集合です。$K$ の点 $y$ は $x$ と異なるので、正値性から $d(y, x) > 0$ で、$n > 1/d(y, x)$ となる $V_n$ に入ります。よって $(V_n)$ は $K$ をおおい、有限個 $V_{n_1}, \dots, V_{n_k}$ で $K$ をおおえます。$n$ が大きいほど $V_n$ は大きくなるので、$N = \max(n_1, \dots, n_k)$ について $K \subset V_N$ です($K = \emptyset$ なら、どの $N$ でもこれは成り立ちます)。$B(x, 1/N)$ の点 $y$ は $d(y, x) < 1/N$ をみたすので $V_N$ に入らず、$K$ にも入りません。よって $B(x, 1/N) \subset X \setminus K$ で、$x$ は $X \setminus K$ の任意の点だったので、$X \setminus K$ は開集合です。補集合が開集合なので、$K$ は閉集合です。
:::

::: drop-assumption
**距離空間を、一般の位相空間に広げる。** 余有限位相を入れた $\mathbb{R}$ では、どの部分集合 $A$ もコンパクトです。$A$ が空でなければ、$A$ をおおう開集合の族から、$A$ の点を含む開集合 $U_0$ を一つ選ぶと(空でない開集合の補集合は有限集合)、$A$ のうち $U_0$ に入らない点は有限個なので、それぞれを含む開集合を一つずつ選べば、有限個で $A$ をおおえるからです。とくに $[0, 1]$ はコンパクトですが、閉集合ではありません。この位相の閉集合は有限集合と $\mathbb{R}$ だけで、$[0, 1]$ はそのどちらでもないからです。証明の3段目で、点 $x$ を $K$ から引き離す開集合 $V_n$ を、距離を使って作れないことが原因です。この空間はハウスドルフ空間ではなく([[@hausdorff]] の「仮定を外すと」)、異なる2点を交わらない開集合で分けることもできません。
:::

逆向きは、一般の距離空間では成り立ちません(下の落とし穴)。$\mathbb{R}^m$ では成り立ち、その証明に $\mathbb{R}$ の[[完備性]]を使います。

::: theorem {#heine-borel name="ハイネ=ボレルの定理"}
距離 $d_2$ を入れた $\mathbb{R}^m$ の部分集合 $K$ について、$K$ がコンパクトであることと、$K$ が有界な閉集合であることは同値である。
:::

::: proof-sketch
1. コンパクトなら有界な閉集合であることは、[[@compact-bounded-closed]] である。逆を示すため、有界な閉集合 $K$ をおおう開集合の族 $(U_\lambda)$ で、有限個では $K$ をおおえないものがあるとし、$K$ を含む箱 $Q_0$ をとる($K$ が有界であることを使う)。
2. 箱の各辺を半分に分けて $2^m$ 個の箱にすると、そのどれかは、$K$ との共通部分が有限個の $U_\lambda$ でおおえない。これを繰り返して、辺の長さが半分ずつになる箱の列 $Q_0 \supset Q_1 \supset Q_2 \supset \cdots$ を作る(有限個の有限個は有限個であることを使う)。
3. $Q_n \cap K$ から点 $x_n$ を選ぶと、$(x_n)$ はコーシー列で、$K$ の点 $x$ に収束する($\mathbb{R}^m$ の完備性と、$K$ が閉集合であることを使う)。
4. $x$ はある $U_\lambda$ に入り、$n$ が大きければ $Q_n$ 全体がその $U_\lambda$ に入るので、$Q_n \cap K$ が1個の $U_\lambda$ でおおえて矛盾する($U_\lambda$ が開集合であることと、三角不等式を使う)。
:::

::: proof
**コンパクトなら有界な閉集合.** [[@compact-bounded-closed]] で示しました。

**有界な閉集合ならコンパクト.** $K$ を $\mathbb{R}^m$ の有界な閉集合とし、$K$ をおおう開集合の族 $(U_\lambda)_{\lambda \in \Lambda}$ で、有限個(0 個を含む)の $U_\lambda$ では $K$ をおおえないものがあると仮定します。以下、有限個の $U_\lambda$ で集合 $A$ をおおえないことを、「$A$ はおおえない」と略します。$K = \emptyset$ は 0 個の $U_\lambda$ でおおえるので、$K$ は空ではなく、上で見たとおり、ある箱 $Q_0 = [-L, L]^m$ に含まれます。$Q_0 \cap K = K$ はおおえません。

辺の長さが $s$ の箱 $Q := [c_1, c_1 + s] \times \dots \times [c_m, c_m + s]$ の各辺を半分に分けると、辺の長さが $s/2$ の $2^m$ 個の箱ができ、その和集合は $Q$ です。$Q \cap K$ がおおえないなら、$2^m$ 個の箱のうちのどれか $Q'$ について、$Q' \cap K$ はおおえません。どれもおおえるなら、それぞれをおおう有限個を合わせた有限個で、$Q \cap K$ がおおえるからです。そこで $Q_0$ から始めて、$Q_n$ を分けた $2^m$ 個の箱のうち、$K$ との共通部分がおおえないものを一つ選んで $Q_{n+1}$ とします。こうして、辺の長さが $2L/2^n$ で、どれも $Q_n \cap K$ がおおえない箱の列 $Q_0 \supset Q_1 \supset Q_2 \supset \cdots$ ができます。

おおえない集合は空ではないので、各 $n$ について点 $x_n \in Q_n \cap K$ を選べます。辺の長さが $s$ の箱の2点 $y, z$ は、どの成分も差が $s$ 以下なので、$d_2(y, z) \le \sqrt{m}\, s$ です。$k, l \ge N$ なら $x_k, x_l \in Q_N$ なので、$d_2(x_k, x_l) \le \sqrt{m} \cdot 2L/2^N$ です。$2^N \ge N$ なので、$\varepsilon > 0$ に対して $N > 2\sqrt{m}\,L/\varepsilon$ ととれば、すべての $k, l \ge N$ について $d_2(x_k, x_l) < \varepsilon$ です。よって $(x_n)$ は[[コーシー列]]で、$\mathbb{R}^m$ は完備なので([[@completeness]] の例)、ある点 $x$ に収束します。$K$ は閉集合なので、[[@closed-set-limits]] から $x \in K$ です。

$x$ はある $U_\lambda$ に属し、$U_\lambda$ は開集合なので、$B(x, r) \subset U_\lambda$ となる $r > 0$ があります。$\sqrt{m} \cdot 2L/2^n < r/2$ かつ $d_2(x_n, x) < r/2$ となる番号 $n$ をとります。$Q_n$ の点 $y$ について、$d_2(y, x) \le d_2(y, x_n) + d_2(x_n, x) < r/2 + r/2 = r$ なので、$Q_n \subset B(x, r) \subset U_\lambda$ です。すると $Q_n \cap K$ は1個の $U_\lambda$ でおおえてしまい、$Q_n$ の選び方に反します。よって $K$ はコンパクトです。
:::

::: drop-assumption
**$\mathbb{R}$ の完備性を外す。** 有理数全体 $\mathbb{Q}$ に距離 $d(x, y) = |x - y|$ を入れ、$K = \{t \in \mathbb{Q} \mid 1 \le t \le 2\}$ を考えます。$K$ は有界で、$\mathbb{Q}$ の閉集合です。$K$ の点からなる点列が $\mathbb{Q}$ の点に収束するなら、その極限も 1 以上 2 以下だからです([[@closed-set-limits]])。ところが、$K$ はコンパクトではありません。$V_n := \{t \in \mathbb{Q} \mid |t - \sqrt{2}| > 1/n\}$($n$ は正の整数)は、$\mathbb{R}$ の開集合 $\{x \in \mathbb{R} \mid |x - \sqrt{2}| > 1/n\}$ と $\mathbb{Q}$ の共通部分なので、[[@relative-topology-metric]] から $\mathbb{Q}$ の開集合です。$\sqrt{2}$ は有理数ではないので、これを集めた族は $K$ をおおいます。有限個を選ぶと、その和集合は $n$ がいちばん大きい $V_N$ です。$\sqrt{2}$ の小数を一桁ずつ伸ばした $1.4, 1.41, 1.414, \dots$ のうち、$\sqrt{2}$ との差が $1/N$ 以下のものは、$K$ の点なのに $V_N$ に入りません。証明の3段目で、コーシー列 $(x_n)$ の行き先 $\sqrt{2}$ が $\mathbb{Q}$ の中にないことが原因です。
:::

::: pitfall
- コンパクトの定義は「どの開被覆も」有限部分被覆をもつことで、「有限個の開集合でおおえる」ことではありません。どの位相空間 $X$ も、$X$ 自身という1個の開集合でおおえます。$(0, 1)$ がコンパクトでないのは、上の $U_n$ のように、有限個では足りない開被覆が一つあるからです。
- 有界な閉集合がコンパクトになるのは、$\mathbb{R}^m$ の話です。$\mathbb{R}$ に[[離散距離]]を入れると、どの2点の距離も 1 以下なので $\mathbb{R}$ は有界で、全体なので閉集合でもありますが、コンパクトではありません。開球 $B(x, 1) = \{x\}$ を集めた開被覆は、有限個を選ぶと有限個の点しかおおえないからです。
- コンパクトかどうかは、位相で決まります。上の例のとおり、同じ $\mathbb{R}$ でも、通常の位相ではコンパクトではなく、余有限位相ではコンパクトです。
:::

::: remark
距離空間では、コンパクトであることは、どの点列も収束する部分列をもつこと(点列コンパクト、sequentially compact)と同値です。$\mathbb{R}$ の有界な数列は収束する部分列をもつ、というボルツァーノ=ワイエルシュトラスの定理 (Bolzano–Weierstrass theorem) は、有界な閉区間が点列コンパクトであることを言っています。二つが同値であることの証明は、この章では扱いません。一般の位相空間では、二つの条件は一致しません。
:::

::: application {#bits-bound field=cs title="読むビット数の上限"}
[[@topological-space]] の応用と同じく、0 と 1 の無限列の全体を $\Sigma$、有限の長さの列 $w$ で始まる無限列の全体を $[w]$ と書き、$[w]$ の形の集合の和集合を開集合とします。$\Sigma$ はコンパクトです。

これを示すため、有限部分被覆をもたない開被覆 $(U_\lambda)$ があったとします。空の列を $w_0$ とすると、$[w_0] = \Sigma$ は有限個の $U_\lambda$ ではおおえません。$[w_k]$ がおおえないとき、$[w_k] = [w_k 0] \cup [w_k 1]$ なので、$[w_k 0]$ と $[w_k 1]$ の少なくとも一方は、有限個の $U_\lambda$ ではおおえません。どちらもおおえるなら、合わせた有限個で $[w_k]$ がおおえるからです。おおえないほうを $[w_{k+1}]$ とします。これを繰り返すと、1ビットずつ伸びる列 $w_0, w_1, w_2, \dots$ で、どの $[w_k]$ も有限個の $U_\lambda$ ではおおえないものができます。先頭の $k$ ビットが $w_k$ になる無限列を $s$ とすると、$s$ はある $U_\lambda$ に入ります。$U_\lambda$ は $[w]$ の形の集合の和集合なので、$s \in [u] \subset U_\lambda$ となる $u$ があり、$u$ は $s$ の先頭の部分です($u$ は空の列でもよい)。$u$ の長さを $k$ とすると $u = w_k$ で、$[w_k]$ が1個の $U_\lambda$ でおおえてしまい、矛盾します。[[@heine-borel]] の証明と同じく、半分ずつに分けていく議論ですが、ここでは極限の点を[[完備性]]から得る必要はありません。選んだビットを並べた列 $s$ が、そのまま $\Sigma$ の点だからです。

ここから、どの入力でも止まるプログラムには、読むビット数の上限があることが分かります。入力 $s$ でプログラムが止まるまでに読んだ先頭の列を $u_s$ とすると、$[u_s]$ は開集合で、$s \in [u_s]$ なので、$([u_s])_{s \in \Sigma}$ は $\Sigma$ の開被覆です。有限部分被覆 $[u_{s_1}], \dots, [u_{s_k}]$ をとり、$u_{s_1}, \dots, u_{s_k}$ の長さの最大を $D$ とします。どの入力 $t$ も、ある $[u_{s_i}]$ に入るので、$t$ の先頭は $u_{s_i}$ です。プログラムは $t$ についても $s_i$ のときと同じように動いて、$u_{s_i}$ を読んだ所で止まります。よって、どの入力でも、読むのは多くても $D$ ビットです。

出発点の「1 を読むか、3 ビットを読み終えたら止まる」プログラムでは、$u_s$ は $1$、$01$、$001$、$000$ のどれかで、$[1] \cup [01] \cup [001] \cup [000] = \Sigma$ から $D = 3$ です。一方、「1 を読んだら止まる」プログラムが止まる入力の全体は $[1] \cup [01] \cup [001] \cup \cdots$ で、$000\cdots$ を含みません。読むビット数に上限がないのは、止まらない入力があるときだけです。

判定のプログラムがどの入力でも止まるなら、答えは先頭の $D$ ビットだけで決まります。先頭の $D$ ビットの $2^D$ 通りについて答えを並べた表を作れば、プログラムをその表で置き換えられます。
:::

## 最大値の定理 {#extreme-value requires=compact}

::: summary
コンパクト空間の上の実数値の連続関数は、最大値と最小値をとるという定理。
:::

::: why
出発点の $(0, 1)$ 上の $f(x) = x$ では、値の集合 $(0, 1)$ に、最大値の候補 1 が入っていませんでした。[[@compact-image]] と [[@compact-bounded-closed]] から、コンパクト空間 $X$ の上の連続関数 $f: X \to \mathbb{R}$ の値の集合 $f(X)$ は、$\mathbb{R}$ の有界な閉集合です。有界なので値はいくらでも大きくはならず、閉集合なので、値が近づいていく先が値の集合から抜け落ちることもありません。この駅では、最大値があることを、開被覆の言葉で直接示します。
:::

::: theorem {#extreme-value-theorem name="最大値の定理"}
空でないコンパクトな位相空間 $X$ から、通常の位相の $\mathbb{R}$ への連続関数 $f$ は、最大値と最小値をとる。つまり、すべての $x \in X$ について $f(x_{\min}) \le f(x) \le f(x_{\max})$ となる点 $x_{\max}, x_{\min} \in X$ がある。
:::

::: proof-sketch
1. $f$ が最大値をとらないとすると、どの点 $p$ にも、$f(p) < f(x)$ となる点 $x$ がある(最大値の否定を使う)。
2. 各点 $x$ について $U_x := \{p \in X \mid f(p) < f(x)\}$ とおくと、$U_x$ は開集合で、1 から $(U_x)_{x \in X}$ は $X$ の開被覆になる($f$ の連続性と、$(-\infty, c)$ が開集合であることを使う)。
3. 有限部分被覆 $U_{x_1}, \dots, U_{x_k}$ をとり、$f(x_1), \dots, f(x_k)$ のうち最大のものを $f(x_j)$ とする($X$ のコンパクト性と、$X$ が空でないことと、有限個の実数には最大のものがあることを使う)。
4. $x_j$ はある $U_{x_i}$ に属するので $f(x_j) < f(x_i) \le f(x_j)$ となり、矛盾する。最小値は、$-f$ に同じ議論を使う($U_{x_i}$ の定義と、$-f$ が連続であることを使う)。
:::

::: proof
$f$ が最大値をとらないと仮定します。最大値をとるとは「ある点 $q$ があって、すべての $x$ について $f(x) \le f(q)$」なので、その否定は、量化子を取り替えて「すべての $q$ について、ある $x$ があって $f(x) > f(q)$」です。つまり、どの点 $p$ についても、$f(p) < f(x)$ となる点 $x$ があります。

各点 $x \in X$ について $U_x := \{p \in X \mid f(p) < f(x)\} = f^{-1}\bigl((-\infty, f(x))\bigr)$ とおきます。$(-\infty, f(x))$ は $\mathbb{R}$ の開集合で、$f$ は連続なので、$U_x$ は $X$ の開集合です。上で見たとおり、どの点 $p$ もある $U_x$ に属するので、$(U_x)_{x \in X}$ は $X$ の開被覆です。

$X$ はコンパクトなので、$X = U_{x_1} \cup \dots \cup U_{x_k}$ となる点 $x_1, \dots, x_k$ があります。$X$ は空でないので $k \ge 1$ で、有限個の実数 $f(x_1), \dots, f(x_k)$ のうち最大のものを $f(x_j)$ とします。$x_j$ も $X$ の点なので、ある $i$ で $x_j \in U_{x_i}$、つまり $f(x_j) < f(x_i)$ です。ところが $f(x_i) \le f(x_j)$ なので、$f(x_j) < f(x_j)$ となって矛盾します。よって $f$ は最大値をとります。

$-f$ も連続なので、$-f$ は最大値をとります。$-f$ が最大になる点は $f$ が最小になる点なので、$f$ は最小値もとります。
:::

閉区間 $[a, b]$ は $\mathbb{R}$ の有界な閉集合なので、[[@heine-borel]] からコンパクトです。よって、閉区間の上の連続関数は最大値と最小値をとります。出発点の最大値の定理は、こうして得られます。証明で使ったのは、$X$ のコンパクト性と $f$ の連続性と $X$ が空でないことのほかは、有限個の実数には最大のものがあることと、$(-\infty, c)$ が開集合であることだけです。値の集合の上限 (supremum) を使う証明もありますが、ここでは使っていません。$\mathbb{R}$ の完備性は、$[a, b]$ がコンパクトであることを示すところで使われています。

::: examples
- 平面の単位円周 $S^1 = \{(x, y) \in \mathbb{R}^2 \mid x^2 + y^2 = 1\}$ はコンパクトです。$S^1$ は、$[0, 2\pi]$ を連続写像 $\theta \mapsto (\cos\theta, \sin\theta)$ で写した像なので、[[@compact-image]] からコンパクトです。よって、$S^1$ の上の連続関数は最大値と最小値をとります。たとえば、輪の形をした針金の上の温度が連続に分布しているなら、いちばん熱い点といちばん冷たい点があります。
- 空でないコンパクトな集合 $K \subset \mathbb{R}^m$ と点 $p$ について、$K$ の中に $p$ にいちばん近い点があります。$g(x) := d_2(x, p)$ は連続なので([[@continuous-map]] の例)、$K$ の上で最小値をとるからです。たとえば、点 $(2, 0)$ に $S^1$ でいちばん近い点は $(1, 0)$ で、距離は 1 です。$K$ がコンパクトでないと、いちばん近い点がないことがあります。$(0, 1]$ には、点 $0$ にいちばん近い点がありません。どの点 $x$ についても、$x/2$ のほうが近いからです。
- [[@metric-space]] の例では、$C[a, b]$ の sup 距離 $d_\infty(f, g) = \sup_{t \in [a, b]} |f(t) - g(t)|$ が最大値になることを、最大値の定理から認めていました。$|f(t) - g(t)|$ は $t$ の連続関数で、$[a, b]$ はコンパクトなので、この定理から最大値をとります。
- [[@bits-bound]] の読むビット数の上限も、この定理で読み直せます。入力 $s$ に、止まるまでに読むビット数を対応させる関数 $\beta: \Sigma \to \mathbb{R}$ は、各 $[u_s]$ の上で一定なので連続で、$\Sigma$ はコンパクトなので最大値をとります。その最大値が上限 $D$ です。
- コンパクト空間の上の実数値の連続関数は有界です。最小値と最大値のあいだに、すべての値が収まるからです。
:::

::: drop-assumption
**コンパクト性を外す。** 出発点の $(0, 1)$ 上の $f(x) = x$ は連続ですが、最大値をとりません。証明の2段目の $U_x = \{p \mid p < x\} = (0, x)$ を集めた族は $(0, 1)$ の開被覆ですが、有限個を選ぶと、その和集合は $x$ がいちばん大きい $(0, x)$ で、$(0, 1)$ 全体をおおえません。証明の3段目で、有限部分被覆がとれないことが原因です。
:::

::: drop-assumption
**連続性を外す。** $[0, 1]$ 上の関数 $f$ を、$0 \le x < 1$ で $f(x) = x$、$f(1) = 0$ と定めます。$[0, 1]$ はコンパクトですが、$f$ は最大値をとりません。値は 1 にいくらでも近づきますが、値が 1 になる点はないからです。証明の2段目で、たとえば $U_{1/2} = \{p \mid f(p) < 1/2\} = [0, 1/2) \cup \{1\}$ が $[0, 1]$ の開集合でないことが原因です。点 $1$ を中心とするどの開球も、$f$ の値が $1/2$ 以上の点を含みます。
:::

::: pitfall
- 最大値と上限は違います。$(0, 1)$ 上の $f(x) = x$ の値は 1 を超えず、1 より小さいどの数よりも大きい値があるので、値の上限は 1 です。ところが、値が 1 になる点はないので、1 は最大値ではありません。最大値の定理が言っているのは、上限が値として実際にとられることです。
- 「閉区間」を「閉集合である区間」と読むと間違えます。$[0, \infty)$ は $\mathbb{R}$ の閉集合ですが、有界ではないのでコンパクトではなく、出発点の $g(x) = x/(1 + x)$ は最大値をとりません。最大値の定理の閉区間は、有界な閉区間 $[a, b]$ のことです。
- 定理は最大値をとる点があることを言うだけで、その点の求め方は教えません。最大値をとる点が二つ以上あることもあります。$[-1, 1]$ 上の $f(x) = x^2$ は、$x = -1$ と $x = 1$ の両方で最大値 1 をとります。
:::

::: application {field=physics title="円周上のつり合いの位置"}
棒で支えた振り子のように、位置が角度 $\theta$ で決まり、$\theta$ と $\theta + 2\pi$ が同じ位置を表す系を考えます。ポテンシャル $V$ は周期 $2\pi$ の関数($V(\theta + 2\pi) = V(\theta)$)で、微分でき、導関数 $V'$ が連続だとします。おもりにはたらく一般化力は $-V'(\theta)$ で、つり合いの位置は $V'(\theta) = 0$ となる角度です。

$[0, 2\pi]$ はコンパクトなので、[[@extreme-value-theorem]] から、$V$ は $[0, 2\pi]$ の上で最大値と最小値をとります。どの実数 $\theta$ も、$2\pi$ の整数倍を足し引きすれば $[0, 2\pi)$ に入り、周期性から $V$ の値は変わらないので、これは $V$ の $\mathbb{R}$ の上での最大値と最小値でもあります。微分できる関数が $\mathbb{R}$ の点で最大値や最小値をとるなら、微積分で習うとおり、その点で導関数は 0 です。よって、最大値をとる角度と最小値をとる角度は、どちらもつり合いの位置です。$V$ が定数でなければ、最大値と最小値は違う値なので、二つは違う位置です($V$ が定数なら、どの位置もつり合いの位置です)。ポテンシャルの形がどれほど複雑でも、周期的なら、つり合いの位置は少なくとも二つあります。重力だけの $V(\theta) = -mgl\cos\theta$ では、真下の $\theta = 0$ で最小、真上の $\theta = \pi$ で最大です。

周期性がなくなると、この議論は使えません。支点のまわりに一定のトルク $\tau$ を加え続けると、ポテンシャルは $V(\theta) = -mgl\cos\theta - \tau\theta$ になり、$V(\theta + 2\pi) = V(\theta) - 2\pi\tau$ なので、周期的ではありません。つり合いの条件は $V'(\theta) = mgl\sin\theta - \tau = 0$、つまり $\sin\theta = \tau/(mgl)$ です。$mgl = 1$、$\tau = 0.5$ なら、$\theta = \pi/6 \approx 0.524$ と $\theta = 5\pi/6 \approx 2.618$ がつり合いの位置です。$\tau = 2$ なら $\sin\theta = 2$ となる $\theta$ はなく、つり合いの位置はありません。おもりは回り続けます。このとき $V$ は $\mathbb{R}$ の上でいくらでも小さな値をとり、最小値をとりません。$[0, 2\pi]$ の上では最小値をとりますが、それは端の点 $\theta = 2\pi$ で、そこでの $V'(2\pi) = -2$ は 0 ではありません。
:::

::: application {field=cs title="重みを制限したロジスティック回帰"}
2値の分類で、データ $(x_i, y_i)$($i = 1, \dots, n$。$x_i \in \mathbb{R}^m$、$y_i$ は $+1$ か $-1$)から重み $w \in \mathbb{R}^m$ を学習するロジスティック回帰では、損失

$$
J(w) := \sum_{i=1}^{n} \log\bigl(1 + e^{-y_i\, w \cdot x_i}\bigr)
$$

を小さくする $w$ を探します。ここで $w \cdot v := \sum_{j=1}^{m} w_j v_j$ で、$w_j$ と $v_j$ は $w$ と $v$ の第 $j$ 成分です。$J$ は $w$ の連続関数ですが、$\mathbb{R}^m$ の上で最小値をとるとは限りません。データが1点で、$m = n = 1$、$x_1 = 1$、$y_1 = +1$ なら $J(w) = \log(1 + e^{-w})$ で、$J(w) > 0$ ですが、$w$ を大きくすると $J(w)$ はいくらでも 0 に近づきます。最小値はなく、損失を小さくしようと重みを更新し続けると、$w$ は限りなく大きくなります。ある $w$ で、すべての $i$ について $y_i\, w \cdot x_i > 0$ となるデータ(原点を通る超平面 $\{v \mid w \cdot v = 0\}$ で二つの組を分けられるデータ)では、いつもこれが起きます。その $w$ を $t$ 倍すると、$t \to \infty$ で $J(tw)$ が 0 に近づくからです。

重みを有界な閉集合 $\{w \in \mathbb{R}^m \mid d_2(w, 0) \le R\}$ に制限すると、この集合は [[@heine-borel]] からコンパクトなので、[[@extreme-value-theorem]] から $J$ は最小値をとります。上の例で $R = 5$ なら、最小値は $w = 5$ での $\log(1 + e^{-5}) \approx 0.0067$ です。

重みの大きさに罰則を加えた $F(w) := J(w) + \mu\, d_2(w, 0)^2$($\mu > 0$)は、重みを制限しなくても最小値をとります。$F(0) = n\log 2$ で、$d_2(w, 0)^2 > F(0)/\mu$ なら $F(w) \ge \mu\, d_2(w, 0)^2 > F(0)$ です。そこで $R := \sqrt{F(0)/\mu}$ として、コンパクトな集合 $\{w \mid d_2(w, 0) \le R\}$ の上で $F$ が最小値をとる点 $w^*$ を選ぶと、その外の $w$ では $F(w) > F(0) \ge F(w^*)$ なので、$w^*$ は $\mathbb{R}^m$ の上で $F$ が最小値をとる点です。上の1点の例で $\mu = 0.1$ なら、$R = \sqrt{10\log 2} \approx 2.63$ で、最小値をとる点は $w \approx 1.18$ です。
:::

## 連結空間 {#connected requires=topological-space,completeness}

::: summary
交わらない二つの空でない開集合に分けられない位相空間。
:::

::: why
出発点の $\mathbb{Q}$ 上の $h(x) = x^2 - 2$ は、値 0 を飛ばしていました。$h(x) < 0$ となる点の集合を $A$、$h(x) > 0$ となる点の集合を $B$ とすると、$h$ は 0 にならないので $\mathbb{Q} = A \cup B$ で、$A$ と $B$ は交わりません。$h$ は連続なので、$A = h^{-1}((-\infty, 0))$ と $B = h^{-1}((0, \infty))$ は $\mathbb{Q}$ の開集合です。$\mathbb{Q}$ は、$\sqrt{2}$ と $-\sqrt{2}$ の所で、交わらない開集合に切り離されています。値を飛ばさずに動けるのは、このように切り離せない空間のはずです。
:::

::: definition {name="連結" en="connected" aliases="連結性,連結空間"}
位相空間 $X$ が連結であるとは、$X = U \cup V$ かつ $U \cap V = \emptyset$ となる空でない開集合 $U, V$ がないことをいう。位相空間の部分集合は、[[相対位相]]で連結なとき、連結であるという。
:::

空間を、交わらない二つの開集合に分けることはできない、ということです。$U$ と $V = X \setminus U$ がどちらも開集合なら、$U$ は開集合でも閉集合でもあります。そこで、連結であることは、開集合でも閉集合でもある部分集合が $\emptyset$ と $X$ だけであることとも言い換えられます。

もう一つの言い換えを使うと、連結性を連続写像で調べられます。2点の集合 $\{0, 1\}$ に離散位相を入れます。$X$ が連結であることは、$X$ から $\{0, 1\}$ への連続写像が定数だけであることと同じです。連続写像 $f: X \to \{0, 1\}$ があれば、$f^{-1}(\{0\})$ と $f^{-1}(\{1\})$ は交わらない開集合で、和集合は $X$ です。$X$ が連結なら一方は空で、$f$ は定数です。逆に、$X$ が空でない開集合 $U, V$ で $X = U \cup V$、$U \cap V = \emptyset$ と分けられるなら、$U$ の点を 0 に、$V$ の点を 1 に写す写像は定数ではなく、$\{0, 1\}$ の開集合 $\emptyset$、$\{0\}$、$\{1\}$、$\{0, 1\}$ の逆像が $\emptyset$、$U$、$V$、$X$ でどれも開集合なので、連続です。

::: examples
- 出発点の $\mathbb{Q}$ は連結ではありません。上の $A$ と $B$ が、$\mathbb{Q}$ を分ける二つの開集合です。
- $\mathbb{R}$ の部分集合 $Y = [0, 1] \cup [2, 3]$ は連結ではありません。[[@topological-spaces]] の確認問題で見たとおり、$[0, 1]$ と $[2, 3]$ はどちらも $Y$ の開集合です。
- 2点以上ある離散位相の空間は連結ではありません。点 $x$ について、$\{x\}$ と $X \setminus \{x\}$ が、交わらない空でない開集合だからです。密着位相の空間は連結です。空でない開集合は $X$ だけなので、空でない二つの開集合は交わってしまいます。
- [[@topological-space]] の応用の、0 と 1 の無限列の空間 $\Sigma$ は連結ではありません。$[0]$ と $[1]$ は交わらない空でない開集合で、和集合は $\Sigma$ です。「先頭のビットを返す」写像 $\Sigma \to \{0, 1\}$ は、連続で、定数ではありません。
:::

$\mathbb{R}$ の部分集合のうち、連結なのは区間です。

::: definition {#def-interval name="区間" en="interval"}
$\mathbb{R}$ の部分集合 $I$ が区間であるとは、次が成り立つことをいう。

$$
\forall p, q \in I\ \ \forall c \in \mathbb{R}: \bigl(p < c < q \Rightarrow c \in I\bigr)
$$
:::

$I$ の2点のあいだにある実数は、すべて $I$ に属する、ということです。$[a, b]$、$(a, b)$、$[0, \infty)$、$\mathbb{R}$ は区間で、1点の集合 $\{a\}$ も区間です。$[0, 1] \cup [2, 3]$ は、1 と 2 のあいだの 1.5 を含まないので区間ではありません。$\mathbb{Q}$ も、1 と 2 のあいだの $\sqrt{2}$ を含まないので、$\mathbb{R}$ の区間ではありません。

::: theorem {#interval-connected name="区間は連結"}
$\mathbb{R}$ の区間は、通常の位相の相対位相で連結である。
:::

::: proof-sketch
1. 区間 $I$ が、交わらない空でない $I$ の開集合 $U, V$ に分けられるとし、$p \in U$、$q \in V$、$p < q$ をとると、$[p, q] \subset I$ である(区間の定義を使う)。
2. $[p, q]$ を半分ずつに分け、左端が $U$ に、右端が $V$ に入る区間 $[a_n, b_n]$ を選び続ける。$b_n - a_n = (q - p)/2^n$ である($I = U \cup V$ であることを使う)。
3. $(a_n)$ はコーシー列で、$(a_n)$ と $(b_n)$ は同じ点 $c \in [p, q]$ に収束する($\mathbb{R}$ の完備性と、閉区間が閉集合であることを使う)。
4. $c$ が $U$ に入れば、$c$ に近い $I$ の点はすべて $U$ に入るが、$V$ の点 $b_n$ が $c$ にいくらでも近づくので矛盾する。$c$ が $V$ に入るときも、$a_n$ について同じである($U, V$ が $I$ の開集合で、交わらないことを使う)。
:::

::: proof
区間 $I$ が連結でないと仮定し、$I = U \cup V$、$U \cap V = \emptyset$ となる、$I$ の空でない開集合 $U, V$ をとります。点 $p \in U$ と $q \in V$ をとると、$U \cap V = \emptyset$ から $p \ne q$ です。$p > q$ なら、$U$ と $V$、$p$ と $q$ の名前をそれぞれ交換して、$p < q$ とします。$I$ は区間なので、$[p, q] \subset I$ です。

$a_0 = p$、$b_0 = q$ とし、$a_n \in U$、$b_n \in V$、$p \le a_n < b_n \le q$ が決まったら、中点 $m = (a_n + b_n)/2$ をとります。$m \in [p, q] \subset I = U \cup V$ なので、$m$ は $U$ か $V$ のどちらかに入ります。$m \in U$ なら $a_{n+1} = m$、$b_{n+1} = b_n$ とし、$m \in V$ なら $a_{n+1} = a_n$、$b_{n+1} = m$ とします。どちらでも $a_{n+1} \in U$、$b_{n+1} \in V$ で、$[a_{n+1}, b_{n+1}] \subset [a_n, b_n]$、$b_{n+1} - a_{n+1} = (b_n - a_n)/2$ です。よって $b_n - a_n = (q - p)/2^n$ です。

$k, l \ge N$ なら $a_k, a_l \in [a_N, b_N]$ なので、$|a_k - a_l| \le (q - p)/2^N$ です。$2^N \ge N$ なので、$\varepsilon > 0$ に対して $N > (q - p)/\varepsilon$ ととれば、すべての $k, l \ge N$ で $|a_k - a_l| < \varepsilon$ です。よって $(a_n)$ は[[コーシー列]]で、$\mathbb{R}$ は[[完備]]なので、ある実数 $c$ に収束します。$|b_n - c| \le (b_n - a_n) + |a_n - c|$ なので、$(b_n)$ も $c$ に収束します。どの $a_n$ も閉区間 $[p, q]$ に属し、$[p, q]$ は閉集合なので、[[@closed-set-limits]] から $c \in [p, q] \subset I$ です。

$c \in U$ とします。$U$ は $I$ の開集合なので、$\mathbb{R}$ の開集合 $U^*$ で $U = U^* \cap I$ となるものがあり、$c \in U^*$ から $B(c, r) \subset U^*$ となる $r > 0$ があります。$b_n \to c$ なので、ある $n$ で $|b_n - c| < r$ となり、$b_n \in [p, q] \subset I$ と合わせて $b_n \in U^* \cap I = U$ です。ところが $b_n \in V$ で、$U \cap V = \emptyset$ に反します。$c \in V$ のときも、$a_n$ について同じ議論で矛盾します。よって $I$ は連結です。
:::

::: drop-assumption
**$\mathbb{R}$ の完備性を外す。** $\mathbb{Q}$ の中で、$K = \{t \in \mathbb{Q} \mid 1 \le t \le 2\}$ は、2点のあいだの有理数をすべて含むので、$\mathbb{Q}$ の中の区間にあたります。ところが、$\{t \in K \mid t^2 < 2\} = (-\sqrt{2}, \sqrt{2}) \cap K$ と $\{t \in K \mid t^2 > 2\} = (\sqrt{2}, \infty) \cap K$ は、$K$ を分ける交わらない空でない開集合なので、$K$ は連結ではありません。証明の手順で $p = 1$、$q = 2$ から中点をとり続けると、$a_n$ と $b_n$ は $\sqrt{2}$ に近づいていきます。証明の3段目で、コーシー列 $(a_n)$ の行き先 $\sqrt{2}$ が $\mathbb{Q}$ の中にないことが原因です。
:::

逆に、区間でない部分集合 $I$ は連結ではありません。$p < c < q$、$c \notin I$ となる $p, q \in I$ と実数 $c$ があり、$I$ は $(-\infty, c) \cap I$ と $(c, \infty) \cap I$ という、交わらない空でない $I$ の開集合に分けられるからです。$\mathbb{R}$ の部分集合では、連結であることと区間であることは同じです。

連結性も、連続写像で保たれます。

::: theorem {#connected-image name="連結集合の連続像"}
位相空間のあいだの連続写像 $f: X \to Y$ について、$X$ が連結なら、[[像]] $f(X)$ は $Y$ の連結な部分集合である。
:::

::: proof-sketch
1. $f(X)$ が連結でないとすると、$Y$ の開集合 $U, V$ で、$U \cap f(X)$ と $V \cap f(X)$ が $f(X)$ を分けるものがある(相対位相の定義を使う)。
2. $f^{-1}(U)$ と $f^{-1}(V)$ は $X$ の開集合である($f$ の連続性を使う)。
3. この二つは空でなく、交わらず、和集合は $X$ なので、$X$ が連結であることに反する(逆像の定義を使う)。
:::

::: proof
$f(X)$ が連結でないと仮定します。相対位相の定義から、$Y$ の開集合 $U, V$ で、$U \cap f(X)$ と $V \cap f(X)$ がどちらも空でなく、交わらず、和集合が $f(X)$ になるものがあります。$f$ は連続なので、$f^{-1}(U)$ と $f^{-1}(V)$ は $X$ の開集合です。

$x \in X$ なら $f(x) \in f(X)$ なので、$f(x)$ は $U$ か $V$ に入り、$x \in f^{-1}(U) \cup f^{-1}(V)$ です。$x$ が両方に入るなら、$f(x) \in (U \cap f(X)) \cap (V \cap f(X)) = \emptyset$ となって矛盾するので、二つは交わりません。$U \cap f(X)$ の点 $f(x)$ をとれば $x \in f^{-1}(U)$ なので、$f^{-1}(U)$ は空ではなく、$f^{-1}(V)$ も同じです。よって $X$ は、交わらない空でない開集合 $f^{-1}(U)$、$f^{-1}(V)$ に分けられ、連結であることに反します。
:::

::: drop-assumption
**連続性を外す。** [[@continuous-map]] の階段関数 $h$($x < 0$ で $h(x) = 0$、$x \ge 0$ で $h(x) = 1$)で、区間なので連結な $\mathbb{R}$ を写すと、像 $\{0, 1\}$ は連結ではありません。$\{0\} = (-1/2, 1/2) \cap \{0, 1\}$ と $\{1\} = (1/2, 3/2) \cap \{0, 1\}$ が、像を分ける開集合だからです。証明の2段目で、$h^{-1}((1/2, 3/2)) = [0, \infty)$ が $\mathbb{R}$ の開集合でないことが原因です。
:::

::: pitfall
- グラフ理論の「連結」は、どの2頂点も辺をたどって結べることで、この駅の連結とは定め方が違います。位相空間の連結は、開集合で二つに分けられないことで、点と点を道で結ぶことは求めていません。どの2点も連続な道で結べること(弧状連結、path-connected)からは連結であることが出ますが、$\mathbb{R}^2$ の部分集合にも、連結なのに弧状連結でないものがあることが知られています。
- 連結かどうかも、位相で決まります。$\mathbb{R}$ は、通常の位相では連結ですが、離散位相では連結ではありません。
:::

::: application {field=cs title="実数の判定プログラム"}
[[@topological-space]] の応用では、近似値の列を読んで実数 $x$ が 0 に等しいかを判定するプログラムは書けないことを見ました。実数全体が連結であることを使うと、もっと強いことが言えます。どの入力でも止まって 0 か 1 を答え、その答えが近似値の列によらず実数だけで決まるプログラムは、どの実数にも同じ答えを返すものしかありません。$x < 0$ かどうかも、$x$ が有理数かどうかも、判定できません。

入力は、$n$ 番目の誤差が $2^{-n}$ 以下になる有理数の近似値の列 $a_1, a_2, a_3, \dots$ とします。プログラムは、$x$ のどの近似値の列を読んでも止まり、答えは近似値の列によらず $x$ だけで決まるとします。この条件がないと、結論は成り立ちません。たとえば $a_1$ だけを読み、$a_1 < 0$ なら 1、そうでなければ 0 を答えるプログラムは、どの入力でも止まりますが、$x = 0$ の近似値の列 $-1/4, 0, 0, \dots$ と $1/4, 0, 0, \dots$ に違う答えを返します。$x$ に答えを対応させる写像を $f: \mathbb{R} \to \{0, 1\}$ とし、$\{0, 1\}$ には離散位相を入れます。

$f$ は連続です。点 $x$ について、誤差が $2^{-n-1}$ 以下になる近似値の列 $a_1, a_2, \dots$($a_n := \lfloor 2^{n+1} x \rfloor / 2^{n+1}$ など。$\lfloor u \rfloor$ は $u$ 以下の最大の整数)を読ませ、プログラムが $a_1, \dots, a_k$ を読んで止まったとします。$|y - x| < 2^{-k-1}$ をみたす実数 $y$ について、$n \le k$ なら $|a_n - y| \le |a_n - x| + |x - y| < 2^{-n-1} + 2^{-k-1} \le 2^{-n}$ です。そこで、先頭が $a_1, \dots, a_k$ で、$k$ 番目より後に $y$ の近似値を続けた列は、$y$ の近似値の列になっています。この列を読ませると、プログラムは同じように動いて、$x$ と同じ答えを返します。よって $f$ は開球 $B(x, 2^{-k-1})$ の上で一定です。どの点のまわりにも $f$ が一定になる開球があるので、$f^{-1}(\{0\})$ と $f^{-1}(\{1\})$ は開集合で、$f$ は連続です。

$\mathbb{R}$ は区間なので連結で、連結な空間から $\{0, 1\}$ への連続写像は定数です。つまり、このプログラムの答えは、どの実数についても同じです。

答えを返さずに動き続けることを許せば、書けるプログラムはあります。近似値 $a_n$ を順に読み、$|a_n| > 2^{-n}$ となったら $a_n$ の符号を答えて止まるプログラムは、$x \ne 0$ なら止まって、$x$ の符号を正しく答えます。$|x| > 2^{-n+1}$ となる $n$ では $|a_n| \ge |x| - 2^{-n} > 2^{-n}$ となり、止まったときは $|a_n - x| \le 2^{-n} < |a_n|$ から、$a_n$ と $x$ の符号は同じだからです。$x = 0$ なら $|a_n| \le 2^{-n}$ が続くので、止まりません。止まる入力の全体は $\mathbb{R} \setminus \{0\}$ で、連結ではありません。
:::

## 中間値の定理 {#intermediate-value requires=connected}

::: summary
連結空間の上の実数値の連続関数は、とった二つの値のあいだの値をすべてとるという定理。
:::

::: why
出発点の $\mathbb{Q}$ 上の $h(x) = x^2 - 2$ が値 0 を飛ばしたのは、[[@connected]] で見たとおり、$\mathbb{Q}$ が連結でなかったからです。定義域が連結なら、[[@connected-image]] から値の集合も連結で、$\mathbb{R}$ の連結な部分集合は区間なので、値を飛ばすことはできないはずです。この駅では、これを定理の形にします。
:::

::: theorem {#intermediate-value-theorem name="中間値の定理"}
連結な位相空間 $X$ から、通常の位相の $\mathbb{R}$ への連続関数 $f$ について、点 $p, q \in X$ と実数 $y$ が $f(p) < y < f(q)$ をみたすなら、$f(c) = y$ となる点 $c \in X$ がある。
:::

::: proof-sketch
1. 像 $f(X)$ は $\mathbb{R}$ の連結な部分集合である(連結集合の連続像を使う)。
2. $y$ が値になければ、$f(X)$ は $(-\infty, y) \cap f(X)$ と $(y, \infty) \cap f(X)$ の和集合で、二つは $f(X)$ の開集合で、交わらない(相対位相の定義を使う)。
3. $f(p)$ は前者に、$f(q)$ は後者に入るので、どちらも空でなく、$f(X)$ が連結であることに反する(連結の定義を使う)。
:::

::: proof
[[@connected-image]] から、$f(X)$ は $\mathbb{R}$ の連結な部分集合です。$f(c) = y$ となる点 $c$ がないと仮定します。$f(X)$ の値はどれも $y$ と異なるので、$y$ より小さいか大きく、

$$
f(X) = \bigl((-\infty, y) \cap f(X)\bigr) \cup \bigl((y, \infty) \cap f(X)\bigr)
$$

です。$(-\infty, y)$ と $(y, \infty)$ は $\mathbb{R}$ の開集合なので、右辺の二つは $f(X)$ の相対位相の開集合で、交わりません。$f(p) < y$ から $f(p)$ は1つ目に、$y < f(q)$ から $f(q)$ は2つ目に入るので、どちらも空ではありません。これは $f(X)$ が連結であることに反します。よって、$f(c) = y$ となる点 $c$ があります。
:::

[[@interval-connected]] から閉区間 $[a, b]$ は連結なので、$[a, b]$ 上の連続関数 $f$ について、$y$ が $f(a)$ と $f(b)$ のあいだにあれば($f(a) < y < f(b)$ か $f(b) < y < f(a)$)、$f(c) = y$ となる $c \in [a, b]$ があります。$f(b) < y < f(a)$ のときは、$p = b$、$q = a$ として定理を使います。$f(c)$ は $f(a)$ とも $f(b)$ とも異なるので、$a < c < b$ です。出発点の中間値の定理は、こうして得られます。

::: examples
- $[1, 2]$ 上の $f(x) = x^2 - 2$ は、$f(1) = -1 < 0 < 2 = f(2)$ なので、$c^2 = 2$ となる $c \in (1, 2)$ があります。実数の中に $\sqrt{2}$ があるということで、証明は、区間の連結性を通して $\mathbb{R}$ の完備性を使っています。出発点の $\mathbb{Q}$ には、この $c$ がありませんでした。
- $f(x) = x^3 - x - 1$ は $f(1) = -1 < 0 < 5 = f(2)$ なので、$(1, 2)$ に根があります(およそ $1.3247$)。同じ考え方で、奇数次の多項式は実数の根をもつことが示せます。次数が奇数なら、正で絶対値を十分に大きくとった所と、負で絶対値を十分に大きくとった所で、値の符号が逆になるからです。
- 連続写像 $T: [0, 1] \to [0, 1]$ は、不動点をもちます。$g(x) := T(x) - x$ とおくと、$g(0) = T(0) \ge 0$、$g(1) = T(1) - 1 \le 0$ です。どちらかが 0 なら、その点が不動点です。どちらも 0 でなければ $g(1) < 0 < g(0)$ なので、$g(c) = 0$、つまり $T(c) = c$ となる $c$ があります。[[@banach-fixed-point]] と違って縮小写像である必要はありませんが、不動点がただ一つかは分からず、逐次近似で近づけるとも限りません。恒等写像 $T(x) = x$ では、どの点も不動点です。$T(x) = 1 - x$ の不動点は $1/2$ だけですが、0 から逐次近似を始めると $0, 1, 0, 1, \dots$ となって近づきません。$\cos$ は $[0, 1]$ を $[\cos 1, 1] \subset [0, 1]$($\cos 1 \approx 0.5403$)に写すので、$[0, 1]$ に不動点があり、その値は $0.739085\ldots$ です。
:::

::: drop-assumption
**連結性を外す。** 連結でない $Y = [0, 1] \cup [2, 3]$ の上の $f(x) = x$ は連続で、$f(1) = 1 < 1.5 < 2 = f(2)$ ですが、$f(c) = 1.5$ となる $c \in Y$ はありません。証明の1段目で、$f(Y) = Y$ が連結でないことが原因です。
:::

::: pitfall
- 定理は $f(c) = y$ となる点があることを言うだけで、その点がただ一つとは限りません。$[-2, 2]$ 上の $f(x) = x^3 - x$ は $f(-2) = -6 < 0 < 6 = f(2)$ で、$f(c) = 0$ となる $c$ は $-1$、$0$、$1$ の三つです。
- 逆は成り立ちません。二つの値のあいだの値をすべてとる関数が、連続とは限りません。$x \ne 0$ で $f(x) = \sin(1/x)$、$f(0) = 0$ と定めた $[-1, 1]$ 上の関数は、0 を含む長さが正のどの区間の上でも $-1$ から $1$ までのすべての値をとり、0 を含まない区間の上では連続なので、この性質をもちます。ところが、$x_n = 1/(\pi/2 + 2\pi n)$ は 0 に収束するのに $f(x_n) = 1$ なので、$f$ は 0 で連続ではありません。
:::

::: application {field=physics title="回転と空間反転"}
3次元の空間の回転と鏡映は、直交行列 $R$($R^\top R = I$)で表されます。$(\det R)^2 = \det(R^\top R) = \det I = 1$ なので、$\det R$ は $1$ か $-1$ です。回転は $\det R = 1$ で、鏡に映す操作や、すべての座標の符号を変える空間反転 $P = -I$ は、$\det P = (-1)^3 = -1$ です。

物体を時刻 $t = 0$ から $t = 1$ まで連続に回すことを、各成分が $t$ の連続関数である直交行列の族 $R(t)$ で表し、$R(0) = I$ とします。$\det R(t)$ は成分の多項式なので、$t$ の連続関数です。もし $\det R(1) = -1$ なら、$\det R(1) = -1 < 0 < 1 = \det R(0)$ なので、[[@intermediate-value-theorem]] から $\det R(t) = 0$ となる $t$ があるはずです。ところが直交行列の行列式は $\pm 1$ なので、そのような $t$ はありません。よって、連続な回転をどれだけ続けても、空間反転にも鏡映にも行き着きません。右手系の座標軸を、回転だけで左手系の座標軸にすることはできない、ということです。

平面では事情が違います。平面の反転 $(x, y) \mapsto (-x, -y)$ は、行列式が $(-1)^2 = 1$ で、角度 $\pi$ の回転として連続に作れます。$R(t)$ を角度 $\pi t$ の回転とすれば、$R(1) = -I$ です。それでも、平面の鏡映 $(x, y) \mapsto (x, -y)$ は行列式が $-1$ なので、平面でも回転では作れません。

物理法則が回転で変わらないことは、連続な変換についての性質です。空間反転で変わらないことは、それとは別に確かめる必要があります。実際、弱い相互作用は空間反転で変わる(パリティの破れ)ことが知られています。
:::

::: application {field=cs title="二分法"}
方程式 $f(x) = 0$ を、区間を半分ずつに狭めて解く方法を、二分法 (bisection method) といいます。$[a, b]$ 上の連続関数 $f$ で $f(a) < 0 < f(b)$ なら、[[@intermediate-value-theorem]] から $[a, b]$ に根があります。中点 $m$ で $f(m) < 0$ なら $[m, b]$ に、$f(m) > 0$ なら $[a, m]$ に区間を狭めます($f(m) = 0$ なら $m$ が根です)。狭めた区間でも、左端の値は負、右端の値は正なので、やはり根があります。[[@interval-connected]] の証明は、これと同じ手順で区間を狭めていく議論でした。

$f(x) = x^3 - x - 1$ を $[1, 2]$ で解くと、最初の5回は次のようになります($f(m)$ は小数第5位を四捨五入)。

| 中点 $m$ | $f(m)$ | 次の区間 |
|---|---|---|
| 1.5 | 0.8750 | $[1, 1.5]$ |
| 1.25 | $-0.2969$ | $[1.25, 1.5]$ |
| 1.375 | 0.2246 | $[1.25, 1.375]$ |
| 1.3125 | $-0.0515$ | $[1.3125, 1.375]$ |
| 1.34375 | 0.0826 | $[1.3125, 1.34375]$ |

$n$ 回で区間の幅は $(b - a)/2^n$ になります。根は区間のどこかにあるので、区間のどの点も、根との差は幅以下です。幅 1 から始めて幅を $10^{-6}$ 未満にするには、$2^{19} = 524288 < 10^6 < 1048576 = 2^{20}$ なので、20 回で足ります。根は $1.3247\ldots$ です。

二分法は、関数について連続性のほかに何も仮定しません。そのかわり、1回で区間の幅は半分にしかなりません。また、計算機では $f(m)$ の符号を近似値で判定するので、根のごく近くで $|f(m)|$ が誤差より小さくなると、符号を誤ることがあります。根に近い $m$ ほど $|f(m)|$ は小さいので、符号を確かめるには、$f(m)$ をそれだけ高い精度で計算する必要があります。
:::

::: review
- 開被覆を使ってコンパクト性を定義し、有限部分被覆をもたない開被覆を挙げて、空間がコンパクトでないことを示せる。
- $\mathbb{R}^m$ ではコンパクトな集合が有界な閉集合であることを証明し、その証明で $\mathbb{R}$ の完備性を使う所を指摘できる。
- コンパクト性が連続写像で保たれることを示し、最大値の定理を開被覆から導ける。
- 連結性を開集合で定義し、連結でない空間の例を挙げ、連結であることを $\{0, 1\}$ への連続写像で言い換えられる。
- 区間が連結であることと、連結性が連続写像で保たれることを示し、中間値の定理を導ける。
- 最大値の定理と中間値の定理について、仮定を一つ外すと結論が成り立たない例を挙げられる。
:::

::: question
$\mathbb{R}$ の部分集合 $[0, 1)$ はコンパクトですか。コンパクトでないなら、有限部分被覆をもたない開被覆を一つ挙げてください。
:::

::: answer
コンパクトではありません。$U_n := [0, 1 - 1/n)$($n \ge 2$)は、$U_n = (-1, 1 - 1/n) \cap [0, 1)$ と書けるので $[0, 1)$ の相対位相の開集合です。$[0, 1)$ のどの点 $x$ も、$n > 1/(1 - x)$ となる $U_n$ に入るので、$(U_n)$ は開被覆です。有限個を選ぶと、その和集合は $n$ がいちばん大きい $U_N$ で、$[0, 1)$ の点 $1 - 1/N$ を含みません。[[@heine-borel]] からも分かります。$[0, 1)$ の点列 $1 - 1/n$ は、$[0, 1)$ にない 1 に収束するので、$[0, 1)$ は $\mathbb{R}$ の閉集合ではなく([[@closed-set-limits]])、コンパクトではありません。
:::

::: question
平面の閉円板 $D = \{(x, y) \in \mathbb{R}^2 \mid x^2 + y^2 \le 1\}$ と開円板 $D^\circ = \{(x, y) \in \mathbb{R}^2 \mid x^2 + y^2 < 1\}$ の上で、$f(x, y) = x + 2y$ は最大値をとりますか。
:::

::: answer
$D$ の上ではとり、$D^\circ$ の上ではとりません。$D$ は原点を中心とする半径 1 の閉球なので閉集合で([[@continuous-map]])、どの2点の距離も 2 以下なので有界です。[[@heine-borel]] から $D$ はコンパクトで、$f$ は連続なので、[[@extreme-value-theorem]] から最大値をとります。$x + 2y \le \sqrt{1^2 + 2^2}\,\sqrt{x^2 + y^2} \le \sqrt{5}$([[@cauchy-schwarz]])で、点 $(1/\sqrt{5}, 2/\sqrt{5})$ での値が $\sqrt{5}$ なので、最大値は $\sqrt{5}$ です。$D^\circ$ の上では、どの点でも $\sqrt{x^2 + y^2} < 1$ から $x + 2y < \sqrt{5}$ です。一方、点 $t(1/\sqrt{5}, 2/\sqrt{5})$($0 < t < 1$)での値 $\sqrt{5}\,t$ は、$t$ を 1 に近づけるといくらでも $\sqrt{5}$ に近づくので、どの値よりも大きい値があり、最大値はありません。$D^\circ$ は閉集合ではないので、コンパクトではありません。
:::

::: question
$\mathbb{R} \setminus \{0\}$ は連結ですか。$\mathbb{R} \setminus \{0\}$ 上の連続関数 $f$ で、$f(-1) = -1$、$f(1) = 1$ なのに、$f(x) = 0$ となる点がないものはありますか。
:::

::: answer
連結ではありません。$(-\infty, 0)$ と $(0, \infty)$ が、$\mathbb{R} \setminus \{0\}$ を分ける交わらない空でない開集合です。$f(x) = x/|x|$($x < 0$ で $-1$、$x > 0$ で $1$)は、どの点 $a$ のまわりでも開球 $B(a, |a|)$ の上で一定なので連続で、$f(-1) = -1$、$f(1) = 1$ ですが、値 0 をとりません。中間値の定理は、定義域が連結であることを仮定しているので、矛盾しません。
:::

::: question
$[0, 1]$ 上の連続関数 $f$ が $f(0) = f(1)$ をみたすとき、$f(c) = f(c + 1/2)$ となる $c \in [0, 1/2]$ があることを示してください。
:::

::: answer
$[0, 1/2]$ 上の連続関数 $g(x) := f(x + 1/2) - f(x)$ を考えます。$g(0) = f(1/2) - f(0)$、$g(1/2) = f(1) - f(1/2) = f(0) - f(1/2) = -g(0)$ です。$g(0) = 0$ なら $c = 0$ でよいです。$g(0) \ne 0$ なら、$g(0)$ と $g(1/2)$ は符号が逆なので、0 は二つの値のあいだにあります。区間 $[0, 1/2]$ は連結なので、中間値の定理から $g(c) = 0$ となる $c \in [0, 1/2]$ があり、このとき $f(c + 1/2) = f(c)$ です。たとえば、1日の気温が連続に変わり、午前0時と翌日の午前0時で同じ値なら、ちょうど12時間離れた二つの時刻で、気温が等しくなります。
:::

::: question
$(0, 1]$ はコンパクトではありません。それでは、$(0, 1]$ 上の連続関数 $f(x) = \sin(1/x)$ は最大値をとりませんか。
:::

::: answer
とります。$x = 2/\pi$(およそ $0.637$)で $\sin(\pi/2) = 1$ となり、$\sin$ の値は 1 を超えないので、最大値は 1 です。最大値の定理は、定義域がコンパクトなら最大値をとることを言うだけで、コンパクトでなければ最大値をとらない、とは言っていません。$(0, 1]$ の上には、$1/x$ のように最大値をとらない連続関数もある、というだけです。
:::
