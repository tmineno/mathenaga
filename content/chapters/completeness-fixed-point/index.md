::: goal
逐次近似が必ず答えにたどり着くための条件を述べ、その理由をひとつの定理から説明できるようになる。
:::

::: goal {field=physics}
力がリプシッツ連続なら、運動方程式の解は初期条件からただ一つに決まる。古典力学の決定論を支えるこの事実を、バナッハの不動点定理から導けるようになります。
:::

::: goal {field=cs}
割引率が 1 未満なら、価値反復法はどの初期値から始めても最適な価値関数に収束する。強化学習の土台にあるこの事実を、バナッハの不動点定理から導けるようになります。
:::

::: motivation
電卓に適当な数を入れて cos のキーを押し続けると、表示は 0.739085… に落ち着きます。この数は方程式 $x = \cos x$ の解です。同じ操作を繰り返して方程式を解くこの方法を、逐次近似(反復法)と呼びます。どれも、写像 $T$ を繰り返し適用して、$x = T(x)$ となる点(不動点)に近づけるという形をしています。
:::

::: motivation {field=physics}
物理には逐次近似がよく出てきます。運動方程式の解をピカールの方法で作るとき、散乱問題をボルン級数で解くとき、自己無撞着場の計算を回すとき、どれもこの形です。
:::

::: motivation {field=cs}
情報科学には、同じ計算を繰り返して答えに近づく方法がたくさんあります。強化学習の価値反復法、PageRank の計算、ニュートン法による求根は、どれもこの形です。
:::

ただし、繰り返せば必ず答えにたどり着くとは限りません。うまくいかない原因は二つあります。

1. 列の項どうしは近づき合っていくのに、行き着く先の点が空間の中にない。
2. そもそも列の項どうしが近づき合わない。

この章では、1 を防ぐ条件として[[completeness|完備性]]を、2 を防ぐ条件として[[contraction|縮小写像]]を導入します。両方がそろえば逐次近似は必ず成功する。これが到達目標の[[banach|バナッハの不動点定理]]です。

## コーシー列 {#cauchy-sequence requires=metric-space}

::: summary
先に進むほど、項どうしがいくらでも近づき合う点列。
:::

::: why
[[点列の収束]]を確かめるには、行き先の点 $x$ を先に知っている必要があります。逐次近似では、その行き先こそが求めたい答えです。だから、列そのものだけを見て判定できる基準が要ります。
:::

::: definition {name="コーシー列" en="Cauchy sequence" aliases="コーシー点列"}
[[距離空間]] $(X, d)$ の点列 $(x_n)$ がコーシー列であるとは、次が成り立つことをいう。

$$
\forall \varepsilon > 0,\ \exists N,\ \forall m, n \ge N:\quad d(x_m, x_n) < \varepsilon
$$
:::

読み方:どんなに小さな許容誤差 $\varepsilon$ を指定されても、ある番号 $N$ から先の項は、どの二つをとっても距離が $\varepsilon$ 未満に収まります。

::: examples
- 収束する点列はコーシー列です。極限を $x$ とすると、三角不等式から $d(x_m, x_n) \le d(x_m, x) + d(x, x_n)$ で、右辺の二つの項はどちらもいくらでも小さくできます。
- 逆は成り立ちません。有理数全体 $\mathbb{Q}$(ふつうの距離)で、$\sqrt{2}$ の小数を一桁ずつ伸ばした列 $1,\ 1.4,\ 1.41,\ 1.414,\ \dots$ はコーシー列ですが、$\mathbb{Q}$ の中に極限はありません。
:::

::: pitfall
隣り合う項の距離 $d(x_{n+1}, x_n)$ が 0 に近づくだけでは、コーシー列とは言えません。$x_n = \sqrt{n}$ では $\sqrt{n+1} - \sqrt{n} \to 0$ ですが、列は限りなく大きくなります。定義が隣どうしではなく、番号 $N$ より先のすべての二項を見ているのはこのためです。
:::

## 完備性 {#completeness requires=cauchy-sequence}

::: summary
コーシー列が必ず収束する、穴のない空間。
:::

::: definition {name="完備" en="complete" aliases="完備性"}
距離空間 $(X, d)$ のすべての[[コーシー列]]が $X$ の点に収束するとき、$X$ は完備であるという。
:::

::: examples
- 完備:$\mathbb{R}$、$\mathbb{R}^n$(ユークリッド距離)、閉区間 $[a, b]$
- 完備でない:$\mathbb{Q}$([[@cauchy-sequence]] の例)、開区間 $(0, 1)$(列 $1/n$ の行き先 0 が空間の外にある)
:::

同じ集合でも、距離の選び方で完備かどうかが変わることがあります。完備性は、集合ではなく距離空間の性質です。

::: application {field=physics title="関数の空間"}
区間 $[a, b]$ 上の連続関数全体 $C[a, b]$ に、二通りの距離を入れてみます。

$$
d_\infty(f, g) = \sup_{t \in [a, b]} |f(t) - g(t)|, \qquad d_1(f, g) = \int_a^b |f(t) - g(t)|\,dt
$$

$d_\infty$ では完備です。$d_\infty$ での収束は[[一様収束]]のことで、連続関数の一様収束極限はまた連続だからです。

$d_1$ では完備ではありません。$[-1, 1]$ 上の連続関数 $f_n(t) = \max(-1, \min(1, nt))$ は原点付近の傾きがどんどん急になる列で、$d_1$ についてはコーシー列ですが、近づいていく先は階段関数です。

量子力学で状態空間に $L^2$ を使う理由の一つがここにあります。$L^2$ は、連続関数の空間を $L^2$ 距離について完備にしたものと見ることができます([[@hilbert-spaces]])。
:::

::: application {field=cs title="価値関数の空間"}
強化学習では、状態の集合 $S$ 上の関数 $V: S \to \mathbb{R}$ を価値関数と呼びます。有界な価値関数の全体 $B(S)$ に sup 距離

$$
d_\infty(V, W) = \sup_{s \in S} |V(s) - W(s)|
$$

を入れた空間は完備です。価値反復法が動く舞台はこの空間で、完備性があるおかげで、反復の行き先が空間の外に逃げません。
:::

## 縮小写像 {#contraction requires=metric-space}

::: summary
写すたびに、どの二点の距離も一定の割合以下に縮む写像。
:::

::: definition {name="縮小写像" en="contraction mapping"}
写像 $T: X \to X$ が縮小写像であるとは、ある定数 $0 \le k < 1$ があって、すべての $x, y \in X$ について

$$
d(T(x), T(y)) \le k\, d(x, y)
$$

が成り立つことをいう。$k$ を縮小率と呼ぶ。
:::

::: examples
閉区間 $[0, 1]$ 上の $\cos$ を考えます。$\cos$ は $[0, 1]$ を $[\cos 1, 1] \subset [0, 1]$ に写し、平均値の定理から

$$
|\cos x - \cos y| \le \sin 1 \cdot |x - y|, \qquad \sin 1 \approx 0.84
$$

なので、縮小率 $k = \sin 1$ の縮小写像です。電卓で cos を 2 回押せば値は $[0, 1]$ に入ります。出発点の実験が収束したのはこのためです。
:::

::: pitfall
大事なのは、$k$ が 1 未満の定数であることです。「距離が縮む」だけでは足りません。[[@banach]] の「仮定を外すと」で反例を見ます。
:::

::: application {field=cs title="ベルマン作用素"}
有限個の状態と行動をもつマルコフ決定過程で、価値関数 $V$ を

$$
(TV)(s) = \max_{a} \Bigl( r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V(s') \Bigr)
$$

に写す写像 $T$ をベルマン作用素と呼びます。最大値どうしの差は差の最大値で抑えられ、遷移確率の和は 1 なので、$d_\infty(TV, TW) \le \gamma\, d_\infty(V, W)$ が成り立ちます。割引率が $0 \le \gamma < 1$ なら、$T$ は縮小率 $\gamma$ の縮小写像です。
:::

## バナッハの不動点定理 {#banach requires=completeness,contraction}

::: summary
完備な空間の縮小写像には不動点がただ一つあり、逐次近似は必ずそこに収束する。
:::

::: theorem {#banach-fixed-point name="バナッハの不動点定理"}
$(X, d)$ を空でない[[completeness|完備]]距離空間、$T: X \to X$ を縮小率 $k$ の[[縮小写像]]とする。このとき次が成り立つ。

1. $T$ の不動点 $x^* = T(x^*)$ がただ一つ存在する。
2. どの初期値 $x_0$ から始めても、$x_n = T(x_{n-1})$ で作った列は $x^*$ に収束する。
3. 誤差は $d(x_n, x^*) \le \dfrac{k^n}{1-k}\, d(x_1, x_0)$ で抑えられる。
:::

::: proof-sketch
1. 一歩の移動距離は毎回 $k$ 倍以下に縮む。等比級数で足し上げると、列はコーシー列になる(縮小性を使う)。
2. $X$ は完備なので、列は $X$ のある点 $x^*$ に収束する(完備性を使う)。
3. $x^*$ が不動点であることと、不動点が一つしかないことは、縮小性の不等式から一行で出る(縮小性を使う)。
:::

::: proof
**1.** 帰納法により $d(x_{n+1}, x_n) \le k^n\, d(x_1, x_0)$。$m > n$ のとき三角不等式を繰り返し使うと

$$
d(x_m, x_n) \le \sum_{j=n}^{m-1} d(x_{j+1}, x_j) \le \sum_{j=n}^{m-1} k^j\, d(x_1, x_0) \le \frac{k^n}{1-k}\, d(x_1, x_0).
$$

$0 \le k < 1$ より右辺は $n \to \infty$ で 0 に近づくので、$(x_n)$ はコーシー列。

**2.** $X$ は完備なので、$x_n \to x^*$ となる $x^* \in X$ がある。

**3.** $T(x_n) = x_{n+1}$ を使うと

$$
d(T(x^*), x^*) \le d(T(x^*), T(x_n)) + d(x_{n+1}, x^*) \le k\, d(x^*, x_n) + d(x_{n+1}, x^*) \to 0.
$$

よって $T(x^*) = x^*$。不動点 $y^*$ がもう一つあれば $d(x^*, y^*) = d(T(x^*), T(y^*)) \le k\, d(x^*, y^*)$ で、$k < 1$ より $d(x^*, y^*) = 0$。

**誤差評価.** 1 の不等式で $m \to \infty$ とする。三角不等式から $d(x_m, x_n) \to d(x^*, x_n)$ なので、主張 3 が得られる。
:::

主張 3 の誤差評価は、何回反復すれば必要な精度に届くかを、計算する前に教えてくれます。

::: drop-assumption
**完備性を外す。** $X = [1, 2] \cap \mathbb{Q}$、$T(x) = \dfrac{x}{2} + \dfrac{1}{x}$ とします。$T$ は有理数を有理数に写し、値は $[\sqrt{2}, 3/2]$ に入るので $X$ を $X$ に写します。$|T'(x)| \le 1/2$ なので縮小率 $1/2$ の縮小写像です。それでも $X$ に不動点はありません。$T(x) = x$ を解くと $x^2 = 2$ で、行き先 $\sqrt{2}$ は $\mathbb{Q}$ の外にあります。

**「1 未満の定数 $k$」を「距離が縮む」に弱める。** $X = [1, \infty)$($\mathbb{R}$ の閉集合なので完備)、$T(x) = x + \dfrac{1}{x}$ とします。$x \ne y$ なら

$$
|T(x) - T(y)| = |x - y|\left(1 - \frac{1}{xy}\right) < |x - y|
$$

で距離は必ず縮みますが、$T(x) > x$ なので不動点はありません。$x, y$ が大きくなるほど縮み方が弱まり、一定の割合 $k$ で抑えられないことが原因です。
:::

::: application {field=physics title="ボルン級数"}
散乱理論のリップマン–シュウィンガー方程式 $\psi = \varphi + G_0 V \psi$ も不動点の形です。右辺を写像とみると、$\|G_0 V\| < 1$ なら縮小写像になり、ボルン級数 $\psi = \varphi + G_0 V \varphi + (G_0 V)^2 \varphi + \cdots$ が収束します。相互作用が弱ければ摂動展開が使えるという直観を、条件として書いたものの一つです。ノルムは [[@norm-inner-product]] で扱います。
:::

::: application {field=cs title="価値反復法の収束"}
[[@completeness]] と [[@contraction]] から、ベルマン作用素 $T$ は完備な空間 $B(S)$ 上の縮小写像です。この定理により、価値反復法 $V_{k+1} = T V_k$ はどの初期値からでも、ただ一つの不動点 $V^*$(最適価値関数)に収束します。主張 3 の誤差評価

$$
d_\infty(V_k, V^*) \le \frac{\gamma^k}{1-\gamma}\, d_\infty(V_1, V_0)
$$

から、必要な精度に届くまでの反復回数を前もって見積もれます。
:::

## ピカールの定理 {#picard-lindelof requires=banach}

::: summary
微分方程式を解くことを、関数の空間で不動点を探すことに言い換える。
:::

初期値問題

$$
\frac{dx}{dt} = f(t, x(t)), \qquad x(0) = x_0
$$

を考えます。$x$ は $\mathbb{R}^n$ に値をとる関数です。両辺を積分すると、これは積分方程式

$$
x(t) = x_0 + \int_0^t f(s, x(s))\,ds
$$

と同値です。右辺を、関数 $x$ を別の関数に写す写像 $T$ とみなすと、解とは $T$ の不動点にほかなりません。舞台は、区間 $[0, h]$ 上の連続関数の空間 $C([0, h], \mathbb{R}^n)$ に sup 距離 $d_\infty$ を入れたもので、この空間は完備です。

::: definition {#lipschitz name="リプシッツ連続" en="Lipschitz continuous"}
関数 $f(t, x)$ が $x$ についてリプシッツ連続であるとは、ある定数 $L$ があって、すべての $t$ と $x, y$ について $|f(t, x) - f(t, y)| \le L\,|x - y|$ が成り立つことをいう。
:::

$f$ が連続で、$x$ について[[リプシッツ連続]](定数 $L$)だとすると、

$$
|T(x)(t) - T(y)(t)| \le \int_0^t L\,|x(s) - y(s)|\,ds \le Lh\; d_\infty(x, y)
$$

なので $d_\infty(T(x), T(y)) \le Lh\, d_\infty(x, y)$。$h < 1/L$ ととれば $T$ は縮小写像になり、バナッハの不動点定理から次が言えます。

::: theorem {#picard-lindelof-short name="ピカールの定理(短時間版)"}
上の条件のもとで、初期値問題は $[0, h]$ 上にただ一つの解をもつ。さらに、ピカールの逐次近似 $x_{k+1} = T(x_k)$ はその解に[[一様収束]]する。
:::

::: proof-sketch
1. 初期値問題を積分方程式に書き換え、解を求めることを、関数を関数に写す写像の不動点を探すことに言い換える。
2. 区間上の連続関数の空間に sup 距離を入れると、完備な距離空間になる(完備性を使う)。
3. 区間の長さをリプシッツ定数の逆数より短くとると、リプシッツ条件からこの写像は縮小写像になる(縮小性を使う)。
4. バナッハの不動点定理から、不動点すなわち解がただ一つ存在し、逐次近似はそこに収束する。sup 距離での収束なので、一様収束である。
:::

リプシッツ性が初期値の近くでしか成り立たない場合は、空間を初期値の近くの関数に制限して同じ議論をします。

::: drop-assumption
$x' = 3x^{2/3}$、$x(0) = 0$ を考えます。$x(t) = 0$ も $x(t) = t^3$ も解なので、解は一つに決まりません。右辺の $3x^{2/3}$ は $x = 0$ でリプシッツ連続ではないため、ピカールの定理が使えません。
:::

::: application {field=physics title="決定論とノートンのドーム"}
ニュートンの運動方程式も、位置と速度を並べれば一階の形 $dx/dt = f(t, x)$ に書けます。力がリプシッツ連続なら、初期条件が運動をただ一つに決めます。これが古典力学の決定論の数学的な裏付けです。

逆に、単位を整えた運動方程式 $\ddot r = \sqrt{r}$($r \ge 0$)を $r(0) = 0,\ \dot r(0) = 0$ で解くと、$r(t) = 0$ のほかに、任意の $T \ge 0$ について

$$
r(t) = \begin{cases} 0 & (t \le T) \\ \dfrac{(t - T)^4}{144} & (t \ge T) \end{cases}
$$

も解になります。頂上に静止した質点が任意の時刻に動き出しうる例(ノートンのドーム)として、物理の哲学で議論されています。
:::

::: review
- 極限を知らなくても、点列が収束しそうかを判定できる(コーシー列)。
- 空間に穴があるかどうかを判定でき、それが距離の選び方で変わることを説明できる(完備性)。
- 逐次近似が収束するための十分条件を述べ、証明の三つの段階を説明できる(バナッハの不動点定理)。
- 微分方程式の解の一意性が、リプシッツ条件から来ることを説明できる(ピカールの定理)。
:::

::: question
開区間 $(0, 1)$ 上の $T(x) = x/2$ は縮小写像ですか。不動点はありますか。
:::

::: answer
縮小率 $1/2$ の縮小写像です。しかし不動点の候補 0 は $(0, 1)$ の外にあり、不動点はありません。$(0, 1)$ が完備でないので、バナッハの不動点定理の仮定をみたしていません。
:::

::: question
$\mathbb{R}$ 上の $T(x) = x + 1$ は縮小写像ですか。
:::

::: answer
いいえ。$|T(x) - T(y)| = |x - y|$ なので距離はまったく縮まず、縮小率を 1 未満にとれません。実際、不動点はありません。
:::

::: question
ピカールの議論で $h < 1/L$ としたのはなぜですか。
:::

::: answer
縮小率 $k = Lh$ を 1 未満にして、$T$ を縮小写像にするためです。$h$ を大きくとると、この評価では縮小性が保証されません。
:::
