MathEnaga は、大学数学を他分野の学生に届ける静的ウェブサイトと、それを原稿から作るオーサリングツールである。この README は仕様書一式の入口で、コンセプトと用語を定める。個々の振る舞いは下の仕様書に書く。この `docs/spec/` が仕様の正本である。

## 概要

| 項目 | 内容 |
|---|---|
| 目的 | 大学数学の裾野を広げる |
| 想定読者 | 物理・情報・経済など他分野の学生 |
| 最初の題材 | 集合位相(距離空間から、ヒルベルト空間と多様体まで) |
| 最初の分野 | 理論物理と情報科学 |
| 提供価値 | 教科書の「物語」と、辞典型サイトの「地図」を両立させる |

## コンセプト

学習の構造を鉄道の路線図で表し、読者がいつも現在地と行き先を見られるようにする。

- 駅は概念・定理、路線は内容のまとまり、章は路線上の区間、終着駅は分野の目標定理にあたる。
- 路線は内容で名付け、分野の名前を付けない。同じ路線を、複数の分野の読者が通る。
- 分野ごとに目標(終着駅と途中下車駅)を決める。分野の路線図には、目標に必要な駅だけを描く。
- 終着駅は、その分野で実際に使う定理にする。例:理論物理はヒルベルト空間と多様体、情報科学はバナッハの不動点定理。
- 距離空間をハブにする。多くの目標は、距離空間の範囲で到達できる。
- 出発駅の手前に「0番線」(記号・定義・証明の読み方)を置く。
- 章の本文はすべての分野で共通にする。分野ごとに書き分けるのは、ゴール・出発点・応用の3つだけ。

## 用語

仕様では、次の言葉を次の意味だけで使う。コードの名前とコメントでもこの言葉を使う。「ルート」という言葉は使わない。

| 用語 | 意味 | データ上の名前 |
|---|---|---|
| 分野 | 読者の専門分野。理論物理、情報科学など。目標と、路線図に描く範囲を決める | field(分野ファイル) |
| 路線 | 内容のまとまりで引いた線。0番線、本線、解析線、幾何線など | line(路線ファイル) |
| 幹線・支線 | 幹線は路線図で横一列に並べる路線、支線は幹線か、路線ファイルでそれより前にある支線から分岐する路線 | layout の有無 |
| 駅 | 概念・定理の単位。路線図の点で、章の中の2段目の見出し1つにあたる | 見出しの ID |
| 章 | 1ページにあたる単位。1つの路線上で続いた駅の区間 | 章フォルダの index.md |
| 未執筆の章 | まだ書いていない章。路線図(全体の図)に予定として灰色で描き、ページは作らない | 路線ファイルの planned |
| 読む順 | 駅を、章番号の順、章の中では見出しの順に並べた順序 | なし(ツールが導く) |
| 前提 | 駅が論理的に依存している駅。読む順で必ず前にある | requires |
| 終着駅・途中下車駅 | 分野の最終目標の駅と、途中の目標の駅 | goals の kind(final / partial) |
| 分野の範囲 | 分野の目標駅から前提をさかのぼって集めた駅 | なし(ツールが導く) |
| 範囲外 | 選んだ分野の範囲に入らない駅。範囲の駅を1つも含まない章は範囲外の章 | なし(ツールが導く) |
| 参照範囲 | 章の駅と、そこから前提をたどれる駅。`[[名前]]` を探す範囲で、分野とは関係しない | なし(ツールが導く) |
| 乗換駅 | 別の路線の駅から前提にされている駅 | なし(ツールが判定) |
| 分岐駅 | 路線図で支線がほかの路線から分かれる駅。支線ごとに1つ以上あり、2つ以上あれば支線はそれらの路線から合流する | なし(ツールが判定) |
| 表示番号 | 章・駅・別行立ての式に振る番号。第3章、A01、(3.1) など | なし(ツールが振る) |
| 共通版・分野版 | すべての分野向けの内容と、特定の分野向けに書く内容 | field 属性の有無 |
| front matter | 章の md の冒頭にある YAML | — |
| 見出し属性 | 見出しの末尾に付ける {…} | — |
| 定義索引 | 全定義をまとめた1つの JSON | defs.json |
| テスト用原稿 | 受け入れテストで値を確かめるときの入力。2026-11-02 の `content/` を写して固定したもの([ADR-004](../adr/ADR-004-frozen-test-manuscript.md))。原稿を書いても変わらず、変えるのはテストの意図を変えるときだけ。10章で、第0章(reading-basics)・第1章(convergence-metric)・第2章(open-sets-continuity)・第3章(completeness-fixed-point)・第4章(norm-inner-product)は完成稿、ほかの章は路線図と検証のための仮原稿。路線ファイルは [content-format.md](content-format.md) の例のとおり(0番線の `style: dotted`、解析線と幾何線の `color_dark`)である。路線ファイルには、未執筆の章として第10〜13章(解析線に2章、幾何線に2章)と第16・17章(集合線に2章)を planned で書いてある(各3駅) | `tests/fixtures/content/` |
| 今の原稿 | 書き進めている原稿。受け入れテストでは、値を書かない不変条件だけを確かめる([ADR-004](../adr/ADR-004-frozen-test-manuscript.md)) | `content/` |
