## Goal

ビルドが章グラフから路線図の SVG を自動で作る。読者は路線図で、各章がどの路線のどこにあるか、路線をまたいでどの章を前提にしているか、今いる章、分野の到達目標、そこまでに通る章、まだ書かれていない章を一目で見られ、章の札と駅から該当する章へ移動できる。執筆者は路線図を手で描かず、調整は路線ファイルの layout・start と路線の順だけで行う。

## Non-goals

- 札や駅の座標を手で指定すること。調整できるのは支線の向き(layout)、始発の路線にするか(start)、路線ファイルの順だけ。
- requires をすべて矢印で描くこと。矢印にするのは、路線図の線をたどって届かない、路線をまたぐ前提だけ(「前提の矢印」)。同じ路線の中の前提と、線をたどって分かる前提は描かない。
- 駅と駅を線でつなぐこと。路線の線・分岐の線・前提の矢印は章の札どうしをつなぎ、どの駅かはラベルで示す。
- 線どうしの交差をなくすこと。交差は許し、札・文字・ラベルと線が重ならないことと、前提の矢印どうしが同じ溝の中で重ならないことだけを保証する。
- 未執筆の章を分野の図に描くこと。未執筆の章は分野の範囲に入らないので、全体の図にだけ描く。

## Inputs / Outputs

### 図の種類

| 図 | 描く駅 | 未執筆の章 | 到達目標の印 | 今の章の強調 | 使う場所 |
|---|---|---|---|---|---|
| 全体の路線図 | すべての駅 | 描く | なし | なし | トップページ |
| 分野の路線図 | 分野の範囲の駅 | 描かない | その分野の到達目標 | なし | 分野の入口ページ |
| 章ページの路線図 | 分野ごとの図(分野の範囲)と、全体の図 | 全体の図にだけ描く | 分野の図にはその分野の到達目標 | 今の章の札 | 章ページ。選んだ分野で出し分ける |

どの図でも、描く駅のある章ごとに章の札を1枚描き、その章の描く駅を札の中に並べる(「配置」)。描く駅のない章の札は描かない。章ページには、分野の数 + 1 枚の図を入れる。表示番号は図によって変わらない(分野の図で G03 を描かなくても、G04 は G04 のまま)。

### 分岐駅

支線 L(始発の路線を除く。「始発の路線」)の、ある図での分岐駅は、次のように決める。分岐駅は1つ以上あり、L はそのすべてから分かれる。分岐駅が2つ以上あれば、L はそれらの路線から合流する路線になり、図にループができる(requires は循環しないので、ループは前提の循環ではない)。

1. その図に描く L の駅のうち、読む順で最初の駅を s とする。
2. s の requires が指す駅のうち、その図に描く駅で、幹線か、路線ファイルで L より前にある支線にあるものを集める。これを候補とする。
3. 候補のうち、ほかの候補から requires をさかのぼって届く駅を除く(ほかの分岐駅を通して前提がつながっているので、線を引かない)。
4. 幹線にない候補が残っていれば、幹線の候補を除く(幹線はすべての支線の根なので、ほかの路線を通してつながっている)。
5. 残った候補を路線ごとに分け(幹線の路線はまとめて1つとみなす)、路線ごとに読む順で最も後ろの駅を選ぶ。選んだ駅が分岐駅である。分岐駅のうち読む順で最も後ろの駅を主な分岐駅、分岐駅のある路線を L の親の路線とよぶ。

全体の図では、未執筆の章の駅も描く駅に含める。未執筆の駅の requires は、路線ファイルの planned に書いたものとする。章に書いた requires はその章の最初の駅の requires、駅ごとに書いた requires はその駅の requires で、書いていなければ空とする([content-format.md](content-format.md))。

描く駅の集合は requires をさかのぼって閉じていて、requires は読む順で前の駅しか指さない。このため s の requires はすべて L の外の路線にあり、図に描かれている。2 で駅が1つもなければ E12 にする。路線ファイルで L より後ろにある支線の駅は候補にしないので、親の路線は必ず路線ファイルで L より前にあり、支線の親子は循環しない。

分岐駅は図ごとに決まる。分野の図では描く駅が違うので、全体の図と同じ分岐駅になるとは限らない。分岐駅の判定と E12 の検査は、全体の図と、分野ごとの図のそれぞれで行う(章ページの図は、描く駅が全体の図か分野の図と同じなので、配置も同じになる)。

### 前提の矢印

ある図での前提の矢印は、次のように決める。

1. その図に描く駅のあいだの requires の辺 u → v(v の requires が u を指す)のうち、u と v が別の路線にあるものを集める。
2. 支線の分岐の線として描く辺(分岐駅 → 支線の最初の駅)を除く。
3. 路線図の線がつなぐ関係を、その図に描く駅のあいだの requires の辺すべてに、次の並びの辺を加えたものとする。
   - 同じ路線で、その図に描く駅のうち読む順で隣り合う2駅の、前の駅 → 後の駅。
   - 幹線の路線どうしでは、その図に描く駅のある幹線の路線を路線ファイルの順に並べ、隣り合う2路線の、前の路線の最後の駅 → 後の路線の最初の駅(幹線の路線は1列につないで描くため)。
4. 1 の辺 u → v のうち、3 の関係からその辺だけを除いても u から v へたどれるものを除く(線をたどれば分かる前提なので、矢印にしない)。
5. 残った辺を、u を含む章と v を含む章の組ごとにまとめる。まとめた1組を1本の前提の矢印とし、u の章の札から v の章の札へ向ける。ラベルは、その組の u の駅名を読む順に「・」でつないだもの(同じ駅は1回だけ)とする。

全体の図では、未執筆の駅の requires(「分岐駅」の最後の段落)も使う。

例:テスト用原稿の全体の図では、路線をまたぐ requires は8本ある(未執筆の章の requires 1本を含む)。そのうち3本(metric-space → cauchy-sequence、continuous-map → topological-space、sets-maps → 集合線の第16章の最初の駅)は分岐の線で、5本は線をたどって届く(たとえば metric-space → contraction は、分岐の線と解析線の並びをたどって届く)ので、前提の矢印はない。

前提の矢印は図ごとに決まる。分野の図では描く駅が違うので、全体の図と同じ矢印になるとは限らない。

### 始発の路線

路線ファイルで `start: true` を書いた支線は、始発の路線とする。始発の路線は、ほかの路線から分かれずに、自分の最初の章から始まる。

1. 始発の路線は分岐駅を持たず、分岐の線を引かない。最初の駅の requires が指すほかの路線の駅は、ほかの路線をまたぐ前提と同じく、「前提の矢印」の規則で矢印にする(線をたどって届くものは矢印にしない)。
2. 始発の路線の最初の駅(その図に描く駅のうち読む順で最初の駅)の requires は、幹線か、路線ファイルでその路線より前にある路線の駅だけを指す。路線ファイルで後ろにある路線の駅を指していれば E12 にする。requires がなくてもよい。
3. 路線ファイルで後ろにある支線は、始発の路線の駅から分かれてよい(始発の路線は親の路線になれる)。
4. 始発の路線には分岐駅がないので、章ページの「ほかの路線への案内」には出ない([site.md](site.md))。読者は、始発の路線の最初の章のページの「前提」と、路線図の前提の矢印で、つながりを知る。

### 配置

1. 図は、段(横の並び)と列(縦の並び)からなる格子で、章の札を1枚ずつ格子の升に置く。列の幅はどの列も同じで、札の幅は列の幅より狭く、隣り合う列の札のあいだには縦の溝(列の溝)が空く。段の高さは、その段で最も高い札の高さとし、隣り合う段のあいだには横の溝(段の溝)を空ける。列の溝と段の溝には札を置かないので、列の溝は図の上端から下端まで、段の溝は左端から右端まで、札にさえぎられない。
2. 幹線の路線を、路線ファイルの順に1つの段(幹線の段)に並べる。幹線の章は、読む順に左の列から1列ずつ置く。未執筆の章は、章番号の順で読む順に入る。
3. 支線は路線ファイルの順に置き(親の路線は先に置かれている)、1つの支線を1つの段に置く。支線は、幹線より上の段、下の段、幹線と同じ高さのどれかに置く。
   - 親の路線がすべて幹線と同じ高さにあれば、layout で決める。`up` は上の段、`down` は下の段、`right` は 4 に従う。
   - 親の路線に上の段の路線があり、下の段の路線がなければ上の段、その逆なら下の段に置く。layout の値は使わない。
   - 上の段と下の段の両方に親の路線があれば、幹線と同じ高さに置く(上下の路線がひし形に合流する)。
   - 始発の路線は、layout で決める(`up` は上の段、`down` は下の段)。
   上の段と下の段には、路線ファイルの順に、幹線から遠い段へ1路線ずつ置いていく(始発の路線も同じ順に数える)。親の路線は路線ファイルで前にあるので、支線は必ず親より幹線から遠い段に来る。
4. 幹線と同じ高さで幹線より右に置ける支線は、図ごとに1つだけで、路線ファイルの順で先の支線が使う。`right` の支線は、分岐駅がその図の幹線の最後の駅なら、幹線と同じ高さで右へ続ける。そうできないとき(分岐駅が幹線の最後の駅でない、またはほかの支線がそこを使った)は `down` と同じに描く。上下の両方から合流する支線がそこに置けないときは、主な分岐駅のある段の側に描く。どちらの場合も通知 N03 を出す。
5. 支線の章は、読む順に左から1列ずつ置く。最初の章は、主な分岐駅を含む章の列の、次の列に置く。幹線と同じ高さに置く支線では、最初の章を、幹線の最後の章と、分岐駅を含むすべての章のどれよりも右にある最初の列に置く。始発の路線では、最初の章を、最初の駅の requires が指す駅(その図に描くもの)を含む章のうち最も右の章の列の、次の列に置く。そのような駅がなければ、左端の列に置く。
6. 章の札の中には、上から次の順に書く。
   - 「第N章」の行。未執筆の章では「未執筆」、章ページの今の章では「このページ」を、同じ行に添える。
   - 章のタイトル。札の幅で2行まで折り返し、それでも収まらなければ末尾を「…」で省く。
   - 駅の行。その図に描くその章の駅を、読む順に1行ずつ並べる。行には表示番号の札と駅名を書く(未執筆の駅には表示番号を書かない)。駅名は札の幅で折り返す。折り返す位置はツールが決め、「の」「・」の後ろを優先する。
   札の高さは、これらが入る高さと、「倍率ごとの表示」の縮小したときの文字(章のタイトルは3行まで)が入る高さの大きいほうにする。
7. 路線の線:同じ路線で列が隣り合う2枚の札を、「第N章」の行の高さで、前の札の右の辺から後の札の左の辺まで、横の線でつなぐ。幹線の路線どうしも、路線ファイルの順に同じようにつなぐ。
8. 分岐の線:分岐駅ごとに、分岐駅を含む章の札から、支線の最初の章の札へ線を引く。線は、分岐駅を含む札の、支線のある側の辺(支線がそれより上の段にあれば上の辺、下の段にあれば下の辺)から、隣の段の溝へ斜めに出る。そこから段の溝を横に進み、支線の最初の札のすぐ左の列の溝を縦に進んで、「第N章」の行の高さで札の左の辺に入る(最初の札が分岐駅の章の次の列にあれば、横に進む部分はない)。線のそばの段の溝に「〈分岐駅の駅名〉から」と書く。
9. 前提の矢印の経路:矢印は直角に折れる線で、札の中を通らず、段の溝と列の溝だけを通る。
   - 始点の札の、終点の側の辺(終点の段が上にあれば上の辺、下にあれば下の辺、同じ段なら上の辺)から出て、その辺に接する段の溝に入る。終点の札には、始点の側の辺(始点の段が上にあれば上の辺、下にあれば下の辺、同じ段なら上の辺)から入る。
   - 始点から出た段の溝と、終点に入る段の溝が同じなら、その溝を横に進んで終点に入る。違えば、列の溝を1本だけ縦に通る。通る列の溝は、終点が始点と同じ列か右の列にあれば終点のすぐ左の溝、左の列にあれば終点のすぐ右の溝とする。
   - 同じ札の同じ辺に出入りする矢印と分岐の線は、辺の上で間をあけて並べる。
   - 同じ札の同じ辺から出る矢印のうち、前提にされる駅が同じもの(ラベルが同じもの)は束ねる。束ねた矢印は、辺の1点から出て、出た段の溝の1つのトラックを共通の区間として横に進み、それぞれの終点へ向かう位置で枝分かれする。枝分かれする位置は、終点に入る段の溝が共通の区間と同じなら終点の札の辺の上、違えば通る列の溝である。枝分かれした先は束ねない矢印と同じ経路で、矢じりは終点ごとに描く。共通の区間は、最も遠くで枝分かれする矢印の線の一部として描き、ほかの矢印の線は枝分かれする点から始める。
   - 同じ溝の中で、矢印や分岐の線の区間が溝に沿った範囲で重なるときは、溝の中の別の位置(トラック)に並べる。トラックが足りなければ溝を広げる。
10. ラベル:前提の矢印のラベルは、その矢印の横向きの区間のうち最も長いものの上に置く。束ねた矢印のラベルは1つだけにし、共通の区間の上に置く。分岐の線のラベルは、斜めの区間のそばの段の溝に置く。ほかの札・文字・ラベル・線と重なるときは、同じ線のほかの区間、区間の中のほかの位置の順に試し、どこにも置けなければ、その段の溝を広げて置く。
11. 札・札の中の文字と印・ラベルは、互いに重ならない。線(路線の線・分岐の線・前提の矢印)は札の中を通らず、ラベルとも重ならない。ただし線どうしは交わってよく、交わる点には何も描かない(つながっていないと分かるように、交わる点で線を止めない)。図は横にも縦にも長くなってよい。ページでは、図の枠の中で図を動かして見る(「図の操作」)。
12. 札の幅と札の中の折り返しは、今の章の札(「このページ」を添える)か未執筆の章の札(「未執筆」を添える)の長さで見積もり、どのページでも同じ配置にする。

寸法と線の太さは実装で決める。

### 印と凡例

| 対象 | 描き方 |
|---|---|
| 路線 | 路線ファイルの color の線。ダークテーマでは color_dark(なければ color)。style が `dotted` なら点線。その路線の章の札の枠、「第N章」の文字、表示番号の札の枠と文字も同じ色にする |
| 章の札 | 書いた章は、路線の色の実線の枠で描く |
| 最終目標 | 駅の行の表示番号の札を路線の色で塗りつぶし、目標の label を札の説明(SVG の `title`)に入れる |
| 途中の目標 | 駅の行に「途中の目標」の札を添え、目標の label を、その札の説明(SVG の `title`)に入れる |
| 前提の矢印 | 地の文の色の細い線と矢じりで描き、ラベルも同じ色で書く |
| 今の章 | 章ページの図では、今の章の札の地を強調の色にし、「第N章」の行に「このページ」と添える。今の章の札が図にないときは、強調する札はない。強調の色はライトで `#ece8fa`、ダークで `#40366f` とする。ダークは地と札の明るさの差が小さく見分けにくいので、ライトより強める |
| 未執筆の章 | 全体の図にだけ描く。札は灰色の破線の枠にし、「第N章」の行に「未執筆」と添え、駅は表示番号のない灰色の駅名で書く。未執筆の章へつながる路線の線と分岐の線は灰色の破線にする。前提の矢印は、書いた章と同じに描く |
| 凡例 | 図に出てくる路線と、最終目標の印。途中の目標があれば途中の目標の印、前提の矢印があれば矢印、未執筆の章があれば未執筆の印も |

### リンク

- 駅の行(表示番号の札と駅名)は、その駅へのリンク(`<ベースパス>chapters/<章ID>/#<駅ID>`)にする(P-03)。
- 分野の路線図と、章ページの分野の図では、リンクに `?field=<分野ID>` を付ける。全体の図では付けない。
- 章ページの図にある今の章の駅だけは、リンクを `#<駅ID>` だけにし、ページを読み込み直さずにその駅へ移動する。
- 章の札の、駅の行を除く部分(「第N章」の行、タイトル、余白)は、その章のページの先頭へのリンク(`<ベースパス>chapters/<章ID>/`)にする。駅と同じく、分野の図では `?field=<分野ID>` を付ける。
- 章ページの図の今の章の札は、そのページの先頭へのリンク(`#`)にし、ページを読み込み直さない。
- ポインタが章の札の中にある間は、駅の行の上にあっても、その札を強調の色にする。路線の線・分岐の線・前提の矢印・ラベルは押せる対象にしない。
- 未執筆の章の札と駅はリンクにしない。
- 駅と章の札のリンクにはキーボードで移動できる。読み上げでは、駅は表示番号と駅名、章の札は「第N章 〈章のタイトル〉」が伝わる。

### 図の操作

ページの図は枠の中に置き、読者が動かしたり拡大・縮小したりして見る。

- 枠にはスクロールバーを出さない。図はマウスのドラッグで上下左右に動かす。タッチ操作では横のドラッグで図を動かし、縦のスワイプはページのスクロールに使う(枠より高い図を縦に見るには、縮小する)。トラックパッドの横方向のスクロールでも図を横に動かす。
- マウスのホイール(トラックパッドの縦のスクロールとピンチを含む)を枠の中で回すと、ポインタの位置を動かさずに拡大・縮小する。ポインタが枠の中にある間は、ホイールでページをスクロールしない。倍率の範囲はボタンと同じ。
- 駅の行や章の札の上から始めたドラッグでは、離してもリンク先へ移らない。ドラッグせずに押したときだけ移る。
- 枠のすぐ上の右端に「拡大」「縮小」「全体を表示」のボタンを置く(枠の中の図を隠さない)。拡大と縮小は枠の中央を基準に 1.25 倍ずつ変え、倍率は 3 倍まで、縮小は図全体が枠に収まる倍率(0.3 倍より小さければ 0.3 倍)までとする。「全体を表示」は、図全体が枠に収まる倍率(1 倍を超えない)にする。
- 図が枠より大きい向きでは、図の端が枠の中央に来るところまで図を動かせる(図の端の先の空いたところが見えてよい)。図が枠に収まる向きでは、図を枠の中央に置き、その向きには動かさない。
- 枠の高さは、1 倍のときの図の高さと 600px の小さいほうとする。開いたときの倍率は、保存した倍率があればその倍率(その図で選べる範囲の外なら、範囲に収める)、なければ 1 倍とする。章ページの図では、図が枠より大きい向きについて、今の章の札の中央を枠の中央に置く。図の端の近くの札でも中央に置き、図の端の先の空いたところを見せる。それ以外の図は左上の端から見せる。
- 「拡大」「縮小」「全体を表示」とホイールで倍率を変えると、その倍率を読者のブラウザに保存し([site.md](site.md)「ブラウザに保存するもの」)、どのページの図も次に開くときはその倍率で表示する。倍率は全ページの図で1つである。表示の設定の「元に戻す」で消える。
- キーボードで枠の外にある駅や章の札のリンクにフォーカスしたら、それが枠の中に見えるように図を横と縦に動かす。マウスやタッチで押したときは図を動かさず、枠からはみ出した駅や章の札でも、1回押せばリンク先へ移る。ボタンはキーボードで押せる。
- スクリプトが動かないときは、ボタンを出さず、枠の中を横と縦にスクロールして見る。

### 倍率ごとの表示

図を縮小すると駅の行の文字は読めなくなるので、倍率に応じて札の中の文字を切り替え、全体の形と章のタイトルを読めるようにする。札の大きさと位置、路線の線・分岐の線・前提の矢印は、どの段階でも変えない。

| 段階 | 倍率 | 札の中に書くもの |
|---|---|---|
| 駅の行 | 0.75 倍以上 | 「配置」6 のとおり |
| 概要 | 0.45 倍以上 0.75 倍未満 | 「第N章」の行(「このページ」「未執筆」を添える。入らなければ「第N章」だけ)と章のタイトルを、駅の行の段階より大きな文字で書く |
| 章のタイトルだけ | 0.45 倍未満 | 章のタイトルを、概要よりさらに大きな文字で書く |

- 概要と章のタイトルだけの段階では、駅の行(表示番号の札・駅名・未執筆の駅名)、「途中の目標」の札、前提の矢印と分岐の線のラベルを隠す。最終目標と途中の目標は、駅の行の段階に戻すと見える。
- 章のタイトルは札の幅で折り返し(「配置」6 と同じ規則)、3行を超える分は末尾を「…」で省く。札の高さは3行まで入るように決める(「配置」6)。文字の大きさは実装で決める。
- 隠した駅のリンクにはキーボードで移動できない。章の札のリンクは、どの段階でも押せて、キーボードで移動できる。図の説明(`desc`)は段階によらず同じ。
- スクリプトが動かないときは、駅の行の段階だけを表示する。

### 代替テキスト

- 図の名前(SVG の `title`):「全体の路線図」「〈分野名〉の路線図」。
- 図の説明(SVG の `desc`):路線ごとに、図に描いた章を読む順に並べ、章ごとに「第N章 〈章のタイトル〉:」に続けて、その章の描く駅を表示番号・駅名・印の順で並べる。未執筆の章は「第N章 〈章のタイトル〉(未執筆):」とし、駅は表示番号を書かずに駅名だけを並べる。印は「(最終目標)」「(途中の目標)」と書く。路線のあとに、前提の矢印ごとに「第M章は、第N章の 〈表示番号〉 〈駅名〉を前提にする。」と書く(前提の駅が2つ以上あれば「、」でつなぐ。未執筆の駅は駅名だけ)。例:「解析線。第3章 完備性と不動点:A01 コーシー列、A02 完備性、A03 縮小写像、A04 バナッハの不動点定理(最終目標)。」
